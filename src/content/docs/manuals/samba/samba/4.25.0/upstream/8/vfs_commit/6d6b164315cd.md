### 名前 {#Name}


<p>vfs_commit — 指定した間隔で未書き出しデータをフラッシュする</p>

### 書式 {#Synopsis}


<p><code>vfs objects = commit</code></p>

### 説明 {#DESCRIPTION}


<p>この VFS モジュールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.7.html">samba(7)</a> スイートの一部です。</p>

<p><code>vfs_commit</code> VFS モジュールは、ファイルに書き込まれたデータ量を追跡し、指定量が蓄積するとディスクへ同期します。</p>

<p><code>vfs_commit</code> は2つの状況で役立ちます。まず、非常に重要なデータがある場合、小さな commit:dthresh 値により、予期しない電源断の影響を最小限にできます。また、一部のシステムでは、ファイルデータを早めに一定間隔でフラッシュすると書き込み性能が向上する場合があります。</p>

<p>このモジュールは他のモジュールと積み重ねて使用できます。</p>

### オプション {#OPTIONS}


<dl><dt>commit:dthresh = BYTES</dt><dd><p>指定したバイト数を書き込むたびに、ファイルデータを同期します。</p>
<p>BYTES には次の接尾辞を付けられます。</p>
<ul><li><p><code>K</code> - BYTES はキロバイト数です。</p></li><li><p><code>M</code> - BYTES はメガバイト数です。</p></li><li><p><code>G</code> - BYTES はギガバイト数です。</p></li></ul></dd></dl>

### 例 {#EXAMPLES}


<p>[precious] 共有で、512キロバイト（524288バイト）のデータを書き込むたびにファイルデータを同期します。</p>

<pre><code>        [precious]
	path = /data/precious
	vfs objects = commit
	commit:dthresh = 512K</code></pre>

### 注意事項 {#CAVEATS}


<p>一部のシステムでは、<code>commit</code> が行うデータ同期によって性能が低下する場合があります。</p>
