### 名前 {#Name}


<p>vfs_prealloc — 一致するファイルに所定サイズの領域を事前割り当てする</p>

### 書式 {#Synopsis}


<p><code>vfs objects = prealloc</code></p>

### 説明 {#DESCRIPTION}


<p>このVFSモジュールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.7.html">samba(7)</a> スイートの一部です。</p>

<p><code>vfs_prealloc</code> VFSモジュールは、新しいファイルを作成するたびに、指定サイズの領域を事前割り当てします。ファイルに割り当てる領域の拡張にコストがかかるディスクサブシステムへ、サイズがあらかじめ決まっているファイルを書き込む環境で便利です。</p>

<p>このモジュールは他のモジュールと積み重ねて使用できます。</p>

### オプション {#OPTIONS}


<dl><dt>prealloc:EXT = BYTES</dt><dd><p>拡張子EXTを持つすべてのファイルに、BYTESで指定したサイズの領域を事前割り当てします。</p>
<p>BYTESには次の接尾辞を付けられます。</p>
<ul><li><p><code>K</code> - BYTESはキロバイト数です。</p></li><li><p><code>M</code> - BYTESはメガバイト数です。</p></li><li><p><code>G</code> - BYTESはギガバイト数です。</p></li></ul></dd></dl>

### 使用例 {#EXAMPLES}


<p>あるプロセスがSamba共有にTIFFファイルを書き込み、そのファイルがほぼ常に4メガバイト（4194304バイト）程度になることがわかっている場合の例です。</p>

<pre><code>        [frames]
	path = /data/frames
	vfs objects = prealloc
	prealloc:tiff = 4M</code></pre>

### 注意事項 {#CAVEATS}


<p><code>vfs_prealloc</code> は、すべてのプラットフォームとファイルシステムでサポートされているわけではありません。現在サポートされているのは、LinuxとIRIX上のXFSファイルシステムだけです。</p>
