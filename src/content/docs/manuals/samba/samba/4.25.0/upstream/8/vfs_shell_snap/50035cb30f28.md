### 名前 {#Name}


<p>vfs_shell_snap — スナップショット作成・削除のためのシェルスクリプト呼び出し</p>

### 書式 {#Synopsis}


<p><code>vfs objects = shell_snap</code></p>

### 説明 {#DESCRIPTION}


<p>この VFS モジュールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.8.html">samba(8)</a> スイートの一部です。</p>

<p><code>vfs_shell_snap</code> VFS は、リモートクライアントが File Server Remote VSS Protocol（FSRVP）で発行するスナップショット作成・削除操作のために、シェルスクリプトの呼び出し機構を提供します。</p>

<p>smb.conf で次のシェル呼び出しを設定できます。</p>

<p><a href="https://www.samba.org/samba/docs/current/man-html/smb.conf.5.html#SHELL_SNAP:CHECKPATHCOMMAND">shell_snap:check path command</a></p>

<ul><li><p>FSRVP クライアントが、共有がスナップショット作成・削除要求をサポートするか確認するときに呼ばれます。</p></li><li><p>コマンドは単一の <em><code>share_path</code></em> 引数で呼ばれます。</p></li><li><p><em><code>share_path</code></em> のスナップショットを作成できる場合、コマンドは0を返さなければなりません。</p></li></ul>

<p><a href="https://www.samba.org/samba/docs/current/man-html/smb.conf.5.html#SHELL_SNAP:CREATECOMMAND">shell_snap:create command</a></p>

<ul><li><p>FSRVP クライアントがスナップショットを作成するときに呼ばれます。</p></li><li><p>コマンドは単一の <em><code>share_path</code></em> 引数で呼ばれます。</p></li><li><p>スナップショットを正常に作成した場合、コマンドは終了状態0を返さなければなりません。</p></li><li><p>コマンドは新しく作成したスナップショットのパスを標準出力へ出力しなければなりません。</p></li></ul>

<p><a href="https://www.samba.org/samba/docs/current/man-html/smb.conf.5.html#SHELL_SNAP:DELETECOMMAND">shell_snap:delete command</a></p>

<ul><li><p>FSRVP クライアントがスナップショットを削除するときに呼ばれます。</p></li><li><p>コマンドは <em><code>base_share_path</code></em> と <em><code>snapshot_share_path</code></em> の引数で呼ばれます。</p></li><li><p>スナップショットを正常に削除した場合、コマンドは終了状態0を返さなければなりません。</p></li></ul>

<p>すべてのコマンドは、認証済みの FSRVP クライアントユーザーとして実行されます。</p>

<p>このモジュールは他のモジュールと積み重ねて使用できます。</p>

### 設定 {#CONFIGURATION}


<pre><code>		[share]
		vfs objects = shell_snap
		shell_snap:check path command = snap_check_path.sh
		shell_snap:create command = snap_create.sh
		shell_snap:delete command = snap_delete.sh</code></pre>

<p>Samba の FSRVP サーバーは [global] セクションで設定する必要があります。</p>

<pre><code>		[global]
		registry shares = yes
		include = registry</code></pre>
