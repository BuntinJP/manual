### 名前 {#Name}


<p>ntlm_auth — Winbind の NTLM 認証機能への外部アクセスを可能にするツール</p>

### 書式 {#Synopsis}


<p><code>ntlm_auth</code></p>

### 説明 {#DESCRIPTION}


<p>このツールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.7.html">samba(7)</a> スイートの一部です。</p>

<p><code>ntlm_auth</code> は NT/LM 認証でユーザーを認証するヘルパーユーティリティーです。認証に成功すると0を、アクセスを拒否すると1を返します。ntlm_auth は winbind を使って、ドメインのユーザー情報と認証データにアクセスします。このユーティリティーは、他のプログラム（現在は <a href="https://www.squid-cache.org/">Squid</a> と <a href="https://www.samba.org/ftp/unpacked/lorikeet/mod_auth_ntlm_winbind/">mod_ntlm_winbind</a>）から使うことだけを想定しています。</p>

### 動作要件 {#OPERATIONAL-REQUIREMENTS}


<p>これらのコマンドの多くが動作するには、<a href="https://www.samba.org/samba/docs/current/man-html/winbindd.8.html">winbindd(8)</a> デーモンが稼働している必要があります。</p>

<p>一部のコマンドでは、<code>$LOCKDIR</code> 内の <code>winbindd_privileged</code> ディレクトリへのアクセスも必要です。このコマンドを root として実行するか、<code>winbindd_privileged</code> ディレクトリへのグループアクセスを許可してください。安全のため、このディレクトリを誰でもアクセスできる状態にしてはいけません。</p>

### 設定例 {#EXAMPLE-SETUP}


<p>Squid 2.5 から Basic 認証と NTLMSSP 認証の両方で ntlm_auth を利用するには、<code>squid.conf</code> ファイルに次の内容を記述します。</p>

<pre><code>auth_param ntlm program ntlm_auth --helper-protocol=squid-2.5-ntlmssp
auth_param basic program ntlm_auth --helper-protocol=squid-2.5-basic
auth_param basic children 5
auth_param basic realm Squid proxy-caching web server
auth_param basic credentialsttl 2 hours</code></pre>

#### 注 {#Note}


<p>この例は、ntlm_auth が実行パス内にインストールされ、<code>winbindd_privileged</code> のグループアクセス権が前述のとおり設定されていることを前提とします。</p>

<p>上の例に加え、グループ制限付きで Squid 2.5 から ntlm_auth を利用するには、<code>squid.conf</code> ファイルに次の内容を追加します。</p>

<pre><code>auth_param ntlm program ntlm_auth --helper-protocol=squid-2.5-ntlmssp --require-membership-of=&#39;WORKGROUP\Domain Users&#39;
auth_param basic program ntlm_auth --helper-protocol=squid-2.5-basic --require-membership-of=&#39;WORKGROUP\Domain Users&#39;</code></pre>

### 問題の解決 {#TROUBLESHOOTING}


<p>MS Windows 9X または Millennium Edition 上の Internet Explorer を、ntlm_auth の NTLMSSP 認証ヘルパー（<code>--helper-protocol</code>=squid-2.5-ntlmssp）で認証する際に問題が起きる場合は、<a href="http://support.microsoft.com/support/kb/articles/Q239/8/69.ASP">the Microsoft Knowledge Base article #239869 and follow instructions described there</a>（Microsoft Knowledge Base の記事 #239869）を読み、そこに記された手順に従ってください。</p>
