### 名前 {#Name}


<p>samba_downgrade_db — ADデータベースをダウングレードするSambaツール</p>

### 書式 {#Synopsis}


<p><code>samba_downgrade_db</code> [<code>-H</code>] [<code>-s</code>]</p>

### 説明 {#DESCRIPTION}


<p>このツールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.8.html">samba(8)</a> スイートの一部です。</p>

<p>Samba Active Directory（AD）データベースの形式は、バージョン4.8と4.11で変更されました。Samba ADドメインコントローラー（DC）を、これらのいずれかより古いリリースへダウングレードする場合（たとえば4.11から4.10）、Sambaパッケージを安全にダウングレードするには、その<em>前に</em>ADデータベースを手動でダウングレードする必要があります。</p>

<p>このツールは、Sambaのsam.ldbデータベースを、バージョン4.25.0で使用される形式からバージョン4.7の形式へダウングレードします。v4.7のデータベース形式は、どのバージョンのSambaでも安全に読み込めます。必要であれば、より新しいバージョンのSambaは、samba実行ファイルの初回起動時にv4.7形式のデータベースを再パックし、再構成します。</p>

<p>このツールを実行する前に、DC上のすべてのSambaサービスを停止する必要があります。ツールの実行後は、Sambaソフトウェアパッケージのダウングレードが完了するまで、sambaを再起動したりデータベースを変更したりしないでください。</p>

### オプション {#OPTIONS}


<dl><dt><code>-H</code> [sam.ldbファイル]</dt><dd><p>システムのsmb.conf内のパスを使用する代わりに、sam.ldbファイルを直接指定します。</p></dd><dt><code>-s</code> [smb.confファイル]</dt><dd><p>システムの既定値（通常は/usr/local/samba/etc/smb.conf）ではなく、smb.confファイルを直接指定します。</p></dd></dl>
