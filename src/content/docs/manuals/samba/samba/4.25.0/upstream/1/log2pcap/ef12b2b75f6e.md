### 名前 {#Name}


<p>log2pcap — Samba ログファイルからネットワークトレースを抽出する</p>

### 書式 {#Synopsis}


<p><code>log2pcap</code> [<code>-h</code>] [<code>-q</code>] [logfile] [pcap_file]</p>

### 説明 {#DESCRIPTION}


<p>このツールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.7.html">samba(7)</a> スイートの一部です。</p>

<p><code>log2pcap</code> は samba ログファイルを読み込み、ログ内のパケットダンプに基づいて pcap ファイル（ethereal や tcpdump など、ほとんどのスニファーで読み取り可能）を生成します。</p>

<p>ログファイルの <em><code>log level</code></em> は、SMB ヘッダー/パラメーターを正しく取得するには少なくとも <code>5</code>、パケットの先頭 512 データバイトを取得するには <code>10</code>、パケット全体を取得するには <code>50</code> でなければなりません。</p>

### オプション {#OPTIONS}


<dl><dt><code>-h</code></dt><dd><p>このパラメーターを指定すると、出力ファイルは text2pcap ユーティリティーで読み取れる形式の 16 進ダンプになります。</p></dd><dt><code>-q</code></dt><dd><p>静かに動作します。データの欠落や不完全なデータに関する警告メッセージを出力しません。</p></dd><dt>logfile</dt><dd><p>Samba ログファイル。ログファイルを指定しない場合、log2pcap は標準入力からログを読み取ろうとします。</p></dd><dt>pcap_file</dt><dd><p>pcap（または 16 進ダンプ）データを書き込む出力ファイル名。この引数を指定しない場合、データを標準出力に書き込みます。</p></dd><dt>-?|<code>--help</code></dt><dd><p>コマンドラインオプションの概要を表示します。</p></dd></dl>

### 使用例 {#EXAMPLES}


<p>すべての samba ログファイルからすべてのネットワークトラフィックを抽出します。</p>

<pre><code>			$ log2pcap &lt; /var/log/* &gt; trace.pcap</code></pre>

<p>text2pcap を使用して pcap に変換します。</p>

<pre><code>	$ log2pcap -h samba.log | text2pcap -T 139,139 - trace.pcap</code></pre>

### バージョン {#VERSION}


<p>このマニュアルページは Samba スイートのバージョン 4.25.0 の一部です。</p>

### バグ {#BUGS}


<p>samba ログから抽出するのは SMB データのみです。LDAP、NetBIOS 名前検索、その他のデータは抽出しません。</p>

<p>生成された TCP ヘッダーと IP ヘッダーには有効なチェックサムが含まれません。</p>
