### 名前 {#Name}


<p>vfs_linux_xfs_sgid — XFS で sgid ビットが継承されない問題を回避する</p>

### 書式 {#Synopsis}


<p><code>vfs objects = linux_xfs_sgid</code></p>

### 説明 {#DESCRIPTION}


<p>この VFS モジュールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.7.html">samba(7)</a> スイートの一部です。</p>

<p><code>vfs_linux_xfs_sgid</code> は、3.11 で修正された古い Linux XFS のバグを回避する VFS モジュールです。このバグでは、既定の ACL が設定されていると、mkdir 時に SGID ビットが継承されません（<a href="https://web.archive.org/web/20160320180937/http://oss.sgi.com/bugzilla/show_bug.cgi?id=280">https://web.archive.org/web/20160320180937/http://oss.sgi.com/bugzilla/show_bug.cgi?id=280</a>。<a href="https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/commit/?id=42c49d7f249c2487f36d3314753d5d8ebcee8249">https://git.kernel.org/pub/scm/linux/kernel/git/torvalds/linux.git/commit/?id=42c49d7f249c2487f36d3314753d5d8ebcee8249</a> で修正済み）。<code>vfs_linux_xfs_sgid</code> VFS モジュールは、親ディレクトリーに SGID ビットが設定されていた場合、<code>mkdir</code> の後で SGID ビットを明示的に設定して、このバグを回避します。</p>

<p>このモジュールは、他のモジュールと重ねて使用できます。</p>

### 使用例 {#EXAMPLES}


<p>[share] に linux_xfs_sgid 機能を追加します。</p>

<pre><code>        [share]
	vfs objects = linux_xfs_sgid</code></pre>
