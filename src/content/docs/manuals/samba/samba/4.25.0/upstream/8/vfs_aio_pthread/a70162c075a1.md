### 名前 {#Name}


<p>vfs_aio_pthread — pthreadプールを使用してSamba VFSの非同期openを実装する</p>

### 書式 {#Synopsis}


<p><code>vfs objects = aio_pthread</code></p>

### 説明 {#DESCRIPTION}


<p>このVFSモジュールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.7.html">samba(7)</a> スイートの一部です。</p>

<p><code>aio_pthread</code> VFSモジュールは、pthreads APIが利用でき、openat()システムコールとスレッドごとの資格情報をサポートするプラットフォーム（新しいLinuxカーネル）で、<a href="https://www.samba.org/samba/docs/current/man-html/smb.conf.5.html#AIO_PTHREAD:AIOOPEN">aio_pthread:aio open = yes</a> によって新規ファイルの非同期openを有効にします。</p>

<p>このモジュールは、<a href="https://www.samba.org/samba/docs/current/man-html/smb.conf.5.html#AIOMAXTHREADS">aio max threads</a> オプションを使用するグローバルなスレッドプールを利用します。</p>

<p>Samba VFSのopenインターフェイスはスレッドセーフではないため、このモジュールは必ずモジュールスタックの最後に指定しなければなりません。このモジュールはopenat()システムコールを直接実行し、Samba VFSのopenインターフェイスは呼び出しません。</p>

### 使用例 {#EXAMPLES}


<p>単純な使用例:</p>

<pre><code>        [cooldata]
	path = /data/ice
	vfs objects = aio_pthread
	aio_pthread:aio open = yes</code></pre>

### オプション {#OPTIONS}


<dl><dt>aio_pthread:aio open = BOOL</dt><dd><p>新しいファイルを作成する際に非同期openを試みます。</p>
<p>既定値は&#39;no&#39;です。</p></dd></dl>
