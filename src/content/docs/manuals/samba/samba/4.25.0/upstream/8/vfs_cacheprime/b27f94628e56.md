### 名前 {#Name}


<p>vfs_cacheprime — カーネルのファイルデータキャッシュに事前読み込みする</p>

### 書式 {#Synopsis}


<p><code>vfs objects = cacheprime</code></p>

### 説明 {#DESCRIPTION}


<p>この VFS モジュールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.7.html">samba(7)</a> スイートの一部です。</p>

<p><code>vfs_cacheprime</code> VFS モジュールは、クライアントが要求した範囲の近くにあるファイルデータをまとめて読み込み、実際にクライアントから要求されたときにカーネルのファイルデータキャッシュにデータがあるようにします。</p>

<p><code>vfs_cacheprime</code> が行うディスク読み取りのサイズは cacheprime:rsize オプションで決まります。すべての読み取りは、このサイズの倍数の境界に揃えられます。クライアントがファイルを開いている間、各データ範囲の事前読み込みは最大1回です。</p>

<p>このモジュールは他のモジュールと積み重ねて使用できます。</p>

### オプション {#OPTIONS}


<dl><dt>cacheprime:rsize = BYTES</dt><dd><p>カーネルのデータキャッシュに事前読み込みするバイト数です。</p>
<p>BYTES には次の接尾辞を付けられます。</p>
<ul><li><p><code>K</code> - BYTES はキロバイト数です。</p></li><li><p><code>M</code> - BYTES はメガバイト数です。</p></li><li><p><code>G</code> - BYTES はギガバイト数です。</p></li></ul></dd></dl>

### 例 {#EXAMPLES}


<p>あるディスクアレイで、すべての読み取りを1メガバイト（1048576バイト）単位とし、1メガバイト境界に揃える必要がある場合の例です。</p>

<pre><code>	[hypothetical]
	vfs objects = cacheprime
	cacheprime:rsize = 1M</code></pre>

### 注意事項 {#CAVEATS}


<p><code>cacheprime</code> は汎用の先読み機構の代わりではありません。ディスク操作の位置とサイズを既知の値に揃える必要がある、非常に特殊な環境だけを対象とします（可能な限りその条件を満たすためのものです）。</p>
