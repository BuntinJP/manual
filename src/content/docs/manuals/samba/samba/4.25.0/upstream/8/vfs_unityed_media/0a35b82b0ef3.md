### 名前 {#Name}


<p>vfs_unityed_media — 複数のAvidクライアントによるネットワークドライブの共有を可能にする</p>

### 書式 {#Synopsis}


<p><code>vfs objects = unityed_media</code></p>

### 説明 {#DESCRIPTION}


<p>このVFSモジュールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.7.html">samba(7)</a> スイートの一部です。</p>

<p>Unityed MediaはMedia Harmony VFSに関連するものです。両者の主な違いは、Unityed Mediaではメディアディレクトリを手動で更新する必要がないことです。Unityed Mediaは、Unity、ISIS、EditShareなどの専用ソリューションと同様の方法でメディアファイルを扱います。クライアント側のアプリケーションは不要で、任意のハードウェア上で動作します。</p>

<p>このモジュールは他のモジュールと積み重ねて使用できます。</p>

### 設定 {#CONFIGURATION}


<p>MacとWindowsのAvidクライアントが同じフォルダーにアクセスする場合は、別々の共有定義を用意し、Windows用共有ではMacの隠しファイルを拒否対象にしてください。「使用例」を参照してください。</p>

### オプション {#OPTIONS}


<dl><dt>unityed_media:clientid = user | hostname | ip</dt><dd><p>ユーザー固有のパスに追加する、クライアントに関連する識別子を指定します。</p>
<ul><li><p><code>user (default)</code> - ユーザー名を使用します。</p></li><li><p><code>hostname</code> - ホスト名を使用します。OS Xクライアントは常に汎用文字列（「workstation」）をサーバーに送信するため、この方法は機能しません。</p></li><li><p><code>ip</code> - クライアントのIPアドレスを使用します。注意: これは未テストであり、まったく機能しない可能性があります。</p></li></ul></dd></dl>

### 使用例 {#EXAMPLES}


<p>MacとWindowsのクライアントに対してunityed_mediaを有効にします。</p>

<pre><code>        [avid_mac]
	path = /avid
	vfs objects = unityed_media
        [avid_win]
	path = /avid
	vfs objects = unityed_media
	veto files = /.DS_Store/._@/.Trash@/.Spotlight@/.hidden/.hotfiles@/.vol/
	delete veto files = yes</code></pre>
