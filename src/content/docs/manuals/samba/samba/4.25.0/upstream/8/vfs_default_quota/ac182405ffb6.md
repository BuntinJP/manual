### 名前 {#Name}


<p>vfs_default_quota — Windows クライアント用の既定クォータレコードを保存する</p>

### 書式 {#Synopsis}


<p><code>vfs objects = default_quota</code></p>

### 説明 {#DESCRIPTION}


<p>この VFS モジュールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.7.html">samba(7)</a> スイートの一部です。</p>

<p>一般的なクォータ実装の多くはユーザーとグループのクォータだけを保存し、既定クォータは保存しません。<code>vfs_default_quota</code> モジュールを使うと、Windows Explorer のインターフェースで確認できる既定クォータ値を Samba が保存できます。</p>

<p>既定では、Samba は既定クォータとして NO_LIMIT を返し、その更新を拒否します。<code>vfs_default_quota</code> は既定クォータをユーザーのクォータレコードに対応付けます。通常 root にはクォータ制限が適用されないため、既定では root ユーザーを使います。</p>

<p>このモジュールは他のモジュールと積み重ねて使用できます。</p>

### オプション {#OPTIONS}


<dl><dt>default_quota:uid = UID</dt><dd><p>UID は、既定のユーザークォータ値を保存するクォータレコードのユーザーIDを指定します。</p></dd><dt>default_quota:gid = GID</dt><dd><p>GID は、既定のグループクォータ値を保存するクォータレコードのグループIDを指定します。</p></dd><dt>default_quota:uid nolimit = BOOL</dt><dd><p>このパラメーターが True の場合、既定のユーザークォータをレコードに保存しているユーザーのクォータは NO_LIMIT と報告されます。それ以外では保存されている値を報告します。</p></dd><dt>default_quota:gid nolimit = BOOL</dt><dd><p>このパラメーターが True の場合、既定のグループクォータをレコードに保存しているグループのクォータは NO_LIMIT と報告されます。それ以外では保存されている値を報告します。</p></dd></dl>

### 例 {#EXAMPLES}


<p>ID 65535 のユーザーのクォータレコードに既定クォータを保存し、そのユーザーにはクォータ制限がないと報告します。</p>

<pre><code>        [global]
	vfs objects = default_quota
	default_quota:uid = 65535
	default_quota:uid nolimit = yes</code></pre>
