### 名前 {#Name}


<p>smbcontrol — smbd、nmbd、winbindd プロセスにメッセージを送る</p>

### 書式 {#Synopsis}


<p><code>smbcontrol</code> [-?|<code>--help</code>] [<code>--usage</code>] [<code>-t</code>|<code>--timeout</code>] [<code>-d</code>|<code>--debuglevel</code>=DEBUGLEVEL] [<code>--debug-stdout</code>] [<code>--configfile</code>=CONFIGFILE] [<code>--option</code>=name=value] [<code>-l</code>|<code>--log-basename</code>=LOGFILEBASE] [<code>--leak-report</code>] [<code>--leak-report-full</code>]</p>

<p><code>smbcontrol</code> [destination] [message-type] [parameter]</p>

### 説明 {#DESCRIPTION}


<p>このツールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.7.html">samba(7)</a> スイートの一部です。</p>

<p><code>smbcontrol</code> は、システム上で動作している <a href="https://www.samba.org/samba/docs/current/man-html/smbd.8.html">smbd(8)</a>、<a href="https://www.samba.org/samba/docs/current/man-html/nmbd.8.html">nmbd(8)</a>、<a href="https://www.samba.org/samba/docs/current/man-html/winbindd.8.html">winbindd(8)</a> デーモンにメッセージを送る非常に小さなプログラムです。</p>

### オプション {#OPTIONS}


<dl><dt><code>-t</code>|<code>--timeout</code></dt><dd><p>タイムアウトを秒単位で設定します。</p></dd><dt>destination</dt><dd><p><em><code>nmbd</code></em>、<em><code>smbd</code></em>、<em><code>winbindd</code></em> のいずれか、またはプロセス ID。</p>
<p>宛先 <em><code>all</code></em> は、nmbd と winbind を含むすべての実行中のデーモンにメッセージを「ブロードキャスト」します。これは Samba 3.3 での変更で、それ以前は smbd パラメーターがこの動作を行っていました。</p>
<p>宛先 <em><code>smbd</code></em> は、<code>smbd.pid</code> ファイルで指定された smbd デーモンにメッセージを送ります。</p>
<p>宛先 <em><code>nmbd</code></em> は、<code>nmbd.pid</code> ファイルで指定された nmbd デーモンにメッセージを送ります。</p>
<p>宛先 <em><code>winbindd</code></em> は、<code>winbindd.pid</code> ファイルで指定された winbind デーモンにメッセージを送ります。</p>
<p>単一のプロセス ID を指定した場合、そのプロセスだけにメッセージを送ります。</p></dd><dt>message-type</dt><dd><p>送信するメッセージの種類。詳細は <code>MESSAGE-TYPES</code> 節を参照してください。</p></dd><dt>parameters</dt><dd><p>message-type に必要なパラメーター</p></dd><dt>-?|<code>--help</code></dt><dd><p>コマンドラインオプションの概要を表示します。</p></dd><dt><code>--usage</code></dt><dd><p>簡単な使用方法を表示します。</p></dd><dt><code>-d</code>|<code>--debuglevel</code>=level</dt><dd><p><em><code>level</code></em> は0から10の整数です。このパラメーターを省略した場合、クライアントアプリケーションでの既定値は1です。</p>
<p>値を大きくすると、サーバーの動作についてログファイルに記録する詳細が増えます。レベル0では重大なエラーと深刻な警告だけを記録します。レベル1は日常的な運用に適しており、実行した操作について少量の情報を生成します。</p>
<p>1より上のレベルは大量のログデータを生成するため、問題の調査時だけ使ってください。3より上は開発者専用に設計されており、大部分が非常に難解な、極めて大量のログデータを生成します。</p>
<p>ここでこのパラメーターを指定すると、<code>${prefix}/etc/smb.conf</code> ファイルの <a href="https://www.samba.org/samba/docs/current/man-html/smb.conf.5.html#LOGLEVEL">log level</a> パラメーターを上書きします。</p></dd><dt><code>--debug-stdout</code></dt><dd><p>デバッグ出力を標準出力へ転送します。既定では、すべてのクライアントは標準エラー出力へログを出します。</p></dd><dt><code>--configfile</code>=&lt;configuration file&gt;</dt><dd><p>指定したファイルには、クライアントが必要とする設定の詳細を記述します。クライアントとサーバーに共通の情報のほか、<a href="https://www.samba.org/samba/docs/current/man-html/smb.conf.5.html#CLIENTSMBENCRYPT">client smb encrypt</a> などのクライアント固有のオプションだけを記述することもできます。詳細は <code>${prefix}/etc/smb.conf</code> を参照してください。既定の設定ファイル名はコンパイル時に決まります。</p></dd><dt><code>--option</code>=&lt;name&gt;=&lt;value&gt;</dt><dd><p>コマンドラインから <a href="https://www.samba.org/samba/docs/current/man-html/smb.conf.5.html">smb.conf(5)</a> オプション &quot;&lt;name&gt;&quot; を値 &quot;&lt;value&gt;&quot; に設定します。コンパイル時の既定値と設定ファイルから読み込んだオプションを上書きします。名前や値に空白が含まれる場合は、<code>--option</code>=name=value 全体を引用符で囲んでください。</p></dd><dt><code>-l</code>|<code>--log-basename</code>=logdirectory</dt><dd><p>ログ/デバッグファイルの基底ディレクトリ名です。拡張子 <code>&quot;.progname&quot;</code> が追加されます（log.smbclient、log.smbd など）。クライアントがログファイルを削除することはありません。</p></dd><dt><code>--leak-report</code></dt><dd><p>終了時の talloc リーク報告を有効にします。</p></dd><dt><code>--leak-report-full</code></dt><dd><p>終了時の完全な talloc リーク報告を有効にします。</p></dd><dt><code>-V</code>|<code>--version</code></dt><dd><p>プログラムのバージョン番号を表示します。</p></dd></dl>

### メッセージの種類 {#MESSAGE-TYPES}


<p>利用可能なメッセージの種類は次のとおりです。</p>

<dl><dt>close-share</dt><dd><p>指定した共有へのクライアント接続を閉じるよう smbd に指示します。ほかの共有への接続には影響しません。引数には接続を閉じる共有名、または現在開いているすべての共有を閉じる &quot;*&quot; を指定します。共有のアクセス制御を変更した場合に役立つことがあります。このメッセージは <code>smbd</code> にのみ送信できます。</p></dd><dt>close-denied-share</dt><dd><p><code>close-share</code> と同様に動作しますが、引き続き共有へのアクセスが許可されているユーザーは切断しません。共有のアクセス制御変更後にすべての smbd に安全に送信できます。最初の接続後にアクセスが拒否されるようになったユーザーだけに影響します。このメッセージは <code>smbd</code> にのみ送信できます。</p></dd><dt>debug</dt><dd><p>デバッグレベルをパラメーターの値に設定します。どの宛先にも送信できます。smbd または winbindd デーモンに送信すると、親プロセスがすべての子プロセスへ再度ブロードキャストし、それぞれのデバッグレベルを変更します。</p></dd><dt>kill-client-ip</dt><dd><p>指定した IP アドレスからのクライアント接続を閉じるよう smbd に指示します。引数には、接続を閉じるクライアントの IP アドレスを指定します。このメッセージは <code>smbd</code> にのみ送信できます。</p></dd><dt>force-election</dt><dd><p><code>nmbd</code> デーモンに、新たなブラウズマスター選出を強制します。</p></dd><dt>ping</dt><dd><p>指定した数の &quot;ping&quot; メッセージを送り、同数の &quot;pong&quot; 応答を待ちます。どの宛先にも送信できます。</p></dd><dt>profile</dt><dd><p>パラメーターに基づいてデーモンのプロファイル設定を変更します。&quot;on&quot; はプロファイル統計収集を有効、&quot;off&quot; は無効、&quot;count&quot; は回数統計だけを収集（時間統計は無効）、&quot;flush&quot; は現在の統計をゼロにします。smbd または nmbd の宛先に送信できます。</p></dd><dt>debuglevel</dt><dd><p>指定したデーモンの debuglevel を要求し、標準出力に書き出します。どの宛先にも送信できます。</p></dd><dt>profilelevel</dt><dd><p>指定したデーモンの profilelevel を要求し、標準出力に書き出します。smbd または nmbd の宛先に送信できます。</p></dd><dt>printnotify</dt><dd><p>プリンターに接続している Windows NT クライアントにプリンター通知メッセージを送るよう smbd に指示します。次の引数を使用できます。</p>
<dl><dt>queuepause printername</dt><dd><p>指定したプリンターに、キュー一時停止の変更通知メッセージを送ります。</p></dd><dt>queueresume printername</dt><dd><p>指定したプリンターのキュー再開の変更通知メッセージを送ります。</p></dd><dt>jobpause printername unixjobid</dt><dd><p>指定したプリンターと Unix ジョブ ID のジョブ一時停止の変更通知メッセージを送ります。</p></dd><dt>jobresume printername unixjobid</dt><dd><p>指定したプリンターと Unix ジョブ ID のジョブ再開の変更通知メッセージを送ります。</p></dd><dt>jobdelete printername unixjobid</dt><dd><p>指定したプリンターと Unix ジョブ ID のジョブ削除の変更通知メッセージを送ります。</p></dd></dl>
<p>このメッセージはイベントの発生を通知するだけで、実際にイベントを発生させるものではありません。</p>
<p>このメッセージは <code>smbd</code> にのみ送信できます。</p></dd><dt>dmalloc-mark</dt><dd><p>dmalloc のマークを設定します。smbd と nmbd の両方に送信できます。Samba が dmalloc サポート付きでビルドされている場合にのみ利用できます。</p></dd><dt>dmalloc-log-changed</dt><dd><p>dmalloc-mark でマークを設定して以降に変化したポインターをダンプします。smbd と nmbd の両方に送信できます。Samba が dmalloc サポート付きでビルドされている場合にのみ利用できます。</p></dd><dt>shutdown</dt><dd><p>指定したデーモンを終了します。smbd と nmbd の両方に送信できます。</p></dd><dt>pool-usage</dt><dd><p>指定したデーモン/プロセスのすべての talloc(pool) メモリー使用量を、人間が読みやすい形式で表示します。smbd と nmbd の両方で利用できます。</p></dd><dt>ringbuf-log</dt><dd><p>ringbuf ログを取得して表示します。<em><code>logging = ringbuf</code></em> が必要です。smbd、winbindd、nmbd で利用できます。</p></dd><dt>drvupgrade</dt><dd><p>指定したドライバーを使用するプリンターのクライアントに、ローカルのドライバーバージョンの更新を強制します。smbd にのみ送信できます。</p></dd><dt>reload-config</dt><dd><p>デーモンに smb.conf 設定ファイルの再読み込みを強制します。<code>smbd</code>、<code>nmbd</code>、<code>winbindd</code> に送信できます。</p></dd><dt>reload-printers</dt><dd><p>smbd にプリンターの再読み込みを強制します。<code>smbd</code> にのみ送信できます。</p></dd><dt>idmap</dt><dd><p>ID マッピングの変更を通知します。<code>smbd</code>、または未実装ですが <code>winbindd</code> に送信できます。</p>
<dl><dt>flush [uid|gid]</dt><dd><p>sid &lt;-&gt; gid および/または sid &lt;-&gt; uid マッピングのキャッシュを消去します。</p></dd><dt>delete &lt;ID&gt;</dt><dd><p>キャッシュからマッピングを削除します。&lt;ID&gt; には SID (S-x-...)、GID (&quot;GID number&quot;)、UID (&quot;UID number&quot;) のいずれかを指定します。</p></dd><dt>kill &lt;ID&gt;</dt><dd><p>キャッシュからマッピングを削除します。その ID が現在使用中の場合は <code>smbd</code> を終了します。</p></dd></dl></dd><dt>num-children</dt><dd><p>smbd の子プロセス数を照会します。このメッセージは <code>smbd</code> にのみ送信できます。</p></dd><dt>reload-certs</dt><dd><p>Samba AD DC の LDAP サーバーに、ldaps:// 接続を保護する TLS 証明書の再読み込みを指示します。このメッセージは <code>ldap_server</code> にのみ送信できます。</p></dd></dl>
