### 名前 {#Name}


<p>smbget — SMB経由でファイルをダウンロードするwget風のユーティリティ</p>

### 書式 {#Synopsis}

### 説明 {#DESCRIPTION}


<p>このツールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.7.html">samba(7)</a> スイートの一部です。</p>

<p>smbgetは、wgetに似た使い方でSMBサーバーからファイルをダウンロードできる単純なユーティリティです。ダウンロードするファイルをコマンドラインで指定できます。</p>

<p>ファイルはsmb-URL規格の形式で指定してください。たとえば、UNCパス <em>\\\\HOST\\SHARE\\file</em> にはsmb://host/share/fileを使用します。</p>

### SMB URL {#SMB-URLS}


<p>SMB URLは次の形式で指定してください。</p>

<pre><code>smb://[[[domain;]user[:password@]]server[/share[/path[/file]]]]</code></pre>

<pre><code>smb:// means all the workgroups</code></pre>

<pre><code>smb://name/ means, if name is a workgroup, all the servers in this workgroup, or if name is a server, all the shares on this server.</code></pre>

### 使用例 {#EXAMPLES}


<pre><code># Recursively download &#39;src&#39; directory
smbget --recursive smb://rhonwyn/jelmer/src
# Download FreeBSD ISO and enable resuming
smbget --resume smb://rhonwyn/isos/FreeBSD5.1.iso
# Recursively download all ISOs
smbget --recursive --resume smb://rhonwyn/isos
# Backup my data on rhonwyn
smbget --recursive --resume smb://rhonwyn/</code></pre>

### 不具合 {#BUGS}


<p>エラー原因が不明な場合にも、Permission deniedが返されることがあります（不正な形式のsmb:// URLや、<code>--recursive</code> を有効にせずディレクトリを取得しようとした場合など）。</p>
