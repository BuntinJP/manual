### 名前 {#Name}


<p>vfs_extd_audit — 選択された Samba VFS 操作を記録する</p>

### 書式 {#Synopsis}


<p><code>vfs objects = extd_audit</code></p>

### 説明 {#DESCRIPTION}


<p>この VFS モジュールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.7.html">samba(7)</a> スイートの一部です。</p>

<p><code>extd_audit</code> VFS モジュールは、選択されたクライアント操作を、<a href="https://www.samba.org/samba/docs/current/man-html/smbd.8.html">smbd(8)</a> ログとシステムログ（<a href="https://www.samba.org/samba/docs/current/man-html/syslog.3.html">syslog(3)</a> を使用）の両方に記録します。</p>

<p><a href="https://www.samba.org/samba/docs/current/man-html/smbd.8.html">smbd(8)</a> ログにも記録する点を除き、<code>vfs_extd_audit</code> は <a href="https://www.samba.org/samba/docs/current/man-html/vfs_audit.8.html">vfs_audit(8)</a> と同じです。</p>

<p>このモジュールは、他のモジュールと重ねて使用できます。</p>

### バージョン {#VERSION}


<p>このマニュアルページは、Samba スイートのバージョン 4.25.0 の一部です。</p>
