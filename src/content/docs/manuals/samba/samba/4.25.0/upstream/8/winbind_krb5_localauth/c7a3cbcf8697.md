### 名前 {#Name}


<p>winbind_krb5_localauth — ユーザーアカウントを対応付ける MIT Kerberos 用プラグイン</p>

### 説明 {#DESCRIPTION}


<p>このプラグインは <a href="https://www.samba.org/samba/docs/current/man-html/samba.7.html">samba(7)</a> スイートの一部です。</p>

<p><code>winbind_krb5_localauth</code> は、MIT Kerberos ライブラリーが Kerberos プリンシパルをローカルユーザーアカウントと照合して検証できるようにするプラグインです。</p>

### 前提条件 {#PREREQUISITES}


<p>MIT Kerberos のバージョン 1.12 以降が必要です。</p>

<p>このプラグインは <a href="https://www.samba.org/samba/docs/current/man-html/winbindd.8.html">winbindd(8)</a> デーモンに問い合わせるため、このデーモンを別途設定して起動する必要があります。</p>

<p>次のセクションを <code>krb5.conf</code> ファイルに追加する必要があります。</p>

<pre><code>[plugins]
	localauth = {
		module = winbind:/usr/lib64/samba/krb5/winbind_krb5_localauth.so
		enable_only = winbind
	}</code></pre>
