### 名前 {#Name}


<p>vfs_widelinks — Samba 共有で共有内のファイルシステムのシンボリックリンクを無視する</p>

### 書式 {#Synopsis}


<p><code>vfs objects = widelinks</code></p>

### 説明 {#DESCRIPTION}


<p>この VFS モジュールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.7.html">samba(7)</a> スイートの一部です。</p>

<p><code>vfs_widelinks</code> VFS モジュールは、共有内のファイルシステムに存在するシンボリックリンクを隠します。Samba バージョン 4.13 以降で、以前は smbd 本体のコード内にあった <code>smb.conf</code> の &quot;wide links = yes&quot; 機能を実装するために使用されます。このモジュールは、smb.conf の &quot;vfs objects =&quot; パラメーターで明示的に読み込むべきではなく、&quot;wide links = yes&quot; を有効にすると暗黙に読み込まれます。これは、共有で既存の安全でない &quot;wide links&quot; 機能を維持するために、既存の smb.conf ファイルを変更する必要がないようにするためです。</p>

<p>&quot;wide links = yes&quot; は意図的に安全性を欠くオプションであり、Samba 環境で決して使用すべきではない点に注意してください。Linux では、&quot;wide links = yes&quot; で可能になることはすべて、代わりにバインドマウントで実現できます。このモジュールは、既存の &quot;wide links = yes&quot; 環境の利用者との後方互換性を提供するために作成されましたが、この使用方法は推奨できず、Samba 開発者も支持していません。</p>

<p>この暗黙の読み込みは、将来の Samba リリースで明示的な読み込みになる可能性があります。安全でない &quot;wide links&quot; 機能を維持したい管理者は、&quot;vfs objects =&quot; のモジュール一覧にこのモジュールを追加する必要が生じるかもしれません。この変更が行われる際には、Samba プロジェクトのリリースノートとこのマニュアルページが更新されます。</p>

<p>このモジュールは、他のモジュールと重ねて使用できます。</p>
