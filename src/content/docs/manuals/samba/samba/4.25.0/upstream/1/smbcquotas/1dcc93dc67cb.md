<p>smbcquotas — NTFS 5 共有のクォータを設定または取得する</p>

### 説明 {#DESCRIPTION}


<p>このツールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.7.html">samba(7)</a> スイートの一部です。</p>

<p><code>smbcquotas</code> プログラムは、SMB ファイル共有の NT クォータを操作します。</p>

<p>コマンドラインでパスワードを指定せず、このパラメーターも指定していない場合、クライアントはパスワードを要求します。</p>

<p>スクリプトにパスワードを含めたり、ユーザーが入力した値をコマンドラインへ渡したりする際は注意してください。安全性のため、必要に応じて Samba クライアントツールにパスワードを尋ねさせるか、<code>kinit</code> で一度パスワードを取得する方が適切です。</p>

				password = &lt;value&gt;
				domain   = &lt;value&gt;

### QUOTA\_SET\_COMMAND {#QUOTA_SET_COMMAND}


<p>QUOTA_SET_COMMAND の形式は、操作名に、その操作に固有のパラメーター群を続けたものです。</p>

<p><code>-u</code> で指定したユーザー、または現在のユーザー名に対してユーザークォータを設定するには、次のようにします。</p>

<p><strong><code>UQLIM:&lt;username&gt;:&lt;softlimit&gt;/&lt;hardlimit&gt;</code></strong></p>

<p>共有の既定のクォータを設定するには、次のようにします。</p>

<p><strong><code>FSQLIM:&lt;softlimit&gt;/&lt;hardlimit&gt;</code></strong></p>

<p>共有のクォータ設定を変更するには、次のようにします。</p>

<p><strong><code>FSQFLAGS:QUOTA_ENABLED/DENY_DISK/LOG_SOFTLIMIT/LOG_HARD_LIMIT</code></strong></p>

<p>すべての制限値はバイト数で指定します。</p>

### 終了状態 {#EXIT-STATUS}


<p><code>smbcquotas</code> プログラムは、実行した操作の成否に応じて終了状態を設定します。終了状態は次のいずれかの値になります。</p>

<p>操作が成功すると、smbcquotas は終了状態 0 を返します。<code>smbcquotas</code> が指定したサーバーに接続できなかった場合、またはクォータの取得や設定でエラーが起きた場合は、終了状態 1 を返します。コマンドライン引数の解析でエラーが起きた場合は、終了状態 2 を返します。</p>
