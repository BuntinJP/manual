### 名前 {#Name}


<p>vfs_snapper — snapperが管理するスナップショットをシャドウコピーとして公開する</p>

### 書式 {#Synopsis}


<p><code>vfs objects = snapper</code></p>

### 説明 {#DESCRIPTION}


<p>このVFSモジュールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.8.html">samba(8)</a> スイートの一部です。</p>

<p><code>vfs_snapper</code> VFSモジュールは、snapperが管理するスナップショットをSambaから利用できるように公開します。これにより、リモートのSMBクライアントは、Windowsエクスプローラーの「以前のバージョン」ダイアログからシャドウコピーへアクセスできます。</p>

<p>File Server Remote VSS Protocol（FSRVP）を使用して、スナップショットをリモートで作成・削除することもできます。スナップショットの作成・削除要求は、DBus経由でsnapperに転送されます。</p>

<p>このモジュールは他のモジュールと積み重ねて使用できます。</p>

### 設定 {#CONFIGURATION}


<p>共有の基になるパスに対応するsnapper設定ファイルが必要です。スナップショットのディレクトリツリーでは、対象ユーザーのアクセスを許可する必要があります。</p>

<pre><code>		[share]
		vfs objects = snapper</code></pre>

<p>スナップショットをリモートで作成・削除するには、[global]セクションでSambaのFSRVPサーバーを設定する必要があります。</p>

<pre><code>		[global]
		registry shares = yes
		include = registry</code></pre>

### 権限 {#PERMISSIONS}


<p>Snapperは、.snapshotsサブディレクトリ内にスナップショットを保存します。このディレクトリでは、Windowsエクスプローラーの「以前のバージョン」ダイアログからスナップショットにアクセスするすべてのユーザーに、ディレクトリの通過を許可する必要があります。既定では、root以外のすべてのユーザーに対して通過は禁止されています。さらに、snapperのALLOW_USERSまたはALLOW_GROUPSオプションで、snapperが管理するスナップショットを一覧表示する権限をユーザーに付与する必要があります。SnapperはSYNC_ACLオプションを使って、これらのユーザーとグループに.snapshotsの通過権限を自動的に付与できます。</p>

<p>Sambaがスナップショットのリモート作成・削除を許可するのは、Active Directory管理者、バックアップオペレーター、またはSeBackupPrivilegeを明示的に付与されたユーザーだけです。Snapper側でも、ALLOW_USERSまたはALLOW_GROUPSオプションを使い、該当ユーザーによる作成・削除を許可する必要があります。</p>

<p>DiskShadow.exe FSRVPクライアントは、最初にActive Directoryのコンピューターアカウントとして認証します。そのため、このアカウントにも、スナップショットの作成・削除要求を出すユーザーアカウントと同じ権限を付与する必要があります。</p>
