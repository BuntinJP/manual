### 名前 {#Name}


<p>smbspool — 印刷ファイルを SMB プリンターへ送信する</p>

### 書式 {#Synopsis}


<p><code>smbspool</code> {job} {user} {title} {copies} {options} [filename]</p>

### 説明 {#DESCRIPTION}


<p>このツールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.7.html">samba(7)</a> スイートの一部です。</p>

<p>smbspool は、印刷ファイルを SMB プリンターへ送る非常に小さな印刷スプールプログラムです。Common UNIX Printing System との互換性のためコマンドライン引数は位置で決まりますが、任意の印刷システム、プログラム、スクリプトから使用できます。</p>

<p><em>デバイス URI</em></p>

<p>smbspool は、方式が &quot;smb&quot; の Uniform Resource Identifier（URI）で送信先を指定します。この文字列には次の形式があります。</p>

<ul><li><p>smb://server[:port]/printer</p></li><li><p>smb://workgroup/server[:port]/printer</p></li><li><p>smb://username:password@server[:port]/printer</p></li><li><p>smb://username:password@workgroup/server[:port]/printer</p></li></ul>

<p>smbspool は環境変数 <code>DEVICE_URI</code> から URI を取得しようとします。<code>DEVICE_URI</code> がない場合、argv[0] が “smb://” で始まればそれを使い、そうでなければ argv[1] を使います。</p>

<p><code>exec(2)</code> 関数を使うプログラムは argv[0] に URI を渡せますが、シェルスクリプトは smbspool の実行前に <code>DEVICE_URI</code> 環境変数を設定する必要があります。</p>

### オプション {#OPTIONS}


<ul><li><p>job 引数（argv[1]）にはジョブID番号を指定しますが、現在 smbspool は使用しません。</p></li><li><p>user 引数（argv[2]）には印刷ユーザー名を指定します。現在、Kerberos 環境でユーザーのチケットキャッシュにアクセスする場合を除き、smbspool は使用しません。</p></li><li><p>title 引数（argv[3]）にはジョブのタイトル文字列を指定し、印刷ジョブの送信時にリモートファイル名として渡されます。</p></li><li><p>copies 引数（argv[4]）には指定ファイルの印刷部数を指定します。ファイル名を指定しない場合、smbspool はこの引数を使用しません。</p></li><li><p>options 引数（argv[5]）には印刷オプションを単一の文字列で指定しますが、現在 smbspool は使用しません。</p></li><li><p>filename 引数（argv[6]）には印刷するファイル名を指定します。省略すると、印刷ファイルを標準入力から読み取ります。</p></li></ul>
