### 名前 {#Name}


<p>vfs_readahead — カーネルのバッファーキャッシュに事前読み込みする</p>

### 書式 {#Synopsis}


<p><code>vfs objects = readahead</code></p>

### 説明 {#DESCRIPTION}


<p>この VFS モジュールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.7.html">samba(7)</a> スイートの一部です。</p>

<p>この <code>vfs_readahead</code> VFS モジュールは、指定したオフセット（既定は16進数0x80000）の倍数の位置での読み取り要求を検出し、readahead システムコール（Linux）または posix_fadvise システムコールを通じて、そのデータをバッファーキャッシュに先読みするようカーネルに指示します。</p>

<p>このモジュールは、Windows Explorer でデータを読み取る Windows Vista クライアントに役立ちます。Explorer は0x80000バイト境界で複数のファイル読み取り要求を非同期に行います。</p>

<p>オフセットの倍数の基準値は readahead:offset オプションで指定し、既定値は0x80000です。</p>

<p><code>vfs_readahead</code> が行うディスク読み取りのサイズは readahead:length オプションで決まります。既定では readahead:offset と同じ値で、明示的に設定しなければ readahead:offset の現在の値を使います。</p>

<p>このモジュールは他のモジュールと積み重ねて使用できます。</p>

### オプション {#OPTIONS}


<p>BYTES には次の接尾辞を付けられます。</p>

<ul><li><p><code>K</code> - BYTES はキロバイト数です。</p></li><li><p><code>M</code> - BYTES はメガバイト数です。</p></li><li><p><code>G</code> - BYTES はギガバイト数です。</p></li></ul>

<dl><dt>readahead:offset = BYTES</dt><dd><p>カーネルのバッファーキャッシュへの先読み要求を発生させるオフセットの倍数の基準値です。</p></dd><dt>readahead:length = BYTES</dt><dd><p>各 readahead 呼び出しで、カーネルのバッファーキャッシュへ読み込むよう要求するバイト数です。</p></dd></dl>
