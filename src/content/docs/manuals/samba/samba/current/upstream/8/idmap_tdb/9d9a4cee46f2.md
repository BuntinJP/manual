### 名前 {#Name}


<p>idmap_tdb — Winbind 用の Samba idmap_tdb バックエンド</p>

### 説明 {#DESCRIPTION}


<p>idmap_tdb プラグインは、winbindd が SID/uid/gid マッピングテーブルの保存に使用する既定のバックエンドです。</p>

<p>idmap_rid のような読み取り専用バックエンドとは異なり、これは ID を割り当てるバックエンドです。つまり、新しいマッピングを作成するには、新しいユーザー ID とグループ ID を割り当てる必要があります。</p>

### IDMAP オプション {#IDMAP-OPTIONS}


<dl><dt>range = low - high</dt><dd><p>このバックエンドが管理を担当する、利用可能な uid と gid の対応付け範囲を定義します。</p></dd></dl>

### 使用例 {#EXAMPLES}


<p>この例は、tdb を既定の idmap バックエンドとして使用する方法を示します。設定した範囲は uid と gid の割り当てに使用されます。</p>

<pre><code>	[global]
	# &quot;backend = tdb&quot; is redundant here since it is the default
	idmap config * : backend = tdb
	idmap config * : range = 1000000-2000000</code></pre>
