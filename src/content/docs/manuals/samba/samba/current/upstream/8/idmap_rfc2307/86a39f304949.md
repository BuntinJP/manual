### 名前 {#Name}


<p>idmap_rfc2307 — Winbind 用の Samba idmap_rfc2307 バックエンド</p>

### 説明 {#DESCRIPTION}


<p>idmap_rfc2307 プラグインは、RFC 2307 で定義された LDAP サーバーのレコードから winbind が ID 対応付けを読み取れるようにします。LDAP サーバーは単独のものでも、AD サーバーが提供するものでも構いません。名前と SID の対応付けには常に AD サーバーが必要で、名前と UID/GID の対応付けを LDAP サーバーに問い合わせます。このモジュールは &quot;idmap&quot; API だけを実装し、読み取り専用です。</p>

<p>管理者は事前に、Active Directory サーバーにユーザーアカウントを作成し、LDAP サーバーに posixAccount と posixGroup オブジェクトを作成して、対応付けを用意する必要があります。Active Directory と LDAP サーバーの名前は同じでなければなりません。</p>

<p>この ID 対応付け方式により、RFC 2307 形式のレコードを保存する既存の LDAP 認証サーバーを再利用できます。</p>

<p>AD サーバーが提供する LDAP サーバーに接続する場合、SSL を使うかどうかは <a href="https://www.samba.org/samba/docs/current/man-html/smb.conf.5.html#LDAPSSLADS">ldap ssl ads</a> パラメーターで決まります。単独の LDAP サーバーでは <a href="https://www.samba.org/samba/docs/current/man-html/smb.conf.5.html#LDAPSSL">ldap ssl</a> が適用されます。</p>

### IDMAP オプション {#IDMAP-OPTIONS}


<dl><dt>range = low - high</dt><dd><p>このバックエンドが管理する、対応付け可能な UID/GID の範囲を定義します。この範囲はフィルターとして働きます。指定した場合、AD 内の UID/GID が範囲外なら無視し、その対応付けを破棄します。ローカルとリモートで定義された ID の意図しない重複を防ぐためのものです。</p></dd><dt>ldap_server = &lt;ad | stand-alone &gt;</dt><dd><p>使用する LDAP サーバーの種類を定義します。Active Directory サーバーが提供する LDAP サーバー（ad）、または単独の LDAP サーバーを指定できます。</p></dd><dt>bind_path_user</dt><dd><p>LDAP サーバーでユーザーオブジェクトを探す検索ベースを指定します。</p></dd><dt>bind_path_group</dt><dd><p>LDAP サーバーでグループオブジェクトを探す検索ベースを指定します。</p></dd><dt>user_cn = &lt;yes | no&gt;</dt><dd><p>LDAP のユーザー名について、uid 属性ではなく cn 属性を問い合わせます。このオプションは必須ではなく、既定値は no です。</p></dd><dt>realm</dt><dd><p>LDAP クエリーでグループ（および user_cn を設定した場合のユーザー）の cn に @realm を追加します。このオプションは必須ではなく、既定では realm を追加しません。</p></dd><dt>ldap_domain</dt><dd><p>Active Directory サーバー内の LDAP サーバーを使う場合、アクセスする Active Directory サーバーのドメインを指定できます。これにより、RFC 2307 レコードを1か所に保持したまま信頼関係を利用できます。このパラメーターは省略可能で、既定では現在のドメインの AD サーバーにアクセスして LDAP レコードを問い合わせます。</p></dd><dt>ldap_url</dt><dd><p>単独の LDAP サーバーを使う場合、このパラメーターはサーバーにアクセスする LDAP URL を指定します。</p></dd><dt>ldap_user_dn</dt><dd><p>認証に使うユーザー DN を定義します。このユーザーの認証用シークレットは net idmap secret で保存してください（<a href="https://www.samba.org/samba/docs/current/man-html/net.8.html">net(8)</a> を参照）。省略すると匿名バインドを行います。</p></dd></dl>

### 例 {#EXAMPLES}


<p>次の例は、単独の LDAP サーバーから ID 対応付けを取得する方法を示します。また、BUILTIN などの内部バックエンドで使えるローカル ID 割り当て用に、競合しない小さな範囲を残す方法も示します。</p>

<pre><code>	[global]
	idmap config * : backend = tdb
	idmap config * : range = 1000000-1999999

	idmap config DOMAIN : backend = rfc2307
	idmap config DOMAIN : range = 2000000-2999999
	idmap config DOMAIN : ldap_server = stand-alone
	idmap config DOMAIN : ldap_url = ldap://ldap1.example.com
	idmap config DOMAIN : ldap_user_dn = cn=ldapmanager,dc=example,dc=com
	idmap config DOMAIN : bind_path_user = ou=People,dc=example,dc=com
	idmap config DOMAIN : bind_path_group = ou=Group,dc=example,dc=com</code></pre>
