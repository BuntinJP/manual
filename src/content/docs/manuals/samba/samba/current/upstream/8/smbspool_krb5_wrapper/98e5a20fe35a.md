### 名前 {#Name}


<p>smbspool_krb5_wrapper — smbspool を呼び出す CUPS 印刷バックエンド</p>

### 書式 {#Synopsis}


<p><code>smbspool_krb5_wrapper</code> {job} {user} {title} {copies} {options} [filename]</p>

### 説明 {#DESCRIPTION}


<p>このツールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.7.html">samba(7)</a> スイートの一部です。</p>

<p>smbspool_krb5_wrapper は、Kerberos 資格情報を使って印刷するためのツールです。動作させるには、smbspool_krb5_wrapper を CUPS の smb バックエンドにする必要があります。所有者は root でなければならず、バイナリーのアクセス権は 0700 にする必要があります。smbspool_krb5_wrapper は、印刷しようとしているユーザーに切り替えた後、smbspool を実行します。ユーザーが直接呼び出すべきではありません。</p>
