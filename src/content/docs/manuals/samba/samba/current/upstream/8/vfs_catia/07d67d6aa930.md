### 名前 {#Name}


<p>vfs_catia — Catia のファイル名に含まれる不正な文字を変換する</p>

### 書式 {#Synopsis}


<p><code>vfs objects = catia</code></p>

### 説明 {#DESCRIPTION}


<p>この VFS モジュールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.7.html">samba(7)</a> スイートの一部です。</p>

<p>Catia CAD パッケージは、CIFS のファイル名では使用できない文字を含むファイル名をよく作成します。<code>vfs_catia</code> VFS モジュールは文字の対応付けを実装し、これらのファイルを CIFS クライアントと共有できるようにします。</p>

<p>このモジュールはスタック可能です。</p>

<p>パラメーター &quot;catia:mappings&quot; は、文字単位の対応付けを指定します。以下を参照してください。</p>

### オプション {#OPTIONS}


<dl><dt>catia:mappings = SERVER_HEX_CHAR:CLIENT_HEX_CHAR</dt><dd><p>SERVER_HEX_CHAR は 0x を接頭辞に持つ 16 進の文字コードを指定します。Samba サーバー側のファイル名にこの文字が含まれると、CIFS クライアントに対して CLIENT_HEX_CHAR に対応付けられます。</p>
<p>逆方向にも同じ対応付けが行われます。複数の文字の対応付けはコンマで区切ります。</p></dd></dl>

### 使用例 {#EXAMPLES}


<p>[CAD] 共有のファイル名で、サーバー側の引用符 (&quot;) をクライアント側の分音記号 (¨) に対応付けます。</p>

<pre><code>        [CAD]
	path = /data/cad
	vfs objects = catia
	catia:mappings = 0x22:0xa8</code></pre>

<p>Catia のファイル名で一般的に使われる文字を包括的に対応付けます。</p>

<pre><code>        [CAD]
	path = /data/cad
	vfs objects = catia
	catia:mappings = 0x22:0xa8,0x2a:0xa4,0x2f:0xf8,0x3a:0xf7,0x3c:0xab,0x3e:0xbb,0x3f:0xbf,0x5c:0xff,0x7c:0xa6</code></pre>

<p>変換対象のサーバー側ファイル名（ここではパス区切り文字 &quot;/&quot; を使用していない点に注意してください）:</p>

<p>a\a:a*a?a&quot;a&lt;a&gt;a|a</p>

<p>クライアントから見える変換後のファイル名:</p>

<p>aÿa÷a¤a¿a¨a«a»a¦a</p>

### 注意事項 {#CAVEATS}


<p>一意で実在するファイル名を得るには、文字の対応付けが両方向（サーバー -&gt; クライアント、およびクライアント -&gt; サーバー）で機能しなければなりません。</p>

<p>機能しない例:</p>

<pre><code>        [CAD]
	path = /data/cad
	vfs objects = catia
	catia:mappings = 0x3a:0x5f</code></pre>

<p>ここではコロン &quot;:&quot; をアンダースコア &quot;_&quot; に対応付けています。</p>

<p>サーバー側のファイル名が &quot;a:should_work&quot; で、クライアントには &quot;a_should_work&quot; に変換されるとします。</p>

<p>しかし、クライアントの &quot;a_should_work&quot; からサーバーへの逆変換では &quot;a:should:work&quot; になり、&quot;file not found&quot; のようなエラーが返されます。</p>
