### 名前 {#Name}


<p>cifsdd — SMB 経由でファイルを変換してコピーする</p>

### 書式 {#Synopsis}


<p><code>cifsdd</code> [OPERAND]...</p>

<p><code>cifsdd</code> OPTION</p>

### 説明 {#DESCRIPTION}


<p>このツールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.7.html">samba(7)</a> スイートの一部です。</p>

<p>オペランドに従って変換と整形を行いながら、ファイルをコピーします。</p>

<dl><dt>bs=BYTES</dt><dd><p>一度に最大 BYTES バイトを読み書きします（既定値: 4096）</p></dd><dt>ibs=BYTES</dt><dd><p>一度に最大 BYTES バイトを読み込みます（既定値: 4096）</p></dd><dt>obs=BYTES</dt><dd><p>一度に BYTES バイトを書き込みます（既定値: 4096）</p></dd><dt>if=FILE</dt><dd><p>標準入力の代わりに FILE から読み込みます</p></dd><dt>of=FILE</dt><dd><p>標準出力の代わりに FILE に書き込みます</p></dd><dt>count=N</dt><dd><p>入力ブロックを N 個だけコピーします</p></dd><dt>seek=N</dt><dd><p>出力の先頭で obs サイズのブロックを N 個飛ばします</p></dd><dt>skip=N</dt><dd><p>入力の先頭で ibs サイズのブロックを N 個読み飛ばします</p></dd><dt>direct</dt><dd><p>データに直接 I/O を使用します</p></dd><dt>sync</dt><dd><p>同期書き込みを使用します</p></dd><dt>oplock</dt><dd><p>入力ファイルと出力ファイルに oplock を取得します</p></dd></dl>
