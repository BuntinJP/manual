### 名前 {#Name}


<p>smb_prometheus_endpoint — Samba のプロファイリング情報を Prometheus から利用できるようにする</p>

### 書式 {#Synopsis}


<p><code>smb_prometheus_endpoint</code> [<code>-a</code> ADDRESS] [<code>-p</code> PORT] [smbprofile.tdb]</p>

### 説明 {#DESCRIPTION}


<p>このツールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.8.html">samba(8)</a> スイートの一部です。</p>

<p>Samba のプロファイリング情報を HTTP 経由で Prometheus から利用できるようにします。</p>

### オプション {#OPTIONS}


<dl><dt><code>-a</code> ADDRESS</dt><dd><p><code>smb_prometheus_endpoint</code> が待ち受けるアドレスです。既定は 127.0.0.1 です。</p></dd><dt><code>-p</code> PORT</dt><dd><p><code>smb_prometheus_endpoint</code> が待ち受けるポートです。既定のポートは 9922 です。</p></dd><dt>smbprofile.tdb</dt><dd><p>Samba が統計情報を保存する、システムの smbprofile.tdb のフルパスです。</p></dd></dl>
