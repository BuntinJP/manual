### 名前 {#Name}


<p>vfs_acl_tdb — NTFS ACL を tdb ファイルに保存する</p>

### 書式 {#Synopsis}


<p><code>vfs objects = acl_tdb</code></p>

### 説明 {#DESCRIPTION}


<p>この VFS モジュールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.7.html">samba(7)</a> スイートの一部です。</p>

<p><code>vfs_acl_tdb</code> VFS モジュールは NTFS アクセス制御リスト (ACL) を tdb ファイルに保存します。これにより、Samba サーバー上で Windows ACL を完全に対応付けることができます。</p>

<p>ACL の設定は <code>$LOCKDIR/file_ntacls.tdb</code> に保存されます。</p>

<p>このモジュールは次のパラメーターを強制します。</p>

<ul><li><p>inherit acls = true</p></li><li><p>dos filemode = true</p></li><li><p>force unknown acl user = true</p></li></ul>

<p>このモジュールはスタック可能です。</p>

### オプション {#OPTIONS}


<dl><dt>acl_tdb:ignore system acls = [yes|no]</dt><dd><p><em>yes</em> に設定すると、このモジュールは POSIX ACL 層との間で可能な限りの対応付けを行い<em>ません</em>。既定値は <em>no</em> で、Samba はシステム ACL と NT ACL の両方を設定・評価し続けます。ローカルアクセスや NFS によるファイルアクセスのためにもシステム ACL を設定する必要がある場合には、こちらが適しています。Samba 経由でしかデータにアクセスしない場合は、yes に設定すると NT ACL との互換性を向上できる可能性があります。</p>
<p><em>acl_tdb:ignore system acls</em> を <em>yes</em> に設定すると、次の追加設定が強制されます。</p>
<ul><li><p>create mask = 0666</p></li><li><p>directory mask = 0777</p></li><li><p>map archive = no</p></li><li><p>map hidden = no</p></li><li><p>map readonly = no</p></li><li><p>map system = no</p></li><li><p>store dos attributes = yes</p></li></ul></dd><dt>acl_tdb:default acl style = [posix|windows|everyone]</dt><dd><p>このパラメーターは、ファイルまたはディレクトリーに <em>security.NTACL</em> 拡張属性がない場合に合成する ACL の種類を決定します。</p>
<p><em>posix</em> に設定すると、ユーザー、グループ、その他の POSIX モード権限に基づいて ACL を合成し、完全な権限を持つ <em>NT Authority\SYSTEM</em> の ACE を追加します。</p>
<p><em>windows</em> に設定すると、Windows と同じ方法で ACL を合成し、所有者と <em>NT Authority\SYSTEM</em> の権限のみを含めます。</p>
<p><em>everyone</em> に設定すると、everyone (S-1-1-0) に完全な権限を付与する ACL を合成します。</p>
<p>このオプションの既定値は <em>posix</em> です。</p></dd></dl>
