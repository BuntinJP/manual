### 名前 {#Name}


<p>idmap_hash — このバックエンドは使用しないでください</p>

### 説明 {#DESCRIPTION}


<p>このプラグインは使用しないでください。idmap_hash プラグインは、ドメインユーザーとグループの SID を、それぞれ 31 ビットの uid と gid に対応付けるハッシュアルゴリズムを実装しています。このプラグインは nss_info API も実装しており、<code>${prefix}/etc/smb.conf</code> の &quot;winbind normalize names&quot; パラメーターと &quot;winbind nss info&quot; パラメーターで有効にすると、ローカルの名前マッピングファイルをサポートできます。このモジュールは、idmap 設定が扱うドメインごとに範囲を部分範囲へ分割します。すべての SID を対応付けるには、UID と GID の範囲全体が必要です。範囲の下限は、システムで利用可能な最小の ID にする必要があります。通常は 1000 です。最大の ID は 2147483647 に設定してください。使用しているハッシュアルゴリズムのため、これより小さい範囲は問題を引き起こします。すべての SID を対応付けるための全範囲は 0 - 2147483647 です。0 - 2147483647 より小さい範囲では、一部の SID が除外されます。通常は 1000 からしか開始できないため、1000 個の SID を対応付けることができません。これだけでも問題が起こる可能性があります。範囲が小さいほど、対応付けられる SID は少なくなります。このプラグインの使用は推奨しません。Samba の将来のリリースで削除される予定です。</p>

### IDMAP オプション {#IDMAP-OPTIONS}


<dl><dt>name_map</dt><dd><p>nss_info API が使用する名前マッピングファイルの絶対パスを指定します。ファイルのエントリーは &quot;<em><code>unix name</code></em> = <em><code>qualified domain name</code></em>&quot; という形式です。ユーザー名とグループ名の両方のマッピングをサポートしています。</p></dd></dl>

### 使用例 {#EXAMPLES}


<p>次の例は、idmap と nss_info の情報に idmap_hash プラグインを使用します。</p>

<pre><code>	[global]
	idmap config * : backend = hash
	idmap config * : range = 1000-2147483647

	winbind nss info = hash
	winbind normalize names = yes
	idmap_hash:name_map = /etc/samba/name_map.cfg</code></pre>
