## smbinfo {#smbinfo}


### Linux SMB クライアントファイルシステム \(CIFS\) 向けに SMB 固有のファイル情報を表示するユーザー空間ヘルパー {#Userspace-helper-to-display-SMB-specific-file-information-for-the-Linux-SMB-client-file-system--CIFS}


<dl><dt>マニュアルセクション:</dt><dd><p>1</p></dd></dl>

#### 書式 {#SYNOPSIS}


<blockquote><p>smbinfo [<code>-v</code>] [<code>-h</code>] [<code>-V</code>] {command} {file system object}</p></blockquote>

#### 説明 {#DESCRIPTION}


<p>このツールは cifs-utils スイートの一部です。</p>

<p>smbinfo は Linux SMB クライアントファイルシステム (CIFS) 用のユーザー空間ヘルパープログラムです。セキュリティ記述子やクォータなど、SMB 固有のファイル情報を表示するためのものです。</p>

<p>このツールは Linux SMB クライアントに CIFS_QUERY_INFO IOCTL を呼び出し、クライアントが SMB Query Info 要求を発行して結果を返すことで動作します。拡張ファイル属性を使用する getcifsacl とは異なります。</p>

#### オプション {#OPTIONS}


<dl><dt><code>-v</code></dt><dd><p>バージョン番号を表示して終了します。</p></dd><dt><code>-V</code></dt><dd><p>詳細な出力。</p></dd><dt><code>-h</code></dt><dd><p>コマンドラインオプションを説明するヘルプを表示します。</p></dd></dl>

#### コマンド {#COMMAND}


<p>fileaccessinfo: FileAccessInformation クラスを表示します</p>

<p>filealigninfo: FileAlignmentInformation クラスを表示します</p>

<p>fileallinfo: FileAllInformation クラスを表示します</p>

<p>filealternatenameinfo: FileAlternateNameInformation クラスを表示します</p>

<p>filebasicinfo: FileBasicInformation クラスを表示します</p>

<p>fileeainfo: FileEaInformation クラスを表示します</p>

<p>filefsfullsizeinfo: FileFsFullSizeInformation クラスを表示します</p>

<p>fileinternalinfo: FileInternalInformation クラスを表示します</p>

<p>filemodeinfo: FileModeInformation クラスを表示します</p>

<p>filenormalizednameinfo: FileNormalizedNameInformation クラスを表示します</p>

<p>filepositioninfo: FilePositionInformation クラスを表示します</p>

<p>filestandardinfo: FileStandardInformation クラスを表示します</p>

<p>filestreaminfo: FileStreamInformation クラスを表示します</p>

<p>filecompressioninfo: FileCompressionInformation クラスを表示します</p>

<p>fsctl-getobjid: ObjectID を表示します</p>

<p>getcompression: ファイルの圧縮設定を表示します。</p>

<p>setcompression <code>-c</code> &lt;no|default|lznt1&gt;: ファイルの圧縮設定を設定します。</p>

<p>list-snapshots: このファイルを格納するボリュームの以前のバージョンを一覧表示します</p>

<p>quota: ボリュームのクォータを、SID の長さ - 変更時刻 - 使用クォータ - クォータしきい値 - クォータ上限 - SID の形式で表示します</p>

<p>secdesc: セキュリティ記述子を、リビジョン - 制御 - 所有者 SID - グループ SID - ACL - ファイルの種類 - ファイルフラグの形式で表示します</p>

<p>keys: このマウントの SMB3 トラフィックを、たとえば Wireshark で復号できるように、セッション ID、暗号化キー、復号キーをダンプします（root が必要）。</p>

<p>gettconinfo: cifs ファイルの TCON Id と Session Id の両方を表示します。</p>

<p>notify: ディレクトリーの変更通知を照会します。</p>

#### 注記 {#NOTES}


<p>smbinfo ユーティリティーのカーネルサポートには、カーネル 4.20 で初めて導入された CIFS_QUERY_INFO IOCTL が必要です。これは SMB2 以降を使用するマウントポイントにのみ実装されています（mount.cifs(8) の vers オプションを参照）。</p>
