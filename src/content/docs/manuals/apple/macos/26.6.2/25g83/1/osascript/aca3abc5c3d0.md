## 名称 {#NAME}

## 解説 {#DESCRIPTION}


<p><code>osascript</code>は、指定されたOSAスクリプトを実行します。スクリプトには、プレーンテキストか、スクリプトエディタまたは<code>osacompile(1)</code>で作成したコンパイル済みスクリプト（<code>.scpt</code>）を指定できます。デフォルトでは、<code>osascript</code>はプレーンテキストをAppleScriptとして扱いますが、<code>-l</code>オプションで変更できます。システムにインストールされているOSA言語の一覧を取得するには、<code>osalang(1)</code>を使用します。</p>

<p><code>osascript</code>は、次の3か所のいずれかからスクリプトを探します。</p>

<ol><li><p>コマンドラインの<code>-e</code>スイッチを使用して、1行ずつ指定したスクリプト。</p></li><li><p>コマンドラインで最初に指定したファイル名のファイルに格納されたスクリプト。このファイルには、プレーンテキストまたはコンパイル済みスクリプトを使用できます。</p></li><li><p>標準入力から渡されたスクリプト。これは、ファイル名引数がない場合にのみ機能します。標準入力から読み取るスクリプトに引数を渡すには、スクリプト名として「-」を明示的に指定する必要があります。</p></li></ol>

<p>スクリプトに続く引数はすべて、文字列のリストとして「run」ハンドラの直接パラメータに渡されます。たとえば、AppleScriptでは次のようになります。</p>

<pre><code>a.scpt:
on run argv
    return &quot;hello, &quot; &amp; item 1 of argv &amp; &quot;.&quot;
end run

% osascript a.scpt world
hello, world.</code></pre>

<p>オプションは次のとおりです。</p>

<dl><dt><code>-e</code> <em>statement</em></dt><dd><p>スクリプトを1行入力します。<code>-e</code>を指定すると、<code>osascript</code>は引数リストからファイル名を探しません。複数の<code>-e</code>オプションを指定して、複数行のスクリプトを組み立てることができます。ほとんどのスクリプトでは、多くのシェルプログラムにとって特殊な文字（たとえば、AppleScriptでは一重引用符、二重引用符、「(」、「)」、「*」）を使用するため、文を壊さずにシェルへ渡すには、引用符とエスケープを正しく使用する必要があります。</p></dd><dt><code>-i</code></dt><dd><p>対話モード：<code>osascript</code>は1行ずつ入力を求め、該当する場合は各行の後に結果を表示します。<code>-e</code>または<em>programfile</em>を使用してコマンド引数として指定したスクリプトは、対話プロンプトを開始する前に読み込まれますが、実行はされません。</p></dd><dt><code>-l</code> <em>language</em></dt><dd><p>すべてのプレーンテキストファイルに使用する言語を上書きします。通常、プレーンテキストファイルはAppleScriptとしてコンパイルされます。</p></dd><dt><code>-s</code> <em>flags</em></dt><dd><p>出力形式を変更します。<em>flags</em>引数は、修飾文字<code>e</code>、<code>h</code>、<code>o</code>、<code>s</code>の任意の組み合わせからなる文字列です。複数の修飾子を同じ文字列に連結でき、複数の<code>-s</code>オプションも指定できます。修飾子は互いに排他的なペアになっています。競合する修飾子を指定した場合は、最後の修飾子が優先されます。各修飾文字の意味は次のとおりです。</p>
<ul><li><dl><dt><code>h</code></dt><dd><p>値を人間が読みやすい形式で表示します（デフォルト）。</p></dd><dt><code>s</code></dt><dd><p>値を再コンパイル可能なソース形式で表示します。</p>
<p><code>osascript</code>は通常、結果を人間が読みやすい形式で表示します。文字列を引用符で囲まず、文字をエスケープせず、リストやレコードの波括弧を省略する、といった形式です。この形式は一般により便利ですが、曖昧さが生じる場合があります。たとえば、リスト「<code>{&quot;foo&quot;, &quot;bar&quot;}</code>」と「<code>{{&quot;foo&quot;, {&quot;bar&quot;}}}</code>」は、どちらも「<code>foo, bar</code>」と表示されます。同じ値へ再コンパイルできる曖昧さのない形式で結果を表示するには、<code>s</code>修飾子を使用します。</p></dd></dl></li><li><dl><dt><code>e</code></dt><dd><p>スクリプトエラーを標準エラー出力に表示します（デフォルト）。</p></dd><dt><code>o</code></dt><dd><p>スクリプトエラーを標準出力に表示します。</p>
<p><code>osascript</code>は通常、スクリプトエラーを標準エラー出力に表示するため、後段のクライアントには有効な結果だけが見えます。ただし、自動テストを実行する場合は、<code>o</code>修飾子を使用すると、照合対象であるスクリプトエラーと、照合対象ではないその他の診断出力とを区別できます。</p></dd></dl></li></ul></dd></dl>

## 歴史 {#HISTORY}


<p>Mac OS X 10.0の<code>osascript</code>は、出力内の「\r」文字を「\n」に変換し、この動作を変更する<code>-s</code>オプションの修飾子<code>c</code>と<code>r</code>を提供していました。現在の<code>osascript</code>は常に出力をそのままにします。必要であれば、<code>tr(1)</code>へパイプで渡してください。</p>

<p>Mac OS X 10.4より前の<code>osascript</code>では、スクリプトに引数を渡すことができませんでした。</p>
