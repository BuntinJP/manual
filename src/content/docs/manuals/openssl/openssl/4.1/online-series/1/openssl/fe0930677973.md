## openssl¶ {#openssl}


### 名前¶ {#name}


<p>openssl - OpenSSLコマンドラインプログラム</p>

### 書式¶ {#synopsis}


<p><strong>openssl</strong> <em>command</em> [ <em>options</em> ... ] [ <em>parameters</em> ... ]</p>

<p><strong>openssl</strong> <strong>no-</strong><em>XXX</em> [ <em>options</em> ]</p>

<p><strong>openssl</strong> <strong><code>-help</code></strong> | <strong><code>-version</code></strong></p>

### 説明¶ {#description}


<p>OpenSSLは、Secure Sockets Layer（SSL）およびTransport Layer Security（TLS）ネットワークプロトコルと、それらに必要な関連暗号標準を実装した暗号ツールキットです。</p>

<p><strong>openssl</strong>プログラムは、OpenSSLの<strong>crypto</strong>ライブラリのさまざまな暗号機能をシェルから使用するためのコマンドラインプログラムです。次の用途に使用できます。</p>

<pre><code>o  Creation and management of private keys, public keys and parameters
o  Public key cryptographic operations
o  Creation of X.509 certificates, CSRs and CRLs
o  Calculation of Message Digests and Message Authentication Codes
o  Encryption and Decryption with Ciphers
o  SSL/TLS Client and Server Tests
o  Handling of S/MIME signed or encrypted mail
o  Timestamp requests, generation and verification</code></pre>

### コマンドの概要¶ {#command-summary}


<p><strong>openssl</strong>プログラムは、多様なコマンド（前述の <a href="#synopsis">&quot;SYNOPSIS&quot;</a> にある<em>command</em>）を提供します。各コマンドは多数のオプションと引数パラメーターを持つことができ、上ではそれぞれ<em>options</em>と<em>parameters</em>として示しています。</p>

<p>ほとんどの標準サブコマンドには、詳しい説明と使用例が用意されています（<a href="https://docs.openssl.org/4.1/man1/openssl-x509/">openssl-x509(1)</a> など）。サブコマンドの一覧表示には <a href="https://docs.openssl.org/4.1/man1/openssl-list/">openssl-list(1)</a> を使用できます。</p>

<p><strong>no-</strong><em>XXX</em>コマンドは、指定した名前のコマンドが利用可能かどうかを調べます。<em>XXX</em>という名前のコマンドが存在しない場合は、0（成功）を返して<strong>no-</strong><em>XXX</em>を出力します。存在する場合は1を返して<em>XXX</em>を出力します。いずれの場合も出力先は<strong>stdout</strong>で、<strong>stderr</strong>には何も出力しません。追加のコマンドライン引数は常に無視します。各暗号には同名のコマンドがあるため、シェルスクリプトから<strong>openssl</strong>プログラムで暗号が利用可能かどうかを簡単に調べられます。（<strong>no-</strong><em>XXX</em>は、<strong>quit</strong>、<strong>list</strong>、<strong>no-</strong><em>XXX</em>自体などの疑似コマンドを検出できません。）</p>

#### 設定オプション¶ {#configuration-option}


<p>多くのコマンドでは、引数の一部または全部に外部設定ファイルを使用し、そのファイルを指定する<strong><code>-config</code></strong>オプションを備えています。既定のファイル名は、既定の証明書保存領域内の <code>openssl.cnf</code> です。この領域は、<a href="https://docs.openssl.org/4.1/man1/openssl-version/">openssl-version(1)</a> コマンドの<strong><code>-d</code></strong>または<strong><code>-a</code></strong>オプションで確認できます。環境変数<strong>OPENSSL_CONF</strong>を使うと、別のファイルの場所を指定したり、空文字列を指定して設定の読み込みを無効にしたりできます。</p>

<p>設定ファイルは、モジュールの読み込みや、証明書・乱数を生成するためのパラメーターの指定などに使用できます。詳細は <a href="https://docs.openssl.org/4.1/man5/config/">config(5)</a> を参照してください。</p>

#### 乱数状態オプション¶ {#random-state-options}


<p>OpenSSL 1.1.1より前は、乱数生成器の状態に関する情報をファイルに保存し、起動時に読み込んで終了時に書き直すことが一般的でした。現在のオペレーティングシステムでは、OSが提供する信頼できるエントロピー源からOpenSSL自身がシードを得るため、通常はこの処理は不要です。ただし、これを必要とする特殊なプラットフォームや状況のため、これらのフラグは引き続きサポートされています。</p>

<p>通常、同じシードファイルを複数回使うのは誤りです。<strong><code>-rand</code></strong>を使う場合は、その都度<strong><code>-writerand</code></strong>と組み合わせてください。</p>

<ul><li><p><strong><code>-rand</code></strong> <em>files</em></p>
<p>乱数生成器のシードに使用するランダムデータを含む、1つまたは複数のファイルです。OS依存の文字で区切って複数のファイルを指定できます。区切り文字は、MS-Windowsでは <code>;</code>、OpenVMSでは <code>,</code>、その他では <code>:</code> です。このフラグを異なるファイル名で繰り返し指定しても、複数のファイルを指定できます。</p></li><li><p><strong><code>-writerand</code></strong> <em>file</em></p>
<p>終了時に、指定した<em>file</em>へシードデータを書き込みます。このファイルは、次回のコマンド実行で使用できます。</p></li></ul>

#### TLSバージョンオプション¶ {#tls-version-options}


<p>いくつかのコマンドはSSL、TLS、DTLSを使用します。既定ではTLSを使用し、クライアントはサポートする最小と最大のプロトコルバージョンを提示します。サーバーは、クライアントが提示し、サーバー自身もサポートするバージョンのうち、最も高いものを選択します。</p>

<p>次のオプションを使うと、使用するプロトコルバージョンと、TCP（SSLおよびTLS）またはUDP（DTLS）のどちらを使用するかを制限できます。OpenSSLのビルド方法によっては、すべてのプロトコルとフラグが利用できるとは限りません。</p>

<ul><li><p><strong><code>-tls1</code></strong>, <strong><code>-tls1_1</code></strong>, <strong><code>-tls1_2</code></strong>, <strong><code>-tls1_3</code></strong>, <strong><code>-no_ssl3</code></strong>, <strong><code>-no_tls1</code></strong>, <strong><code>-no_tls1_1</code></strong>, <strong><code>-no_tls1_2</code></strong>, <strong><code>-no_tls1_3</code></strong></p>
<p>これらのオプションは、指定したSSLまたはTLSプロトコルの使用を必須にするか、無効にします。特定のTLSバージョンを必須にすると、そのバージョンだけを提示または受け付けます。特定のプロトコルは1つだけ指定でき、どの<strong>no_</strong>オプションとも併用できません。<strong>no_*</strong>オプションは<strong>s_time</strong>と<strong>ciphers</strong>コマンドでは機能しませんが、<strong>s_client</strong>と<strong>s_server</strong>では機能します。</p></li><li><p><strong><code>-dtls</code></strong>, <strong><code>-dtls1</code></strong>, <strong><code>-dtls1_2</code></strong>, <strong><code>-dtls1_3</code></strong></p>
<p>これらのオプションは、TLSの代わりにDTLSを使用することを指定します。<strong><code>-dtls</code></strong>では、クライアントはサポートされている任意のDTLSプロトコルバージョンをネゴシエートします。DTLS1.0、DTLS1.2、DTLS1.3だけをそれぞれサポートするには、<strong><code>-dtls1</code></strong>、<strong><code>-dtls1_2</code></strong>、<strong><code>-dtls1_3</code></strong>オプションを使用してください。</p></li></ul>

#### プロバイダーオプション¶ {#provider-options}


<ul><li><p><strong><code>-provider</code></strong> <em>name</em></p>
<p><em>name</em>で識別されるプロバイダーを読み込んで初期化します。<em>name</em>にはプロバイダーモジュールへのパスも指定できます。その場合、プロバイダー名は単なるモジュール名ではなく、指定したパスになります。相対パスの解釈はプラットフォームに依存します。設定された「MODULESDIR」パス、環境変数<strong>OPENSSL_MODULES</strong>、または<strong><code>-provider-path</code></strong>で指定したパスが、相対パスの先頭に付加されます。詳細は <a href="https://docs.openssl.org/4.1/man7/provider/">provider(7)</a> を参照してください。</p></li><li><p><strong><code>-provider-path</code></strong> <em>path</em></p>
<p>プロバイダーを探す際に使用する検索パスを指定します。同じ目的で環境変数<strong>OPENSSL_MODULES</strong>を設定することもできます。</p></li><li><p><strong><code>-provparam</code></strong> <em>[name:]key=value</em></p>
<p>プロバイダー<em>name</em>（省略可能）の設定パラメーター<em>key</em>を値<em>val</em>に設定します。<em>name</em>を省略すると、読み込み済みのすべてのプロバイダーに設定を適用します。このオプションを複数回指定して、複数のパラメーターを設定できます。これから読み込む非既定のプロバイダーに設定を適用する場合は、そのプロバイダーの読み込みを指定するオプションを、このオプションより前に指定してください。プロバイダーの初期化だけに影響するパラメーターは、現時点では設定ファイルで指定する必要があります。このインターフェースで設定した場合に効果があるのは、後から必要に応じても照会されるパラメーターだけです。値がUTF8文字列のパラメーターだけをサポートします。サポートするパラメーターについては、個々のプロバイダーと関連アルゴリズムの文書を参照してください。</p></li><li><p><strong><code>-propquery</code></strong> <em>propq</em></p>
<p>読み込み済みプロバイダーからアルゴリズムを取得するときに使用する、<em>プロパティー照会句</em>を指定します。詳細は <a href="https://docs.openssl.org/4.1/man7/property/">property(7)</a> を参照してください。</p></li></ul>

### 履歴¶ {#history}


<p><strong>list</strong> -<em>XXX</em><strong><code>-algorithms</code></strong>オプションはOpenSSL 1.0.0で追加されました。その他のコマンドが利用可能なバージョンについては、それぞれのマニュアルページを参照してください。</p>

<p><strong><code>-issuer_checks</code></strong>オプションはOpenSSL 1.1.0から非推奨であり、通知せずに無視されます。</p>

<p><strong><code>-xcertform</code></strong>と<strong><code>-xkeyform</code></strong>オプションはOpenSSL 3.0から廃止されており、効果はありません。</p>

<p>追加引数なしで <code>openssl</code> を実行すると起動できた対話モードは、OpenSSL 3.0で削除されました。現在、引数なしでの実行は <code>openssl help</code> と同じです。</p>

<p><strong>engine</strong>コマンドと、<code>org.openssl.engine</code> URIスキームを含むエンジンサポート全体は、OpenSSL 4.0で削除されました。代わりにプロバイダーを使用してください。</p>
