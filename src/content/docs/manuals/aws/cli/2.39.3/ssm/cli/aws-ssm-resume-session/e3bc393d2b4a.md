## resume-session¶ {#resume-session}


### 説明¶ {#Description}


<p>切断されたセッションをマネージドノードに再接続します。切断されたセッションの接続は再開できますが、終了したセッションは再開できません。</p>

#### 注記 {#Note}


<p>このコマンドは主に、断続的なネットワーク障害の際にクライアントマシンが自動再接続するためのものです。それ以外の用途は想定されていません。</p>

<p>関連項目: <a href="https://docs.aws.amazon.com/goto/WebAPI/ssm-2014-11-06/ResumeSession">AWS API Documentation</a></p>
