## list-command-invocations¶ {#list-command-invocations}


### 説明¶ {#Description}


<p>呼び出しとは、特定のマネージドノードに送信されたコマンドのコピーです。コマンドは 1 つ以上のマネージドノードに適用できます。コマンド呼び出しは 1 つのマネージドノードに適用されます。例えば、ユーザーが 3 つのマネージドノードに対して <code>SendCommand</code> を実行すると、リクエストされた各マネージドノード ID に対してコマンド呼び出しが作成されます。<code>ListCommandInvocations</code> はコマンド実行に関するステータスを提供します。</p>

<p>関連項目: <a href="https://docs.aws.amazon.com/goto/WebAPI/ssm-2014-11-06/ListCommandInvocations">AWS API Documentation</a></p>

<p><code>list-command-invocations</code> はページネーションを行う操作です。結果のデータセット全体を取得するために、複数回の API 呼び出しが行われる場合があります。<code>--no-paginate</code> 引数を指定すると、ページネーションを無効にできます。ページネーションされた応答に対して <code>--output text</code> と <code>--query</code> 引数を使用する場合、<code>--query</code> 引数は次のクエリ式の結果からデータを抽出する必要があります: <code>CommandInvocations</code></p>
