## get-command-invocation¶ {#get-command-invocation}


### 説明¶ {#Description}


<p>呼び出しまたはプラグインのコマンド実行に関する詳細情報を返します。Run Command API は、それを支えるシステムが分散しているため、結果整合性モデルに従います。つまり、リソースに影響する API コマンドを実行しても、その結果が後続のすべてのコマンドにすぐに反映されるとは限りません。ある API コマンドの直後に別の API コマンドを実行する際は、この点に留意してください。</p>

<blockquote><p><code>GetCommandInvocation</code> は、ドキュメント内のプラグインの実行状態のみを返します。特定のマネージドノードでのコマンド実行状態を取得するには ListCommandInvocations を使用します。複数のマネージドノードにわたるコマンド実行状態を取得するには ListCommands を使用します。</p></blockquote>

<p>関連項目: <a href="https://docs.aws.amazon.com/goto/WebAPI/ssm-2014-11-06/GetCommandInvocation">AWS API Documentation</a></p>

<p><code>--generate-cli-skeleton</code> (string) API リクエストを送信せずに、JSON スケルトンを標準出力に表示します。値を指定しない場合、または値に <code>input</code> を指定した場合は、<code>--cli-input-json</code> の引数に使用できる入力 JSON のサンプルを表示します。同様に、<code>yaml-input</code> を指定した場合は、<code>--cli-input-yaml</code> で使用できる入力 YAML のサンプルを表示します。値に <code>output</code> を指定した場合は、コマンドの入力を検証し、そのコマンドの出力 JSON のサンプルを返します。生成される JSON スケルトンは AWS CLI のバージョン間で一定ではなく、生成される JSON スケルトンの後方互換性は保証されません。</p>

<p>StatusDetails -&gt; (string)</p>

<blockquote><p>呼び出しに対するコマンド実行の詳細な状態。<code>StatusDetails</code> はエラー制御と同時実行制御のパラメーターに起因する状態も含むため、<code>Status</code> より多くの情報を含みます。<code>StatusDetails</code> は <code>Status</code> と異なる結果を示す場合があります。これらの状態の詳細については、<em>Amazon Web Services Systems Manager ユーザーガイド</em>の <a href="https://docs.aws.amazon.com/systems-manager/latest/userguide/monitor-commands.html">Understanding command statuses</a> を参照してください。<code>StatusDetails</code> は次の値のいずれかです。</p>
<ul><li><p>Pending: コマンドはまだマネージドノードに送信されていません。</p></li><li><p>In Progress: コマンドはマネージドノードに送信済みですが、終端状態に達していません。</p></li><li><p>Delayed: システムは対象へのコマンド送信を試みましたが、対象を利用できませんでした。ネットワークの問題、ノードの停止などの理由で、マネージドノードを利用できない場合があります。システムはコマンドの送信を再試行します。</p></li><li><p>Success: コマンドまたはプラグインは正常に実行されました。終端状態です。</p></li><li><p>Delivery Timed Out: 配信タイムアウトの期限までにコマンドをマネージドノードに配信できませんでした。配信タイムアウトは親コマンドの <code>MaxErrors</code> 制限には加算されませんが、親コマンドの状態が Success または Incomplete になるかの判定には影響します。終端状態です。</p></li><li><p>Execution Timed Out: コマンドはマネージドノードで実行を開始しましたが、タイムアウト期限までに完了しませんでした。実行タイムアウトは親コマンドの <code>MaxErrors</code> 制限に加算されます。終端状態です。</p></li><li><p>Failed: コマンドはマネージドノードで正常に実行されませんでした。プラグインの場合、結果コードがゼロでなかったことを示します。コマンド呼び出しの場合、1 つ以上のプラグインの結果コードがゼロでなかったことを示します。呼び出しの失敗は親コマンドの <code>MaxErrors</code> 制限に加算されます。終端状態です。</p></li><li><p>Cancelled: コマンドは完了する前に終了させられました。終端状態です。</p></li><li><p>Undeliverable: コマンドをマネージドノードに配信できません。ノードが存在しないか、応答していない可能性があります。配信不能な呼び出しは親コマンドの <code>MaxErrors</code> 制限には加算されず、親コマンドの状態が Success または Incomplete になるかの判定にも影響しません。終端状態です。</p></li><li><p>Terminated: 親コマンドが <code>MaxErrors</code> 制限を超えたため、後続のコマンド呼び出しがシステムによってキャンセルされました。終端状態です。</p></li></ul>
<p>制約:</p>
<ul><li><p>最小: <code>0</code></p></li><li><p>最大: <code>100</code></p></li></ul></blockquote>

<p>StandardOutputContent -&gt; (string)</p>

<blockquote><p>プラグインが <code>stdout</code> に書き込んだ先頭 24,000 文字。コマンドの実行が完了しておらず、<code>ExecutionStatus</code> が Succeeded でも Failed でもない場合、この文字列は空です。</p>
<p>制約:</p>
<ul><li><p>最大: <code>24000</code></p></li></ul></blockquote>

<p>StandardOutputUrl -&gt; (string)</p>

<blockquote><p>プラグインが <code>stdout</code> に書き込んだ全文を保存した Amazon Simple Storage Service (Amazon S3) の URL。S3 バケットを指定していない場合、この文字列は空です。</p></blockquote>

<p>StandardErrorContent -&gt; (string)</p>

<blockquote><p>プラグインが <code>stderr</code> に書き込んだ先頭 8,000 文字。コマンドの実行が完了していない場合、この文字列は空です。</p>
<p>制約:</p>
<ul><li><p>最大: <code>8000</code></p></li></ul></blockquote>

<p>StandardErrorUrl -&gt; (string)</p>

<blockquote><p>プラグインが <code>stderr</code> に書き込んだ全文の URL。コマンドの実行が完了していない場合、この文字列は空です。</p></blockquote>

<p>CloudWatchOutputConfig -&gt; (structure)</p>

<blockquote><p>Systems Manager がコマンド出力を送信した Amazon CloudWatch Logs の情報。</p>
<p>CloudWatchLogGroupName -&gt; (string)</p>
<blockquote><p>コマンド出力の送信先となる CloudWatch Logs ロググループの名前。グループ名を指定しない場合、Amazon Web Services Systems Manager がロググループを自動作成します。ロググループは次の命名形式を使用します。</p>
<blockquote><p><a href="#id1">``</a>aws/ssm/<em>SystemsManagerDocumentName</em> ``</p></blockquote>
<p>制約:</p>
<ul><li><p>最小: <code>1</code></p></li><li><p>最大: <code>512</code></p></li></ul></blockquote>
<p>CloudWatchOutputEnabled -&gt; (boolean)</p>
<blockquote><p>Systems Manager がコマンド出力を CloudWatch Logs に送信できるようにします。</p></blockquote></blockquote>
