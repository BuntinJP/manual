## describe-patch-properties¶ {#describe-patch-properties}


### 説明¶ {#Description}


<p>利用可能なパッチのプロパティを、製品、製品ファミリー、分類、重要度などのプロパティ別に一覧表示します。報告されたプロパティは、CreatePatchBaseline、UpdatePatchBaseline、DescribeAvailablePatches、DescribePatchBaselines などの操作のリクエストで指定するフィルターに使用できます。</p>
