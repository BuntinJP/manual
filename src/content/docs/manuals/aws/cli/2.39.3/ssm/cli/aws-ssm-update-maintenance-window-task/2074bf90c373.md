## update-maintenance-window-task¶ {#update-maintenance-window-task}


### 説明¶ {#Description}


<p>メンテナンスウィンドウに割り当てられたタスクを変更します。タスクタイプは変更できませんが、次の値は変更できます。</p>

<ul><li><p><code>TaskARN</code>。例えば、<code>RUN_COMMAND</code> タスクを <code>AWS-RunPowerShellScript</code> から <code>AWS-RunShellScript</code> に変更できます。</p></li><li><p><code>ServiceRoleArn</code></p></li><li><p><code>TaskInvocationParameters</code></p></li><li><p><code>Priority</code></p></li><li><p><code>MaxConcurrency</code></p></li><li><p><code>MaxErrors</code></p></li></ul>

#### 注記 {#Note}


<p>メンテナンスウィンドウの Run Command タイプのタスクには、1 つ以上の対象を指定する必要があります。ほかのメンテナンスウィンドウのタスクタイプ (Automation、Lambda、Step Functions) では、タスクによって対象の指定は任意です。対象を指定しないタスクの実行については、<em>Amazon Web Services Systems Manager ユーザーガイド</em>の <a href="https://docs.aws.amazon.com/systems-manager/latest/userguide/maintenance-windows-targetless-tasks.html">Registering maintenance window tasks without targets</a> を参照してください。</p>

<p><code>UpdateMaintenanceWindowTask</code> のパラメータの値が null の場合、対応するフィールドは変更されません。<code>Replace</code> を true に設定すると、RegisterTaskWithMaintenanceWindow オペレーションで必須のすべてのフィールドが、このリクエストでも必須になります。指定されていないオプションのフィールドは null に設定されます。</p>

#### 警告 {#Warning}


<p><code>TaskInvocationParameters</code> にオプションを指定したメンテナンスウィンドウタスクを更新するときは、保持するすべての <code>TaskInvocationParameters</code> の値を再度指定する必要があります。再度指定しない値は削除されます。例えば、Run Command タスクの登録時に、<code>Comment</code>、<code>NotificationConfig</code>、<code>OutputS3BucketName</code> の <code>TaskInvocationParameters</code> 値を指定したとします。メンテナンスウィンドウタスクを更新し、別の <code>OutputS3BucketName</code> 値のみを指定すると、<code>Comment</code> と <code>NotificationConfig</code> の値は削除されます。</p>

<p>関連項目: <a href="https://docs.aws.amazon.com/goto/WebAPI/ssm-2014-11-06/UpdateMaintenanceWindowTask">AWS API Documentation</a></p>
