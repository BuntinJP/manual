## describe-instance-information¶ {#describe-instance-information}


### 説明¶ {#Description}


<p>1 つ以上のマネージドノードについて、OS プラットフォーム、SSM Agent バージョン、関連付け状態、IP アドレスなどの情報を提供します。Stopped または Terminated 状態のノードの情報は返しません。</p>

<p>1 つ以上のノード ID を指定した場合、それらのマネージドノードの情報を返します。指定しない場合は、すべてのマネージドノードの情報を返します。無効なノード ID や、自分が所有していないノードを指定するとエラーになります。</p>

#### 注記 {#Note}


<p>この API 操作が返す <code>IamRole</code> フィールドは、Systems Manager Quick Setup のホスト管理設定を使用した Amazon EC2 インスタンスに割り当てられたロール、またはオンプレミスのマネージドノードに割り当てられたロールです。</p>

<p>関連項目: <a href="https://docs.aws.amazon.com/goto/WebAPI/ssm-2014-11-06/DescribeInstanceInformation">AWS API Documentation</a></p>

<p><code>describe-instance-information</code> はページネーションを行う操作です。結果のデータセット全体を取得するために、複数回の API 呼び出しが行われる場合があります。<code>--no-paginate</code> 引数を指定すると、ページネーションを無効にできます。ページネーションされた応答に対して <code>--output text</code> と <code>--query</code> 引数を使用する場合、<code>--query</code> 引数は次のクエリ式の結果からデータを抽出する必要があります: <code>InstanceInformationList</code></p>

### 出力¶ {#Output}


<p>InstanceInformationList -&gt; (list)</p>

<blockquote><p>マネージドノードの情報一覧。</p>
<p>(structure)</p>
<blockquote><p>マネージドノードの特定の一覧に対するフィルターを定義します。</p>
<p>InstanceId -&gt; (string)</p>
<blockquote><p>マネージドノードの ID。</p>
<p>制約:</p>
<ul><li><p>パターン: <code>(^i-(\w{8}|\w{17})$)|(^mi-\w{17}$)</code></p></li></ul></blockquote>
<p>PingStatus -&gt; (string)</p>
<blockquote><p>SSM Agent の接続状態。</p>
<h4 id="Note-4">注記</h4>
<p><code>Inactive</code> 状態は非推奨となり、現在は使用されていません。</p>
<p>指定可能な値:</p>
<ul><li><p><code>Online</code></p></li><li><p><code>ConnectionLost</code></p></li><li><p><code>Inactive</code></p></li></ul></blockquote>
<p>LastPingDateTime -&gt; (timestamp)</p>
<blockquote><p>エージェントが Systems Manager サービスに最後に ping を送った日時。</p></blockquote>

<blockquote><p>Linux マネージドノードで実行中の SSM Agent のバージョン。</p>
<p>制約:</p>
<ul><li><p>パターン: <code>^[0-9]{1,6}(\.[0-9]{1,6}){2,3}$</code></p></li></ul></blockquote>
<p>IsLatestVersion -&gt; (boolean)</p>
<blockquote><p>Linux マネージドノードで最新の SSM Agent が実行されているかを示します。一部の古い Windows Server は Systems Manager リクエストの処理に EC2Config サービスを使用するため、このフィールドは Windows マネージドノードに最新版がインストールされているかどうかは示しません。</p></blockquote>
<p>PlatformType -&gt; (string)</p>
<blockquote><p>オペレーティングシステムのプラットフォームの種類。</p>
<p>指定可能な値:</p>
<ul><li><p><code>Windows</code></p></li><li><p><code>Linux</code></p></li><li><p><code>MacOS</code></p></li></ul></blockquote>
<p>PlatformName -&gt; (string)</p>
<blockquote><p>マネージドノードで実行中のオペレーティングシステムのプラットフォーム名。</p></blockquote>
<p>PlatformVersion -&gt; (string)</p>
<blockquote><p>マネージドノードで実行中の OS プラットフォームのバージョン。</p></blockquote>
<p>ActivationId -&gt; (string)</p>
<blockquote><p>サーバーまたは仮想マシン (VM) の登録時に Amazon Web Services Systems Manager が作成したアクティベーション ID。</p>
<p>制約:</p>
<ul><li><p>パターン: <code>^[0-9a-f]{8}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{4}-[0-9a-f]{12}$</code></p></li></ul></blockquote>
<p>IamRole -&gt; (string)</p>
<blockquote><p>Systems Manager Quick Setup のホスト管理設定を使用した Amazon EC2 インスタンスに割り当てられたロール、またはオンプレミスのマネージドノードに割り当てられたロール。</p>
<p>この呼び出しは、<em>管理対象外</em>の Amazon EC2 インスタンス (Systems Manager 用に設定されていないインスタンス) の IAM ロールを返しません。そのロールを取得するには、Amazon EC2 の <code>DescribeInstances</code> 操作を使用します。詳細については、<em>Amazon EC2 API リファレンス</em>の <a href="https://docs.aws.amazon.com/AWSEC2/latest/APIReference/API_DescribeInstances.html">DescribeInstances</a>、または <em>Amazon Web Services CLI コマンドリファレンス</em>の <a href="https://docs.aws.amazon.com/cli/latest/reference/ec2/describe-instances.html">describe-instances</a> を参照してください。</p>
<p>制約:</p>
<ul><li><p>最大: <code>64</code></p></li></ul></blockquote>
<p>RegistrationDate -&gt; (timestamp)</p>
<blockquote><p>サーバーまたは VM がマネージドノードとして Amazon Web Services に登録された日時。</p></blockquote>

<blockquote><p>インスタンスの種類。EC2 インスタンスまたはマネージドインスタンスです。</p>

<ul><li><p><code>ManagedInstance</code></p></li><li><p><code>EC2Instance</code></p></li></ul></blockquote>
<p>Name -&gt; (string)</p>
<blockquote><p>オンプレミスサーバー、エッジデバイス、仮想マシン (VM) が Systems Manager マネージドノードとしてアクティベートされる際に割り当てられる名前。CreateActivation コマンドの <code>DefaultInstanceName</code> プロパティで指定します。<a href="https://docs.aws.amazon.com/systems-manager/latest/userguide/hybrid-multicloud-ssm-agent-install-linux.html">How to install SSM Agent on hybrid Linux nodes</a> および <a href="https://docs.aws.amazon.com/systems-manager/latest/userguide/hybrid-multicloud-ssm-agent-install-windows.html">How to install SSM Agent on hybrid Windows Server nodes</a> に説明されているように、ノードへの SSM Agent インストール時にアクティベーションコードと ID を指定すると適用されます。EC2 インスタンスの <code>Name</code> タグを取得するには、Amazon EC2 の <code>DescribeInstances</code> 操作を使用します。詳細については、<em>Amazon EC2 API リファレンス</em>の <a href="https://docs.aws.amazon.com/AWSEC2/latest/APIReference/API_DescribeInstances.html">DescribeInstances</a>、または <em>Amazon Web Services CLI コマンドリファレンス</em>の <a href="https://docs.aws.amazon.com/cli/latest/reference/ec2/describe-instances.html">describe-instances</a> を参照してください。</p></blockquote>

<blockquote><p>マネージドノードの IP アドレス。</p>
