## update-managed-instance-role¶ {#update-managed-instance-role}


### 説明¶ {#Description}


<p>オンプレミスサーバー、エッジデバイス、または仮想マシン (VM) に割り当てられている Identity and Access Management (IAM) ロールを変更します。これらのハイブリッドノードへの IAM ロールの最初の割り当ては、アクティベーション手順で行われます。詳細については、CreateActivation を参照してください。</p>

<p>関連項目: <a href="https://docs.aws.amazon.com/goto/WebAPI/ssm-2014-11-06/UpdateManagedInstanceRole">AWS API Documentation</a></p>

### オプション¶ {#Options}


<p><code>--instance-id</code> (string) [必須]</p>

<blockquote><p>ロールを更新するマネージドノードの ID。</p>
<p>制約:</p>
<ul><li><p>最小: <code>20</code></p></li><li><p>最大: <code>124</code></p></li><li><p>パターン: <code>(^mi-[0-9a-f]{17}$)|(^eks_c:[0-9A-Za-z][A-Za-z0-9\-_]{0,99}_\w{17}$)</code></p></li></ul></blockquote>

<p><code>--iam-role</code> (string) [必須]</p>

<blockquote><p>マネージドノードに割り当てる Identity and Access Management (IAM) ロールの名前。この IAM ロールは、Amazon Web Services Systems Manager のサービスプリンシパル <code>ssm.amazonaws.com</code> に対する AssumeRole 権限を提供する必要があります。詳細については、<em>Amazon Web Services Systems Manager ユーザーガイド</em>の <a href="https://docs.aws.amazon.com/systems-manager/latest/userguide/hybrid-multicloud-service-role.html">Create the IAM service role required for Systems Manager in hybrid and multicloud environments</a> を参照してください。</p>
<h4 id="Note">注記</h4>
<p>このパラメーターに IAM サービスリンクロールを指定することはできません。固有のロールを作成する必要があります。</p>
<p>制約:</p>
<ul><li><p>最大: <code>64</code></p></li></ul></blockquote>
