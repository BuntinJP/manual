## get-maintenance-window-task¶ {#get-maintenance-window-task}


### 説明¶ {#Description}


<p>メンテナンスウィンドウタスクの詳細を取得します。</p>

#### 注記 {#Note}


<p>ターゲットを指定していないメンテナンスウィンドウタスクでは、<code>--max-errors</code> と <code>--max-concurrency</code> の値を指定できません。代わりに、システムはプレースホルダー値 <code>1</code> を挿入します。この値は、このコマンドのレスポンスに表示されることがあります。これらの値はタスクの実行に影響しないため、無視できます。</p>

<p>メンテナンスウィンドウ内のタスクの一覧を取得するには、代わりに DescribeMaintenanceWindowTasks コマンドを使用します。</p>

<p>関連項目: <a href="https://docs.aws.amazon.com/goto/WebAPI/ssm-2014-11-06/GetMaintenanceWindowTask">AWS API Documentation</a></p>
