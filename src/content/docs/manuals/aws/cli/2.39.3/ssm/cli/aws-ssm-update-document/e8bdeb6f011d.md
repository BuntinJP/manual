## update-document¶ {#update-document}


### 説明¶ {#Description}


<p>SSM ドキュメントの 1 つ以上の値を更新します。</p>

<p>関連項目: <a href="https://docs.aws.amazon.com/goto/WebAPI/ssm-2014-11-06/UpdateDocument">AWS API Documentation</a></p>

<p><strong>ドキュメントの新しいバージョンを作成するには</strong></p>

<p>次の <code>update-document</code> の例を Windows コンピューターで実行すると、ドキュメントの新しいバージョンが作成されます。<code>--document</code> で指定するドキュメントは JSON 形式でなければなりません。<code>file://</code> に続けてコンテンツファイルのパスを指定する必要があることに注意してください。<code>--document-version</code> パラメータの先頭に <code>$</code> があるため、Windows では値を二重引用符で囲む必要があります。Linux、MacOS、または PowerShell プロンプトでは、値を一重引用符で囲む必要があります。</p>

<p>Windows 版。</p>

<pre><code>aws ssm update-document \
    --name &quot;RunShellScript&quot; \
    --content &quot;file://RunShellScript.json&quot; \
    --document-version &quot;$LATEST&quot;</code></pre>

<p>Linux/Mac 版。</p>

<pre><code>aws ssm update-document \
    --name &quot;RunShellScript&quot; \
    --content &quot;file://RunShellScript.json&quot; \
    --document-version &#39;$LATEST&#39;</code></pre>

<pre><code>{

            &quot;name&quot;: &quot;runShellScript&quot;,
            &quot;inputs&quot;: {
                &quot;runCommand&quot;: &quot;{{ commands }}&quot;
            }
        }
    ]
}</code></pre>
