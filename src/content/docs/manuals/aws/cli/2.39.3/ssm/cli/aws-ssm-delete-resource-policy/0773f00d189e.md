## delete-resource-policy¶ {#delete-resource-policy}


### 説明¶ {#Description}


<p>Systems Manager のリソースポリシーを削除します。リソースポリシーを使用すると、Systems Manager リソースを管理できる IAM エンティティ (Amazon Web Services アカウントなど) を定義できます。以下のリソースは Systems Manager のリソースポリシーをサポートしています。</p>

<ul><li><p><code>OpsItemGroup</code> - <code>OpsItemGroup</code> のリソースポリシーにより、Amazon Web Services アカウントは OpsCenter の運用作業項目 (OpsItem) を表示して操作できます。</p></li><li><p><code>Parameter</code> - リソースポリシーは、Resource Access Manager (RAM) を使ってパラメーターをほかのアカウントと共有するために使用されます。パラメーターのクロスアカウント共有の詳細については、<em>Amazon Web Services Systems Manager ユーザーガイド</em>の <a href="https://docs.aws.amazon.com/systems-manager/latest/userguide/parameter-store-shared-parameters.html">Working with shared parameters</a> を参照してください。</p></li><li><p><code>Document</code> - Resource Access Manager (RAM) を使ってドキュメントを共有します。ドキュメントの共有の詳細については、<em>Amazon Web Services Systems Manager ユーザーガイド</em>の <a href="https://docs.aws.amazon.com/systems-manager/latest/userguide/documents-ssm-sharing.html">Sharing Systems Manager documents</a> を参照してください。</p></li></ul>

<p>関連項目: <a href="https://docs.aws.amazon.com/goto/WebAPI/ssm-2014-11-06/DeleteResourcePolicy">AWS API Documentation</a></p>

### オプション¶ {#Options}


<p><code>--resource-arn</code> (string) [必須]</p>

<blockquote><p>ポリシーがアタッチされているリソースの Amazon リソースネーム (ARN)。</p>
<p>制約:</p>
<ul><li><p>最小: <code>20</code></p></li><li><p>最大: <code>2048</code></p></li></ul></blockquote>

<p><code>--policy-id</code> (string) [必須]</p>

<blockquote><p>ポリシー ID。</p></blockquote>

<p><code>--policy-hash</code> (string) [必須]</p>

<blockquote><p>現在のポリシーバージョンの ID。このハッシュは、複数の呼び出しがポリシーの上書きを試みることを防ぐのに役立ちます。</p></blockquote>

<p><code>--deletion-mode</code> (string)</p>

<blockquote><p>操作で意図する結果を指定します。<code>Document</code> リソースタイプにのみ適用されます。ほかのリソースタイプでは、このパラメーターは無視されます。省略可能です。既定値は <code>RemoveSharing</code> です。</p>
<ul><li><p><code>RemoveSharing</code> - リソースポリシーを削除し、ドキュメントの共有を解除します。</p></li><li><p><code>RollbackMigration</code> - ポリシーを削除する代わりに、既存の利用者のアクセスを維持したまま、ドキュメントを Custom 共有に戻します。</p></li></ul>
<p>指定可能な値:</p>
<ul><li><p><code>RemoveSharing</code></p></li><li><p><code>RollbackMigration</code></p></li></ul></blockquote>

<p><code>--cli-input-json</code> | <code>--cli-input-yaml</code> (string) 指定された JSON 文字列から引数を読み取ります。JSON 文字列は <code>--generate-cli-skeleton</code> が提供する形式に従います。コマンドラインでほかの引数を指定した場合、その値が JSON で指定した値を上書きします。文字列はそのまま解釈されるため、JSON で指定する値を使って任意のバイナリ値を渡すことはできません。<code>--cli-input-yaml</code> と同時には指定できません。</p>

<p><code>--generate-cli-skeleton</code> (string) API リクエストを送信せずに、JSON スケルトンを標準出力に表示します。値を指定しない場合、または値に <code>input</code> を指定した場合は、<code>--cli-input-json</code> の引数に使用できる入力 JSON のサンプルを表示します。同様に、<code>yaml-input</code> を指定した場合は、<code>--cli-input-yaml</code> で使用できる入力 YAML のサンプルを表示します。値に <code>output</code> を指定した場合は、コマンドの入力を検証し、そのコマンドの出力 JSON のサンプルを返します。生成される JSON スケルトンは AWS CLI のバージョン間で一定ではなく、生成される JSON スケルトンの後方互換性は保証されません。</p>
