## get-parameter¶ {#get-parameter}


### 説明¶ {#Description}


<p>パラメーター名を指定して、単一のパラメーターの情報を取得します。</p>

<p>パラメーター名にスペースを含めることはできません。サービスは、パラメーター名の先頭または末尾に指定されたスペースをすべて削除します。指定したパラメーター名の文字の間にスペースがある場合、リクエストは <code>ValidationException</code> エラーで失敗します。</p>

#### 注記 {#Note}


<p>複数のパラメーターの情報を一度に取得するには、GetParameters 操作を使用します。</p>

#### 注記 {#Note-2}


<p>Parameter Store のスループットは、Systems Manager が処理できる 1 秒あたりの API トランザクション数 (TPS) を定義します。これは、Amazon Web Services アカウントおよび Amazon Web Services リージョンの <code>GetParameter</code>、<code>GetParameters</code>、<code>PutParameter</code> API 呼び出しに適用されます。既定では、Parameter Store は低量から中量のワークロードに適した標準のスループットクォータで設定されています。設定データを取得する頻度が低いアプリケーションや、小規模で動作するアプリケーションは、追加料金なしでこの既定の設定を使用できます。</p>

<p>より大量のワークロードには、高スループットを有効にできます。これにより、アカウントとリージョンでサポートされる 1 秒あたりの最大トランザクション数が増えます。スループットの引き上げは、複数のパラメーターへの同時アクセスが必要なアプリケーションやワークロードをサポートします。<code>ThrottlingException: Rate exceeded</code> エラーが発生する場合は、高スループットを有効にしてください。詳細については、<a href="https://docs.aws.amazon.com/systems-manager/latest/userguide/parameter-store-throughput.html">Changing Parameter Store throughput</a> を参照してください。</p>

<p>関連項目: <a href="https://docs.aws.amazon.com/goto/WebAPI/ssm-2014-11-06/GetParameter">AWS API Documentation</a></p>

### オプション¶ {#Options}


<p><code>--name</code> (string) [必須]</p>

<blockquote><p>照会するパラメーターの名前または Amazon リソースネーム (ARN)。別のアカウントから共有されたパラメーターには、完全な ARN を使用する必要があります。</p>
<p>パラメーターラベルで照会するには <code>&quot;Name&quot;: &quot;name:label&quot;</code> を使用します。パラメーターバージョンで照会するには <code>&quot;Name&quot;: &quot;name:version&quot;</code> を使用します。</p>
<p>共有パラメーターの詳細については、<em>Amazon Web Services Systems Manager ユーザーガイド</em>の <a href="https://docs.aws.amazon.com/systems-manager/latest/userguide/parameter-store-shared-parameters.html">Working with shared parameters</a> を参照してください。</p>
<p>制約:</p>
<ul><li><p>最小: <code>1</code></p></li><li><p>最大: <code>2048</code></p></li></ul></blockquote>

<p><code>--with-decryption</code> | <code>--no-with-decryption</code> (boolean)</p>

<blockquote><p>セキュア文字列パラメーターの復号された値を返します。このフラグは、<code>String</code> および <code>StringList</code> のパラメータータイプでは無視されます。</p></blockquote>

<p><code>--cli-input-json</code> | <code>--cli-input-yaml</code> (string) 指定された JSON 文字列から引数を読み取ります。JSON 文字列は <code>--generate-cli-skeleton</code> が提供する形式に従います。コマンドラインでほかの引数を指定した場合、その値が JSON で指定した値を上書きします。文字列はそのまま解釈されるため、JSON で指定する値を使って任意のバイナリ値を渡すことはできません。<code>--cli-input-yaml</code> と同時には指定できません。</p>

<p><code>--generate-cli-skeleton</code> (string) API リクエストを送信せずに、JSON スケルトンを標準出力に表示します。値を指定しない場合、または値に <code>input</code> を指定した場合は、<code>--cli-input-json</code> の引数に使用できる入力 JSON のサンプルを表示します。同様に、<code>yaml-input</code> を指定した場合は、<code>--cli-input-yaml</code> で使用できる入力 YAML のサンプルを表示します。値に <code>output</code> を指定した場合は、コマンドの入力を検証し、そのコマンドの出力 JSON のサンプルを返します。生成される JSON スケルトンは AWS CLI のバージョン間で一定ではなく、生成される JSON スケルトンの後方互換性は保証されません。</p>
