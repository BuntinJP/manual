<blockquote><p>変更テンプレートの承認要求に対する応答の情報。</p>

<blockquote><p>ドキュメントレビュー要求に対するレビュー担当者の応答の詳細。</p>
<p>(structure)</p>
<blockquote><p>ドキュメントレビュー要求に対するレビュー担当者の応答の情報。</p>

<blockquote><p>組織のメンバーが作成した新しいカスタム SSM ドキュメント、または既存の SSM ドキュメントの最新バージョンに対する、現在のレビュー状態。</p>
<p>同時に APPROVED 状態にできるドキュメントのバージョンは 1 つだけです。新しいバージョンが承認されると、以前のバージョンの状態は REJECTED に変わります。</p>

<p>指定可能な値:</p>
<ul><li><p><code>APPROVED</code></p></li><li><p><code>NOT_REVIEWED</code></p></li><li><p><code>PENDING</code></p></li><li><p><code>REJECTED</code></p></li></ul></blockquote>
<p>Comment -&gt; (list)</p>
<blockquote><p>レビュー担当者がドキュメントレビューへの応答の一部として入力したコメント。</p>
<p>制約:</p>
<ul><li><p>最小: <code>0</code></p></li><li><p>最大: <code>1</code></p></li></ul>
<p>(structure)</p>
<blockquote><p>ドキュメントレビュー要求に追加されたコメントに関する情報。</p>
<p>Type -&gt; (string)</p>
<blockquote><p>レビュー要求に追加された情報の種類。現在サポートされる値は <code>Comment</code> のみです。</p>
<p>指定可能な値:</p>
<ul><li><p><code>Comment</code></p></li></ul></blockquote>
<p>Content -&gt; (string)</p>
<blockquote><p>ドキュメントの新しいバージョンのレビューを要求したユーザー、またはそのバージョンをレビューするユーザーが入力したコメントの内容。</p>
<p>制約:</p>
<ul><li><p>最小: <code>1</code></p></li><li><p>最大: <code>1024</code></p></li><li><p>パターン: <code>^(?!\s*$).+</code></p></li></ul></blockquote></blockquote></blockquote>
<p>Reviewer -&gt; (string)</p>
<blockquote><p>ドキュメント要求のレビューを割り当てられた、組織内のユーザー。</p>
<p>制約:</p>
<ul><li><p>最大: <code>50</code></p></li><li><p>パターン: <code>^[a-zA-Z0-9_\-.]{1,128}$</code></p></li></ul></blockquote></blockquote></blockquote></blockquote>

<p>NextToken -&gt; (string)</p>
