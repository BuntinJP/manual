## delete-inventory¶ {#delete-inventory}


### 説明¶ {#Description}


<p>カスタムインベントリタイプ、またはそのタイプに関連するデータを削除します。カスタムインベントリタイプの削除は、カスタムインベントリスキーマの削除とも呼ばれます。</p>

<p>関連項目: <a href="https://docs.aws.amazon.com/goto/WebAPI/ssm-2014-11-06/DeleteInventory">AWS API Documentation</a></p>

### オプション¶ {#Options}


<p><code>--type-name</code> (string) [必須]</p>

<blockquote><p>以前に収集したすべてのデータ、またはインベントリタイプ自体を削除するカスタムインベントリタイプの名前。</p>
<p>制約:</p>
<ul><li><p>最小: <code>1</code></p></li><li><p>最大: <code>100</code></p></li><li><p>パターン: <code>^(AWS|Custom):.*$</code></p></li></ul></blockquote>

<p><code>--schema-delete-option</code> (string)</p>

<blockquote><p>カスタムインベントリタイプ (スキーマ) を削除するには <code>SchemaDeleteOption</code> を使用します。このオプションを選択しない場合、システムはそのカスタムインベントリタイプに関連する既存のインベントリデータのみを削除します。次のいずれかのオプションを選択します。</p>
<p>DisableSchema: このオプションを選択すると、指定したバージョンおよびそれ以前のバージョンのすべてのインベントリデータが無視されます。このスキーマを再び有効にするには、無効化したバージョンより大きいバージョンに対して <code>PutInventory</code> 操作を呼び出す必要があります。</p>
<p>DeleteSchema: このオプションは、指定したカスタムタイプを Inventory サービスから削除します。必要であれば、後でスキーマを再作成できます。</p>
<p>指定可能な値:</p>
<ul><li><p><code>DisableSchema</code></p></li><li><p><code>DeleteSchema</code></p></li></ul></blockquote>

<p><code>--dry-run</code> | <code>--no-dry-run</code> (boolean)</p>

<blockquote><p>データやデータタイプを削除せずに削除要求の概要を表示するには、このオプションを使用します。削除される内容を把握するだけの場合に役立ちます。削除対象のデータが意図したとおりであることを確認したら、<code>DryRun</code> オプションを指定せずに同じコマンドを実行できます。</p></blockquote>

<p><code>--client-token</code> (string)</p>

<blockquote><p>ユーザーが指定する冪等性トークン。</p>
<p>制約:</p>
<ul><li><p>パターン: <code>[a-f0-9]{8}-[a-f0-9]{4}-[a-f0-9]{4}-[a-f0-9]{4}-[a-f0-9]{12}</code></p></li></ul></blockquote>

<p><code>--cli-input-json</code> | <code>--cli-input-yaml</code> (string) 指定された JSON 文字列から引数を読み取ります。JSON 文字列は <code>--generate-cli-skeleton</code> が提供する形式に従います。コマンドラインでほかの引数を指定した場合、その値が JSON で指定した値を上書きします。文字列はそのまま解釈されるため、JSON で指定する値を使って任意のバイナリ値を渡すことはできません。<code>--cli-input-yaml</code> と同時には指定できません。</p>

<p><code>--generate-cli-skeleton</code> (string) API リクエストを送信せずに、JSON スケルトンを標準出力に表示します。値を指定しない場合、または値に <code>input</code> を指定した場合は、<code>--cli-input-json</code> の引数に使用できる入力 JSON のサンプルを表示します。同様に、<code>yaml-input</code> を指定した場合は、<code>--cli-input-yaml</code> で使用できる入力 YAML のサンプルを表示します。値に <code>output</code> を指定した場合は、コマンドの入力を検証し、そのコマンドの出力 JSON のサンプルを返します。生成される JSON スケルトンは AWS CLI のバージョン間で一定ではなく、生成される JSON スケルトンの後方互換性は保証されません。</p>
