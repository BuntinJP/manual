## get-parameters-by-path¶ {#get-parameters-by-path}


### 説明¶ {#Description}


<p>階層内の指定したレベルの配下にある、1 つ以上のパラメーターの情報を取得します。</p>

<p>リクエスト結果はベストエフォートで返されます。<code>MaxResults</code> を指定した場合、応答には指定した上限までの情報が含まれます。ただし、返される項目数はゼロから <code>MaxResults</code> の値までの範囲になります。結果の処理中にサービスの内部制限に達すると、操作を停止し、その時点までに一致した値と <code>NextToken</code> を返します。後続の呼び出しで <code>NextToken</code> を指定して、次の結果セットを取得できます。</p>

<p>パラメーター名にスペースを含めることはできません。サービスは、パラメーター名の先頭または末尾に指定されたスペースをすべて削除します。指定したパラメーター名の文字の間にスペースがある場合、リクエストは <code>ValidationException</code> エラーで失敗します。</p>

<p>関連項目: <a href="https://docs.aws.amazon.com/goto/WebAPI/ssm-2014-11-06/GetParametersByPath">AWS API Documentation</a></p>

<p><code>get-parameters-by-path</code> はページネーションを行う操作です。結果のデータセット全体を取得するために、複数回の API 呼び出しが行われる場合があります。<code>--no-paginate</code> 引数を指定すると、ページネーションを無効にできます。ページネーションされた応答に対して <code>--output text</code> と <code>--query</code> 引数を使用する場合、<code>--query</code> 引数は次のクエリ式の結果からデータを抽出する必要があります: <code>Parameters</code></p>

### オプション¶ {#Options}


<p><code>--path</code> (string) [必須]</p>

<blockquote><p>パラメーターの階層。階層はスラッシュ (/) で始まります。階層は、パラメーター名から最後の部分を除いたものです。API 呼び出しが成功するには、パスにパラメーター名の最後の部分を含めてはいけません。パラメーター名の階層は最大 15 レベルです。階層の例: <code>/Finance/Prod/IAD/WinServ2016/license33</code></p>
<p>制約:</p>
<ul><li><p>最小: <code>1</code></p></li><li><p>最大: <code>2048</code></p></li></ul></blockquote>

<p><code>--recursive</code> | <code>--no-recursive</code> (boolean)</p>

<blockquote><p>階層内のすべてのパラメーターを取得します。</p>
<h4 id="Warning">警告</h4>
<p>ユーザーがあるパスにアクセスできる場合、そのパスのすべてのレベルにアクセスできます。たとえば、パス <code>/a</code> へのアクセス権限があるユーザーは、<code>/a/b</code> にもアクセスできます。IAM でパラメーター <code>/a/b</code> へのアクセスが明示的に拒否されていても、<code>/a</code> に対して GetParametersByPath API 操作を再帰的に呼び出し、<code>/a/b</code> を表示できます。</p></blockquote>

<p><code>--parameter-filters</code> (list)</p>

<blockquote><p>リクエスト結果を絞り込むフィルター。</p>
<h4 id="Note">注記</h4>
<p><code>GetParametersByPath</code> では、次の <code>Key</code> の値がサポートされます: <code>Type</code>、<code>KeyId</code>、<code>Label</code>。</p>
<p><code>GetParametersByPath</code> では、次の <code>Key</code> の値はサポートされません: <code>tag</code>、<code>DataType</code>、<code>Name</code>、<code>Path</code>、<code>Tier</code>。</p>
<p>(structure)</p>
<blockquote><p>1 つ以上のフィルター。フィルターを使用すると、より具体的な結果の一覧を返せます。</p>
<p>Key -&gt; (string) [必須]</p>
<blockquote><p>フィルターの名前。</p>
<p><code>ParameterStringFilter</code> オブジェクトは DescribeParameters および GetParametersByPath API 操作で使用します。ただし、<code>Key</code> に列挙されたパターン値のすべてを、両方の操作で使用できるわけではありません。</p>
<p><code>DescribeParameters</code> では、<code>Label</code> を除くすべての列挙されたパターンが有効です。</p>
<p><code>GetParametersByPath</code> では、<code>Key</code> に列挙された次のパターンは無効です: <code>tag</code>、<code>DataType</code>、<code>Name</code>、<code>Path</code>、<code>Tier</code>。</p>
<p>有効なパラメーターフィルターの構成を示す Amazon Web Services CLI コマンド例については、<em>Amazon Web Services Systems Manager ユーザーガイド</em>の <a href="https://docs.aws.amazon.com/systems-manager/latest/userguide/parameter-search.html">Searching for Systems Manager parameters</a> を参照してください。</p>
<p>制約:</p>
<ul><li><p>最小: <code>1</code></p></li><li><p>最大: <code>132</code></p></li><li><p>パターン: <code>^(tag:.+|Name|Type|KeyId|Path|Label|Tier|DataType)$</code></p></li></ul></blockquote>
<p>Option -&gt; (string)</p>
<blockquote><p>DescribeParameters で使用するすべてのフィルターで、有効なオプションは <code>Equals</code> と <code>BeginsWith</code> です。<code>Name</code> フィルターは、さらに <code>Contains</code> オプションもサポートします。(例外: キーに <code>Path</code> を使用するフィルターでは、有効なオプションは <code>Recursive</code> と <code>OneLevel</code> です。)</p>
<p>GetParametersByPath で使用するフィルターで、有効なオプションは <code>Equals</code> と <code>BeginsWith</code> です。(例外: Key 名に <code>Label</code> を使用するフィルターでは、有効なオプションは <code>Equals</code> のみです。)</p>
<p>制約:</p>
<ul><li><p>最小: <code>1</code></p></li><li><p>最大: <code>10</code></p></li></ul></blockquote>
<p>Values -&gt; (list)</p>
<blockquote><p>検索する値。</p>
<p>制約:</p>
<ul><li><p>最小: <code>1</code></p></li><li><p>最大: <code>50</code></p></li></ul>
<p>(string)</p>
<blockquote><p>制約:</p>
<ul><li><p>最小: <code>1</code></p></li><li><p>最大: <code>1024</code></p></li></ul></blockquote></blockquote></blockquote></blockquote>
