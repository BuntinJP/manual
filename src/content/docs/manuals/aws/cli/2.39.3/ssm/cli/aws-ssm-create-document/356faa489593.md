## create-document¶ {#create-document}


### 説明¶ {#Description}


<p>Amazon Web Services Systems Manager ドキュメント (SSM ドキュメント) を作成します。SSM ドキュメントは、Systems Manager がマネージドノードで実行するアクションを定義します。サポートされるスキーマ、機能、構文など、SSM ドキュメントの詳細については、<em>Amazon Web Services Systems Manager ユーザーガイド</em>の <a href="https://docs.aws.amazon.com/systems-manager/latest/userguide/documents.html">Amazon Web Services Systems Manager Documents</a> を参照してください。</p>

<p>関連項目: <a href="https://docs.aws.amazon.com/goto/WebAPI/ssm-2014-11-06/CreateDocument">AWS API Documentation</a></p>
