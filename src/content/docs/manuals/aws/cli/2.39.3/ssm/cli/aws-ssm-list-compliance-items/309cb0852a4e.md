## list-compliance-items¶ {#list-compliance-items}


### 説明¶ {#Description}


<p>指定したリソース ID に対して、異なるリソースタイプのコンプライアンス状態の一覧を返します。現在は、1 回の呼び出しにリソース ID を 1 つだけ指定できます。一覧の結果は、フィルターで指定した条件によって異なります。</p>

<p>関連項目: <a href="https://docs.aws.amazon.com/goto/WebAPI/ssm-2014-11-06/ListComplianceItems">AWS API Documentation</a></p>

<p><code>list-compliance-items</code> はページネーションを行う操作です。結果のデータセット全体を取得するために、複数回の API 呼び出しが行われる場合があります。<code>--no-paginate</code> 引数を指定すると、ページネーションを無効にできます。ページネーションされた応答に対して <code>--output text</code> と <code>--query</code> 引数を使用する場合、<code>--query</code> 引数は次のクエリ式の結果からデータを抽出する必要があります: <code>ComplianceItems</code></p>

<h4 id="Warning">警告</h4>
<p>State Manager の関連付けでは、<code>ExecutionTime</code> の値は Systems Manager サービスがコンプライアンス状態を取得して集約した時刻を表し、必ずしも基となる関連付けがマネージドノードで実行された時刻ではありません。State Manager は、いずれかの関連付けが実行されるたびにインスタンス上のすべての関連付けのコンプライアンス状態を更新するため、異なる時刻に実行された複数の関連付けに同じ実行時刻が表示される場合があります。</p>
<p>ExecutionTime -&gt; (timestamp) [必須]</p>
<blockquote><p>実行が行われた時刻。次の形式で保存される datetime オブジェクトで表します: <code>yyyy-MM-dd&#39;T&#39;HH:mm:ss&#39;Z&#39;</code></p>
<h4 id="Warning-2">警告</h4>
<p>State Manager の関連付けでは、このタイムスタンプは Systems Manager サービスがコンプライアンス状態を取得して報告した時刻を表し、基となる関連付けがマネージドノードで実際に実行された時刻ではありません。実際の関連付けの実行時刻を追跡するには、DescribeAssociationExecutionTargets コマンドを使用するか、Systems Manager コンソールで関連付けの実行履歴を確認してください。</p></blockquote>
