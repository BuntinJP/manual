## delete-association¶ {#delete-association}


### 説明¶ {#Description}


<p>指定した Amazon Web Services Systems Manager ドキュメント (SSM ドキュメント) と指定したマネージドノードとの関連付けを解除します。<code>Targets</code> パラメーターを使用して関連付けを作成した場合は、関連付け ID を使用して関連付けを削除する必要があります。</p>

<p>ドキュメントとマネージドノードとの関連付けを解除しても、ノードの設定は変わりません。ドキュメントの関連付けを解除した後でマネージドノードの設定状態を変更するには、目的の設定を含む新しいドキュメントを作成し、そのノードに関連付ける必要があります。</p>

<p>関連項目: <a href="https://docs.aws.amazon.com/goto/WebAPI/ssm-2014-11-06/DeleteAssociation">AWS API Documentation</a></p>

### オプション¶ {#Options}


<p><code>--name</code> (string)</p>

<blockquote><p>SSM ドキュメントの名前。</p>
<p>制約:</p>
<ul><li><p>パターン: <code>^[a-zA-Z0-9_\-.:/]{3,128}$</code></p></li></ul></blockquote>

<p><code>--instance-id</code> (string)</p>

<blockquote><p>マネージドノードの ID。</p>
<h4 id="Note">注記</h4>
<p><code>InstanceId</code> は非推奨になりました。関連付けにマネージドノードの ID を指定するには、<code>Targets</code> パラメーターを使用します。スキーマバージョン 2.0 以降を使用する Systems Manager ドキュメント (SSM ドキュメント) に対して、<code>InstanceID</code> パラメーターを含むリクエストは失敗します。また、<code>InstanceId</code> パラメーターを使用する場合は、<code>AssociationName</code>、<code>DocumentVersion</code>、<code>MaxErrors</code>、<code>MaxConcurrency</code>、<code>OutputLocation</code>、<code>ScheduleExpression</code> の各パラメーターを使用できません。これらのパラメーターを使用するには、<code>Targets</code> パラメーターを使用する必要があります。</p>
<p>制約:</p>
<ul><li><p>パターン: <code>(^i-(\w{8}|\w{17})$)|(^mi-\w{17}$)</code></p></li></ul></blockquote>

<p><code>--association-id</code> (string)</p>

<blockquote><p>削除する関連付け ID。</p>
<p>制約:</p>
<ul><li><p>パターン: <code>[0-9a-fA-F]{8}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{12}</code></p></li></ul></blockquote>
