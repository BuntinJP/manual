## describe-ops-items¶ {#describe-ops-items}


### 説明¶ {#Description}


<p>OpsItem の集合を照会します。OpsItem の一覧を照会するには、Identity and Access Management (IAM) の権限が必要です。詳細については、<em>Amazon Web Services Systems Manager ユーザーガイド</em>の <a href="https://docs.aws.amazon.com/systems-manager/latest/userguide/OpsCenter-setup.html">Set up OpsCenter</a> を参照してください。</p>

<p>運用エンジニアや IT 担当者は、Amazon Web Services Systems Manager OpsCenter を使用して、Amazon Web Services リソースのパフォーマンスと健全性に影響する運用上の問題を表示、調査、修復します。詳細については、<em>Amazon Web Services Systems Manager ユーザーガイド</em>の <a href="https://docs.aws.amazon.com/systems-manager/latest/userguide/OpsCenter.html">Amazon Web Services Systems Manager OpsCenter</a> を参照してください。</p>

<p>関連項目: <a href="https://docs.aws.amazon.com/goto/WebAPI/ssm-2014-11-06/DescribeOpsItems">AWS API Documentation</a></p>

<p><code>describe-ops-items</code> はページネーションを行う操作です。結果のデータセット全体を取得するために、複数回の API 呼び出しが行われる場合があります。<code>--no-paginate</code> 引数を指定すると、ページネーションを無効にできます。ページネーションされた応答に対して <code>--output text</code> と <code>--query</code> 引数を使用する場合、<code>--query</code> 引数は次のクエリ式の結果からデータを抽出する必要があります: <code>OpsItemSummaries</code></p>
