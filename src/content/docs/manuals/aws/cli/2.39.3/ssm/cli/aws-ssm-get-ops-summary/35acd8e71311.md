## get-ops-summary¶ {#get-ops-summary}


### 説明¶ {#Description}


<p>指定したフィルターと集計器に基づいて、運用メタデータ (OpsData) の概要を表示します。OpsData には、Amazon Web Services Systems Manager OpsCenter の運用作業項目 (OpsItem) に関する情報のほか、Amazon Web Services Systems Manager Explorer に OpsData を報告するよう設定された任意の Amazon Web Services リソースやサービスに関する情報を含めることができます。</p>

<p>関連項目: <a href="https://docs.aws.amazon.com/goto/WebAPI/ssm-2014-11-06/GetOpsSummary">AWS API Documentation</a></p>

<p><code>get-ops-summary</code> はページネーションを行う操作です。結果のデータセット全体を取得するために、複数回の API 呼び出しが行われる場合があります。<code>--no-paginate</code> 引数を指定すると、ページネーションを無効にできます。ページネーションされた応答に対して <code>--output text</code> と <code>--query</code> 引数を使用する場合、<code>--query</code> 引数は次のクエリ式の結果からデータを抽出する必要があります: <code>Entities</code></p>

<p>バイナリ BLOB に使用する書式。既定の形式は base64 です。base64 形式では、バイナリ BLOB を base64 エンコードされた文字列として指定する必要があります。raw-in-base64-out 形式は AWS CLI V1 の動作との互換性を維持し、バイナリ値はそのまま渡す必要があります。バイナリ BLOB に対応する内容をファイルから指定する場合、<code>fileb://</code> は常にバイナリとして扱われ、<code>cli-binary-format</code> の設定にかかわらずファイルの内容が直接使用されます。<code>file://</code> を使用する場合、ファイルの内容を、設定された <code>cli-binary-format</code> に適した形式にする必要があります。</p>

<ul><li><p>base64</p></li><li><p>raw-in-base64-out</p></li></ul>

<p>出力用の CLI ページャーを無効にします。</p>

<p><code>--no-cli-auto-prompt</code> (boolean)</p>
