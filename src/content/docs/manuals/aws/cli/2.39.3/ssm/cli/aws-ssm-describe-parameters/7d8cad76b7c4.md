## describe-parameters¶ {#describe-parameters}


### 説明¶ {#Description}


<p>Amazon Web Services アカウント内のパラメーター、または <a href="https://docs.aws.amazon.com/systems-manager/latest/APIReference/API_DescribeParameters.html#systemsmanager-DescribeParameters-request-Shared">Shared</a> オプションを有効にした場合は自分と共有されたパラメーターを一覧表示します。</p>

<p>リクエスト結果はベストエフォートで返されます。<code>MaxResults</code> を指定した場合、応答には指定した上限までの情報が含まれます。ただし、返される項目数はゼロから <code>MaxResults</code> の値までの範囲になります。結果の処理中にサービスの内部制限に達すると、操作を停止し、その時点までに一致した値と <code>NextToken</code> を返します。後続の呼び出しで <code>NextToken</code> を指定して、次の結果セットを取得できます。</p>

<p>パラメーター名にスペースを含めることはできません。サービスは、パラメーター名の先頭または末尾に指定されたスペースをすべて削除します。指定したパラメーター名の文字の間にスペースがある場合、リクエストは <code>ValidationException</code> エラーで失敗します。</p>

#### 警告 {#Warning}


<p>パラメーターの暗号化に使用した KMS キーのエイリアスを変更した場合は、そのパラメーターが KMS の参照に使用するキーエイリアスも更新する必要があります。そうしない場合、<code>DescribeParameters</code> は元のキーエイリアスが参照していたものを取得します。</p>

<p>関連項目: <a href="https://docs.aws.amazon.com/goto/WebAPI/ssm-2014-11-06/DescribeParameters">AWS API Documentation</a></p>

<p><code>describe-parameters</code> はページネーションを行う操作です。結果のデータセット全体を取得するために、複数回の API 呼び出しが行われる場合があります。<code>--no-paginate</code> 引数を指定すると、ページネーションを無効にできます。ページネーションされた応答に対して <code>--output text</code> と <code>--query</code> 引数を使用する場合、<code>--query</code> 引数は次のクエリ式の結果からデータを抽出する必要があります: <code>Parameters</code></p>
