## create-ops-item¶ {#create-ops-item}


### 説明¶ {#Description}


<p>新しい OpsItem を作成します。新しい OpsItem を作成するには、Identity and Access Management (IAM) の権限が必要です。詳細については、<em>Amazon Web Services Systems Manager ユーザーガイド</em>の <a href="https://docs.aws.amazon.com/systems-manager/latest/userguide/OpsCenter-setup.html">Set up OpsCenter</a> を参照してください。</p>

<p>運用エンジニアや IT 担当者は、Amazon Web Services Systems Manager OpsCenter を使用して、Amazon Web Services リソースのパフォーマンスと健全性に影響する運用上の問題を表示、調査、修復します。詳細については、<em>Amazon Web Services Systems Manager ユーザーガイド</em>の <a href="https://docs.aws.amazon.com/systems-manager/latest/userguide/OpsCenter.html">Amazon Web Services Systems Manager OpsCenter</a> を参照してください。</p>

<p>関連項目: <a href="https://docs.aws.amazon.com/goto/WebAPI/ssm-2014-11-06/CreateOpsItem">AWS API Documentation</a></p>

#### 注記 {#Note-3}


<p>以下の例を使用するには、AWS CLI をインストールして設定しておく必要があります。詳細については、<em>AWS CLI ユーザーガイド</em>の <a href="https://docs.aws.amazon.com/cli/latest/userguide/cli-chap-getting-started.html">Getting started guide</a> を参照してください。</p>

<p>特に断りのない限り、すべての例は Unix 系の引用符規則を使用しています。これらの例は、使用する端末の引用符規則に合わせて調整する必要があります。<em>AWS CLI ユーザーガイド</em>の <a href="https://docs.aws.amazon.com/cli/latest/userguide/cli-usage-parameters-quoting-strings.html">Using quotation marks with strings</a> を参照してください。</p>

<p><strong>OpsItem を作成するには</strong></p>

<p>次の <code>create-ops-item</code> の例は、OperationalData の /aws/resources キーを使用して、Amazon DynamoDB の関連リソースを持つ OpsItem を作成します。</p>

<pre><code>aws ssm create-ops-item \
    --title &quot;EC2 instance disk full&quot; \
    --description &quot;Log clean up may have failed which caused the disk to be full&quot; \
    --priority 2 \
    --source ec2 \
    --operational-data &#39;{&quot;/aws/resources&quot;:{&quot;Value&quot;:&quot;[{\&quot;arn\&quot;: \&quot;arn:aws:dynamodb:us-west-2:12345678:table/OpsItems\&quot;}]&quot;,&quot;Type&quot;:&quot;SearchableString&quot;}}&#39; \
    --notifications Arn=&quot;arn:aws:sns:us-west-2:12345678:TestUser&quot;</code></pre>

<p>出力:</p>

<pre><code>{
    &quot;OpsItemId&quot;: &quot;oi-1a2b3c4d5e6f&quot;
}</code></pre>

<p>詳細については、<em>AWS Systems Manager ユーザーガイド</em>の <a href="https://docs.aws.amazon.com/systems-manager/latest/userguide/OpsCenter-creating-OpsItems-CLI.html">Creating OpsItems manually (AWS CLI)</a> を参照してください。</p>

### 出力¶ {#Output}


<p>OpsItemId -&gt; (string)</p>

<blockquote><p>OpsItem の ID。</p></blockquote>

<p>OpsItemArn -&gt; (string)</p>

<blockquote><p>OpsItem の Amazon リソースネーム (ARN)。</p>
<p>制約:</p>
<ul><li><p>最小: <code>20</code></p></li><li><p>最大: <code>2048</code></p></li><li><p>パターン: <code>arn:(aws[a-zA-Z-]*)?:ssm:[a-z0-9-\.]{0,63}:[0-9]{12}:opsitem.*</code></p></li></ul></blockquote>
