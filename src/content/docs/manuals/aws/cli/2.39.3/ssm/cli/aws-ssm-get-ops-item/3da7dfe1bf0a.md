## get-ops-item¶ {#get-ops-item}


### 説明¶ {#Description}


<p>ID を使って OpsItem の情報を取得します。OpsItem の情報を表示するには、Identity and Access Management (IAM) の権限が必要です。詳細については、<em>Amazon Web Services Systems Manager ユーザーガイド</em>の <a href="https://docs.aws.amazon.com/systems-manager/latest/userguide/OpsCenter-setup.html">Set up OpsCenter</a> を参照してください。</p>

<p>運用エンジニアや IT 担当者は、Amazon Web Services Systems Manager OpsCenter を使用して、Amazon Web Services リソースのパフォーマンスと健全性に影響する運用上の問題を表示、調査、修復します。詳細については、<em>Amazon Web Services Systems Manager ユーザーガイド</em>の <a href="https://docs.aws.amazon.com/systems-manager/latest/userguide/OpsCenter.html">Amazon Web Services Systems Manager OpsCenter</a> を参照してください。</p>

<p>関連項目: <a href="https://docs.aws.amazon.com/goto/WebAPI/ssm-2014-11-06/GetOpsItem">AWS API Documentation</a></p>

<p>制約:</p>
<ul><li><p>最小: <code>1</code></p></li><li><p>最大: <code>64</code></p></li><li><p>パターン: <code>^(?!\s*$).+</code></p></li></ul></blockquote>
<p>Severity -&gt; (string)</p>
<blockquote><p>OpsItem の重要度。選択肢は 1 ～ 4 です。</p>
<p>制約:</p>
<ul><li><p>最小: <code>1</code></p></li><li><p>最大: <code>64</code></p></li><li><p>パターン: <code>^(?!\s*$).+</code></p></li></ul></blockquote>
<p>ActualStartTime -&gt; (timestamp)</p>
<blockquote><p>ランブックワークフローが開始された時刻。現在は OpsItem タイプ <code>/aws/changerequest</code> についてのみ報告されます。</p></blockquote>
<p>ActualEndTime -&gt; (timestamp)</p>
<blockquote><p>ランブックワークフローが終了した時刻。現在は OpsItem タイプ <code>/aws/changerequest</code> についてのみ報告されます。</p></blockquote>
<p>PlannedStartTime -&gt; (timestamp)</p>
<blockquote><p>ランブックワークフローの開始について変更要求で指定された時刻。現在は OpsItem タイプ <code>/aws/changerequest</code> についてのみサポートされます。</p></blockquote>
<p>PlannedEndTime -&gt; (timestamp)</p>
<blockquote><p>ランブックワークフローの終了について変更要求で指定された時刻。現在は OpsItem タイプ <code>/aws/changerequest</code> についてのみサポートされます。</p></blockquote>
<p>OpsItemArn -&gt; (string)</p>
<blockquote><p>OpsItem の Amazon リソースネーム (ARN)。</p>
<p>制約:</p>
<ul><li><p>最小: <code>20</code></p></li><li><p>最大: <code>2048</code></p></li><li><p>パターン: <code>arn:(aws[a-zA-Z-]*)?:ssm:[a-z0-9-\.]{0,63}:[0-9]{12}:opsitem.*</code></p></li></ul></blockquote></blockquote>
