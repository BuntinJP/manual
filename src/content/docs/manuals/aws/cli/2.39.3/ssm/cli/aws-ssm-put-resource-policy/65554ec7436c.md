## put-resource-policy¶ {#put-resource-policy}


### 説明¶ {#Description}


<p>Systems Manager のリソースポリシーを作成または更新します。リソースポリシーを使用すると、Systems Manager リソースを管理できる IAM エンティティ (Amazon Web Services アカウントなど) を定義できます。以下のリソースは Systems Manager のリソースポリシーをサポートしています。</p>

<ul><li><p><code>OpsItemGroup</code> - <code>OpsItemGroup</code> のリソースポリシーにより、Amazon Web Services アカウントは OpsCenter の運用作業項目 (OpsItem) を表示して操作できます。</p></li><li><p><code>Parameter</code> - リソースポリシーは、Resource Access Manager (RAM) を使ってパラメーターをほかのアカウントと共有するために使用されます。パラメーターを共有するには、アドバンストパラメーター階層に属している必要があります。パラメーター階層については、<a href="https://docs.aws.amazon.com/systems-manager/latest/userguide/parameter-store-advanced-parameters.html">Managing parameter tiers</a> を参照してください。既存のスタンダードパラメーターをアドバンストパラメーターに変更する方法については、<a href="https://docs.aws.amazon.com/systems-manager/latest/userguide/parameter-store-advanced-parameters.html#parameter-store-advanced-parameters-enabling">Changing a standard parameter to an advanced parameter</a> を参照してください。<code>SecureString</code> パラメーターを共有するには、カスタマーマネージドキーで暗号化し、そのキーを Key Management Service を通じて別途共有する必要があります。Amazon Web Services マネージドキーは共有できません。既定の Amazon Web Services マネージドキーで暗号化されたパラメーターは、代わりにカスタマーマネージドキーを使用するよう更新できます。KMS キーの定義については、<em>Key Management Service デベロッパーガイド</em>の <a href="https://docs.aws.amazon.com/kms/latest/developerguide/concepts.html">KMS concepts</a> を参照してください。</p></li></ul>

#### 警告 {#Warning}


<p>Systems Manager の <code>PutResourcePolicy</code> 操作を使用してパラメーターを共有できますが、代わりに Resource Access Manager (RAM) を使用することをお勧めします。<code>PutResourcePolicy</code> を使用すると、RAM の <a href="https://docs.aws.amazon.com/ram/latest/APIReference/API_PromoteResourceShareCreatedFromPolicy.html">PromoteResourceShareCreatedFromPolicy</a> API 操作を使用してパラメーターを標準の RAM リソース共有に昇格させる追加手順が必要になるためです。この手順を行わないと、<code>--shared</code> オプションを使用する Systems Manager の <a href="https://docs.aws.amazon.com/systems-manager/latest/APIReference/API_DescribeParameters.html">DescribeParameters</a> API 操作でパラメーターが返されません。詳細については、<em>Amazon Web Services Systems Manager ユーザーガイド</em>の <a href="https://docs.aws.amazon.com/systems-manager/latest/userguide/parameter-store-shared-parameters.html#share">Sharing a parameter</a> を参照してください。</p>

<ul><li><p><code>Document</code> - Resource Access Manager (RAM) を使ってドキュメントを共有します。ドキュメントの共有の詳細については、<em>Amazon Web Services Systems Manager ユーザーガイド</em>の <a href="https://docs.aws.amazon.com/systems-manager/latest/userguide/documents-ssm-sharing.html">Sharing Systems Manager documents</a> を参照してください。</p></li></ul>

#### 警告 {#Warning-2}


<p>Systems Manager の <code>PutResourcePolicy</code> 操作を使用してドキュメントを共有できますが、代わりに Resource Access Manager (RAM) を使用することをお勧めします。<code>PutResourcePolicy</code> を使用すると追加手順が必要です。RAM の <a href="https://docs.aws.amazon.com/ram/latest/APIReference/API_PromoteResourceShareCreatedFromPolicy.html">PromoteResourceShareCreatedFromPolicy</a> API 操作を使用して、ドキュメントを標準の RAM リソース共有に昇格させる必要があります。この手順を行わないと、共有ドキュメントでフィルタリングする際に、Systems Manager の <a href="https://docs.aws.amazon.com/systems-manager/latest/APIReference/API_ListDocuments.html">ListDocuments</a> API 操作でドキュメントが返されません。また、Amazon Web Services Config の <a href="https://docs.aws.amazon.com/config/latest/APIReference/API_PutRemediationConfigurations.html">PutRemediationConfigurations</a> API 操作でも、そのドキュメントを使用できません。</p>
