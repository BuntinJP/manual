## describe-instance-patch-states¶ {#describe-instance-patch-states}


### 説明¶ {#Description}

<p>InstanceId -&gt; (string) [必須]</p>
<blockquote><p>概要レベルのパッチコンプライアンス情報を収集したマネージドノードの ID。</p>
<p>制約:</p>
<ul><li><p>パターン: <code>(^i-(\w{8}|\w{17})$)|(^mi-\w{17}$)</code></p></li></ul></blockquote>
<p>PatchGroup -&gt; (string) [必須]</p>
<blockquote><p>マネージドノードが属するパッチグループの名前。</p>
<p>制約:</p>
<ul><li><p>最小: <code>1</code></p></li><li><p>最大: <code>256</code></p></li><li><p>パターン: <code>^([\p{L}\p{Z}\p{N}_.:/=+\-@]*)$</code></p></li></ul></blockquote>
<p>BaselineId -&gt; (string) [必須]</p>
<blockquote><p>マネージドノードへのパッチ適用に使用したパッチベースラインの ID。</p>
<p>制約:</p>
<ul><li><p>最小: <code>20</code></p></li><li><p>最大: <code>128</code></p></li><li><p>パターン: <code>^[a-zA-Z0-9_\-:/]{20,128}$</code></p></li></ul></blockquote>
<p>SnapshotId -&gt; (string)</p>
<blockquote><p>このコンプライアンスデータを収集したパッチ操作で使用した、パッチベースラインスナップショットの ID。</p>
<p>制約:</p>
<ul><li><p>最小: <code>36</code></p></li><li><p>最大: <code>36</code></p></li><li><p>パターン: <code>^[0-9a-fA-F]{8}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{4}-[0-9a-fA-F]{12}$</code></p></li></ul></blockquote>
<p>InstallOverrideList -&gt; (string)</p>
<blockquote><p>インストールするパッチの一覧を指す https URL または Amazon Simple Storage Service (Amazon S3) のパス形式 URL。このパッチインストール一覧は、S3 バケットに YAML 形式で保持し、SSM ドキュメント <code>AWS-RunPatchBaseline</code> で指定します。既定のパッチベースラインで指定されたパッチより優先されます。</p>
<p><code>InstallOverrideList</code> パラメーターの詳細については、<em>Amazon Web Services Systems Manager ユーザーガイド</em>の「パッチ適用用 SSM Command ドキュメント: ``AWS-RunPatchBaseline` <a href="https://docs.aws.amazon.com/systems-manager/latest/userguide/patch-manager-about-aws-runpatchbaseline">https://docs.aws.amazon.com/systems-manager/latest/userguide/patch-manager-about-aws-runpatchbaseline</a>.html`__」を参照してください。</p>
<p>制約:</p>
<ul><li><p>最小: <code>1</code></p></li><li><p>最大: <code>256</code></p></li><li><p>パターン: <code>^https://.+$|^s3://([^/]+)/(.*?([^/]+))$</code></p></li></ul></blockquote>
<p>OwnerInformation -&gt; (string)</p>
<blockquote><p>プレースホルダー情報。現在のサービスリリースでは、このフィールドは常に空です。</p>
<p>制約:</p>
<ul><li><p>最小: <code>1</code></p></li><li><p>最大: <code>128</code></p></li></ul></blockquote>
<p>InstalledCount -&gt; (integer)</p>
<blockquote><p>パッチベースラインに含まれ、マネージドノードにインストールされているパッチの数。</p></blockquote>
<p>InstalledOtherCount -&gt; (integer)</p>
<blockquote><p>パッチベースラインに指定されておらず、マネージドノードにインストールされているパッチの数。</p></blockquote>
<p>InstalledPendingRebootCount -&gt; (integer)</p>
<blockquote><p>マネージドノードの最終再起動以降に Patch Manager がインストールしたパッチの数。</p></blockquote>
<p>InstalledRejectedCount -&gt; (integer)</p>
<blockquote><p><code>RejectedPatches</code> 一覧に指定され、マネージドノードにインストールされているパッチの数。状態が <code>InstalledRejected</code> のパッチは通常、<code>RejectedPatches</code> 一覧に追加される前にインストールされたものです。</p>
<h4 id="Note-2">注記</h4>
<p><code>RejectedPatchesAction</code> に指定されたオプションが <code>ALLOW_AS_DEPENDENCY</code> の場合、<code>InstalledRejectedCount</code> の値は常に <code>0</code> (ゼロ) になります。</p></blockquote>
<p>MissingCount -&gt; (integer)</p>
<blockquote><p>パッチベースラインに含まれ、そのマネージドノードに適用可能であるにもかかわらず、現在インストールされていないパッチの数。</p></blockquote>
<p>FailedCount -&gt; (integer)</p>
<blockquote><p>パッチベースラインに含まれ、直近のパッチ操作でインストールを試みたものの失敗したパッチの数。</p></blockquote>
<p>UnreportedNotApplicableCount -&gt; (integer)</p>
<blockquote><p>サポートされる上限 <code>NotApplicableCount</code> を超えており、名前付きで Inventory に報告されないパッチの数。Inventory は Amazon Web Services Systems Manager のツールです。</p></blockquote>
<p>NotApplicableCount -&gt; (integer)</p>
<blockquote><p>パッチベースラインに含まれるものの、マネージドノードに適用できないためインストールされていないパッチの数。パッチ名の一覧が非常に大きい場合、この数は途中で打ち切られることがあります。この制限を超えるパッチ数は <code>UnreportedNotApplicableCount</code> に報告されます。</p></blockquote>
<p>AvailableSecurityUpdateCount -&gt; (integer)</p>
<blockquote><p>利用可能でも、パッチベースラインの要件を満たしていないため承認されていないセキュリティ関連パッチの数。たとえば、指定した自動承認期間が終わる前に、パッチの更新版がリリースされた場合があります。</p>
<p>Windows Server マネージドノードにのみ適用されます。</p></blockquote>
<p>OperationStartTime -&gt; (timestamp) [必須]</p>
<blockquote><p>マネージドノードで直近のパッチ操作が開始された時刻。</p></blockquote>
<p>OperationEndTime -&gt; (timestamp) [必須]</p>
<blockquote><p>マネージドノードで直近のパッチ操作が完了した時刻。</p></blockquote>
<p>Operation -&gt; (string) [必須]</p>
<blockquote><p>実行されたパッチ操作の種類: または</p>
<ul><li><p><code>SCAN</code> はパッチコンプライアンス状態を評価します。</p></li><li><p><code>INSTALL</code> は不足しているパッチをインストールします。</p></li></ul>
<p>指定可能な値:</p>
<ul><li><p><code>Scan</code></p></li><li><p><code>Install</code></p></li></ul></blockquote>
<p>LastNoRebootInstallOperationTime -&gt; (timestamp)</p>
<blockquote><p>再起動オプションに <code>NoReboot</code> を指定して、マネージドノードへのパッチ適用を最後に試みた時刻。</p></blockquote>
<p>RebootOption -&gt; (string)</p>
<blockquote><p>パッチベースラインで指定された再起動オプションを示します。</p>
<h4 id="Note-3">注記</h4>
<p>再起動オプションは <code>Install</code> 操作にのみ適用されます。Patch Manager の <code>Scan</code> 操作では再起動は試みられません。</p>
<ul><li><p><code>RebootIfNeeded</code>: パッチがインストールされた場合、または状態が <code>InstalledPendingReboot</code> のパッチが検出された場合、Patch Manager はマネージドノードの再起動を試みます。</p></li><li><p><code>NoReboot</code>: Patch Manager は、システムの再起動を試みずに不足しているパッケージのインストールを試みます。このオプションでインストールされたパッチの状態は <code>InstalledPendingReboot</code> になります。これらのパッチは、再起動するまで有効にならない場合があります。</p></li></ul>
<p>指定可能な値:</p>
<ul><li><p><code>RebootIfNeeded</code></p></li><li><p><code>NoReboot</code></p></li></ul></blockquote>
<p>CriticalNonCompliantCount -&gt; (integer)</p>
<blockquote><p>パッチベースラインのコンプライアンス報告で <code>Critical</code> と指定されているものの、インストールされていないパッチのノードごとの数。これらのパッチは、不足、インストール失敗、拒否、またはインストール済みで必要なマネージドノードの再起動待ちの可能性があります。これらのマネージドノードの状態は <code>NON_COMPLIANT</code> です。</p></blockquote>
<p>SecurityNonCompliantCount -&gt; (integer)</p>
<blockquote><p>パッチアドバイザリで <code>Security</code> と指定されているものの、インストールされていないパッチのノードごとの数。これらのパッチは、不足、インストール失敗、拒否、またはインストール済みで必要なマネージドノードの再起動待ちの可能性があります。これらのマネージドノードの状態は <code>NON_COMPLIANT</code> です。</p></blockquote>
<p>OtherNonCompliantCount -&gt; (integer)</p>
<blockquote><p><code>Critical</code> または <code>Security</code> 以外に指定され、パッチベースラインに準拠していないパッチのノードごとの数。これらのマネージドノードの状態は <code>NON_COMPLIANT</code> です。</p></blockquote></blockquote></blockquote>

<p>NextToken -&gt; (string)</p>

<blockquote><p>次の項目セットを要求するときに使用するトークン。返す追加項目がない場合、この文字列は空です。</p></blockquote>
