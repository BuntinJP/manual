## get-default-patch-baseline¶ {#get-default-patch-baseline}


### 説明¶ {#Description}


<p>既定のパッチベースラインを取得します。Amazon Web Services Systems Manager は、複数の既定のパッチベースラインの作成をサポートしています。たとえば、オペレーティングシステムごとに既定のパッチベースラインを作成できます。</p>

<p>オペレーティングシステムの値を指定しない場合、Windows の既定のパッチベースラインが返されます。</p>

<p>関連項目: <a href="https://docs.aws.amazon.com/goto/WebAPI/ssm-2014-11-06/GetDefaultPatchBaseline">AWS API Documentation</a></p>
