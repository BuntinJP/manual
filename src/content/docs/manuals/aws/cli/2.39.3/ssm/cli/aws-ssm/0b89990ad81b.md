## ssm¶ {#ssm}


### 説明¶ {#Description}


<p>Amazon Web Services Systems Manager は、Amazon Web Services のアプリケーションとリソースの運用ハブであり、大規模でも安全でセキュアな運用を可能にする、ハイブリッドクラウド環境向けのセキュアなエンドツーエンド管理ソリューションです。</p>

<p>このリファレンスは <a href="https://docs.aws.amazon.com/systems-manager/latest/userguide/">Amazon Web Services Systems Manager User Guide</a> と併用することを想定しています。利用を開始するには、<a href="https://docs.aws.amazon.com/systems-manager/latest/userguide/systems-manager-setting-up-console.html">Setting up Amazon Web Services Systems Manager</a> を参照してください。</p>

<blockquote><p><strong>関連リソース</strong></p></blockquote>

<ul><li><p>Systems Manager を構成する各ツールの情報については、<em>Amazon Web Services Systems Manager ユーザーガイド</em>の <a href="https://docs.aws.amazon.com/systems-manager/latest/userguide/systems-manager-tools.html">Using Systems Manager tools</a> を参照してください。</p></li><li><p>Amazon Web Services Systems Manager のツールである Automation の事前定義ランブックの詳細については、* <a href="https://docs.aws.amazon.com/systems-manager-automation-runbooks/latest/userguide/automation-runbook-reference.html">Systems Manager Automation Runbook Reference</a> * を参照してください。</p></li><li><p>Systems Manager のツールである AppConfig については、* <a href="https://docs.aws.amazon.com/appconfig/latest/userguide/">AppConfig User Guide</a> * および * <a href="https://docs.aws.amazon.com/appconfig/2019-10-09/APIReference/">AppConfig API Reference</a> * を参照してください。</p></li><li><p>Systems Manager のツールである Incident Manager については、* <a href="https://docs.aws.amazon.com/incident-manager/latest/userguide/">Systems Manager Incident Manager User Guide</a> * および * <a href="https://docs.aws.amazon.com/incident-manager/latest/APIReference/">Systems Manager Incident Manager API Reference</a> * を参照してください。</p></li></ul>
