### 名前 {#NAME}


<p><code>paste</code> — ファイルの対応する行、または連続する行を結合する</p>

### 書式 {#SYNOPSIS}


<div class="manual-table"><table><tbody><tr><td><p><code>paste</code></p></td><td><p>[<code>-s</code>] [<code>-d</code> <em>list</em>] <em>file ...</em></p></td></tr></tbody></table></div>

### 説明 {#DESCRIPTION}


<p><code>paste</code> ユーティリティは、指定された入力ファイルの対応する行を連結し、最後のファイル以外の改行文字を単一のタブ文字に置き換えて、結果の行を標準出力へ書き出します。他の入力ファイルにまだデータがある間に、ある入力ファイルがファイル末尾に達した場合、そのファイルは空行を無限に供給するものとして扱われます。</p>

<p>オプションは次のとおりです。</p>

<dl><dt><code>-d</code> <em>list</em></dt><dd><p>既定のタブの代わりに、指定した 1 文字以上の文字で改行文字を置き換えます。<em>list</em> の文字は循環して使用されます。つまり、<em>list</em> を使い切ると、<em>list</em> の最初の文字を再び使用します。これは、最後の入力ファイルの行（既定の動作の場合）または各ファイルの最後の行（<code>-s</code> オプションを使用する場合）が表示されるまで続きます。その時点で、<code>paste</code> は再び <em>list</em> の先頭から文字を選び始めます。</p>
<p>list では、次の特殊文字も使用できます。</p>
<dl><dt><code>\n</code></dt><dd><p>改行文字</p></dd><dt><code>\t</code></dt><dd><p>タブ文字</p></dd><dt><code>\\</code></dt><dd><p>バックスラッシュ文字</p></dd><dt><code>\0</code></dt><dd><p>空文字列（ヌル文字ではありません）</p></dd></dl>
<p>これら以外の文字の前にバックスラッシュを付けた場合、その文字自体と同じ意味になります。</p></dd><dt><code>-s</code></dt><dd><p>各入力ファイルのすべての行を、コマンドラインの順序でファイルごとに連結します。各入力ファイルの最終行以外のすべての行の改行文字は、<code>-d</code> オプションで別途指定しない限り、タブ文字に置き換えられます。</p></dd></dl>

<p>1 つ以上の入力ファイルに「-」を指定した場合、標準入力を使用します。標準入力は「-」の各出現に対して、順に循環しながら 1 行ずつ読み取られます。</p>

### 終了ステータス {#EXIT_STATUS}


<p><code>paste</code> ユーティリティは、成功した場合は 0、エラーが発生した場合は 0 より大きい値で終了します。</p>

### 使用例 {#EXAMPLES}


<p>カレントディレクトリのファイルを 3 列で一覧表示します。</p>

<pre><code>$ ls | paste - - -
$ ls | paste -s -d &#39;\t\t\n&#39; -</code></pre>

<p><em>file</em> の 2 行ずつを 1 行に結合します。</p>

<pre><code>$ paste - - &lt; file
$ paste -s -d &#39;\t\n&#39; file</code></pre>

<p>「<code>cat -n</code>」と同様に、<em>file</em> の行に番号を付けます。</p>

<pre><code>$ sed = file | paste - -
$ sed = file | paste -s -d &#39;\t\n&#39; -</code></pre>

<p><code>PATH</code> 環境変数に使用できるように、bin という名前のディレクトリのコロン区切りリストを作成します。</p>

<p><code>$ find / -name bin -type d | paste -s -d : -</code></p>
