### デプロイ {#Deployment}


<p>警告</p>

<p>ログインできない場合は、localhost または HTTPS 経由でサービスにアクセスしていることを確認してください。それ以外の場合は HTTP_ALLOWED=true を設定してください。</p>

<pre><code># docker-compose.yml
services:
  convertx:
    image: ghcr.io/c4illin/convertx
    container_name: convertx
    restart: unless-stopped
    ports:
      - &quot;3000:3000&quot;
    environment:
      - PUID=1000 # user id for file permissions (should match your host user id)
      - JWT_SECRET=aLongAndSecretStringUsedToSignTheJSONWebToken1234 # will use randomUUID() if unset
      # - HTTP_ALLOWED=true # uncomment this if accessing it over a non-https connection
    volumes:
      - ./data:/app/data</code></pre>

<p>または</p>

<pre><code>docker run -p 3000:3000 -e PUID=1000 -e PGID=1000 -v ./data:/app/data ghcr.io/c4illin/convertx</code></pre>

<p>マッピングした <code>./data</code> ボリュームで権限の問題が起きないように、<code>PUID</code> と <code>PGID</code> をホストのユーザー（<code>id -u</code> と <code>id -g</code>）に合わせてください。unable to open database file が表示される場合は、ディレクトリーの権限を確認するか、選択したパスに対して <code>chown -R $USER:$USER path</code> を実行してください。</p>

<p>続いてブラウザーで <code>http://localhost:3000</code> を開き、アカウントを作成してください。誰でも最初のアカウントを登録できるため、未設定のまま外部からアクセスできる状態で放置しないでください。</p>

#### 環境変数 {#Environment-variables}


<p>すべて省略可能ですが、JWT_SECRET の設定を推奨します。</p>

<p>警告</p>

<p>ALLOW_UNAUTHENTICATED または ACCOUNT_REGISTRATION が true の状態で、サービスをインターネットに公開してはいけません。信頼できるユーザーだけにサービスへのアクセスを許可してください。</p>
