# 2026-11-13 日本語訳バッチの統合

## 範囲

AWS CLI 2.39.3 / SSM の95文書と、macOS 27.2 / 26B123 の systemextensionsctl(8) を、保存原文と同じリビジョンへ統合する。

- 初回統合は、原文抽出と独立意味レビューを確認済みの96件に限定。
- 他の翻訳案・部分訳、抽出欠落が判明した文書はこのバッチの受理対象に含めない。
- 原文・IRは既存mainのまま保持。原文の版やサービス仕様を翻訳側で推測変更しない。

## キューと担当

2026-11-04の取り込み記録が示す担当解放の引継ぎに従い、最新mainを同期した統合作業ツリー1つだけをキューwriterとした。今回の作業環境では、開始前にキュー操作プロセス・ロックがないこと、全305ジョブがpendingで予約なしであることを確認。旧Macの現在の未保存状態は直接確認できていないため、その作業ツリーを書き換えたり回復操作を行ったりはしていない。

独立翻訳workerは原文を読んで候補JSONを保存するだけで、各workerが別々の正本キューを操作する構成にはしていない。公式queueのnext/save/review/completeを統合担当だけが順番に実行し、原文・IRハッシュと独立レビュー対象の訳文ハッシュが一致したものだけを受理する。

## 確認範囲

- 原文HTML本文とIR全文の空白除外一致（AWS95件）。独立照合も実施。
- 翻訳担当とは別のレビュー担当が条件、否定、既定値、削除・権限・待機条件等を確認。同一原文・保護要素・同一訳に限る厳密一致再利用を含む。
- 各文書の translation/review.md に確認範囲と原文/IR/訳文SHAを保存。
- 公式validateTranslationによるID網羅、空訳、保護トークンとstyle入れ子検証。
- 公式IRレンダラーによる表・コード例を含むページ生成。
- 自動検証や原文との一致は、サービス実行結果や現在仕様の保証ではない。

## 原文由来の注意

get-resource-policiesとput-resource-policyの対応対象記述など、保存原文間に仕様上の不整合がある。これらは翻訳で独自に統一していない。利用時は対象版の公式文書・サービス仕様も確認すること。
