# 翻訳の独立レビュー

レビュー日: 2026-09-06。翻訳担当と同じ作業で、Apple macOS 26.6.2（25g83）の `tar(1)` 原文 `source.roff`、`ir.json`、依頼 JSON、用語集、および `translation/ja.json` の全 368 セグメントを読み合わせました。

対象範囲は NAME から BUGS までです。見出し 13、書式 4 系統、オプション定義、環境変数、終了ステータス、使用例、互換性、セキュリティ、規格、歴史、既知の制限を含みます。mtree 入力例などの literal ブロックは IR 側に残り、翻訳対象ではありません。

重大な意味の反転、条件の欠落、本文の翻訳漏れは検出しませんでした。特に次を確認しています。

- 展開可能な形式（tar, pax, cpio, zip, jar, ar, xar, rpm, 7-zip, ISO 9660）と作成可能な形式（tar, pax, cpio, ar, zip, 7-zip, shar）の差。
- `-r` / `-u` は非圧縮の通常ファイルでのみ動作し、`-f` が必須。展開時は後の同名エントリが先を上書き。
- 除外は包含およびコマンドライン指定より優先。包含未指定時は全エントリ処理。
- ACL / fflags / mac-metadata / xattrs の既定はモードと root / 非 root、および Mac OS X 例外に依存。`--acls` は Mac OS X では拡張 ACL を NFSv4 ACL へ変換し、拡張 ACL の格納には `--mac-metadata` を推奨。
- ブロックサイズは 512 バイトレコード単位、既定 20 レコード（10240 バイト）。`-f` の既定は FreeBSD `/dev/sa0`、Linux `/dev/st0`。macOS の既定は原文に無いため補っていません。
- 圧縮オプションは作成時のみ意味を持ち、展開・一覧では無視。読み取り時は自動認識。`--lzma` は非推奨で `--xz` を使う。
- `--newer` 系と `--older` 系の ctime / mtime、ファイル基準と日付基準の区別。`--one-file-system` はマウントポイントを越えない。
- `--no-*` は対応する肯定オプションの逆。非 root の x モード既定、`-O` の展開先が標準出力・一覧先が標準エラー出力、`-o` の x モードと c/r/u モードでの意味の違い。
- 数値範囲: gzip / lrzip / lzop は 1–9、xz は 0–9、lz4 ブロックサイズは 4–7（既定 7）、zstd のよくある値は 1–22、フレーム閾値 1,024 未満は拒否、スレッド 0 は CPU コア数。
- `lz4:compression-level` の説明が lzop 圧縮レベルとなっている原文の文言は訂正していません。
- `-s` の基本正規表現、`~` / `\1`–`\9`、末尾修飾子 g/s/p/b と H/R/S（抑制）対 h/r/s（有効）、既定 `hrs`。`--strip-components` は包含／除外の後、セキュリティ検査の前にパスを編集。
- `-T` の `-C` 行、`--null` がその特別扱いを無効にすること。終了ステータスは成功 0、エラー >0。
- セキュリティの 3 経路（絶対パス、`..`、シンボリックリンク）。既定の防御、`-U` による中間リンク削除、`-P` による検査無効化、`-k` 非上書き。
- 規格: tar は ISO/IEC 9945-1:1996 に現れ IEEE Std 1003.1-2001 で削除。GNU tar 1.15 未満の `-l` は `--one-file-system` の同義。歴史の年月（1979-01、1987-11 頃、FreeBSD 1.0 / 5.4、2005-05）。
- `r` / `u` は非圧縮通常ファイル必須。`@foo` と `-foo` は `./` 付きで指定。作成時の先頭 `./` は常に削除、先頭 `/` は `-P` が無いと削除。マルチボリューム未対応。
