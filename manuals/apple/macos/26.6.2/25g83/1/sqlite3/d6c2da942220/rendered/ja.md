## 名前 {#NAME}


<p><strong>sqlite3</strong> - SQLite バージョン 3 のコマンドラインインタフェース</p>

## 書式 {#SYNOPSIS}


<p><strong>sqlite3</strong> [<em>options</em>] [<em>databasefile</em>] [<em>SQL</em>]</p>

## 概要 {#SUMMARY}


<p><strong>sqlite3</strong> は、問い合わせを対話的に評価し、結果を複数の形式で表示できる、SQLite ライブラリの端末ベースのフロントエンドです。<strong>sqlite3</strong> は、シェルスクリプトやほかのアプリケーション内でバッチ処理機能を提供するためにも使えます。</p>

## 説明 {#DESCRIPTION}


<p><strong>sqlite3</strong> の対話セッションを始めるには、<strong>sqlite3</strong> コマンドを起動し、必要に応じてデータベースファイルの名前を指定します。データベースファイルが存在しない場合は作成されます。データベースファイルが存在する場合は開かれます。</p>

<p>たとえば、&quot;mydata.db&quot; という新しいデータベースファイルを作成し、&quot;memos&quot; という表を作成して、その表にいくつかのレコードを挿入するには、次のようにします。</p>

<p>$ <strong>sqlite3 mydata.db</strong> <br> SQLite version 3.43.2 2023-10-10 13:08:14 <br> 使用法のヒントは &quot;.help&quot; を入力してください。 <br> sqlite&gt; <strong>CREATE TABLE memos(text, priority INTEGER);</strong> <br> sqlite&gt; <strong>INSERT INTO memos VALUES(&#39;deliver project description&#39;, 10);</strong> <br> sqlite&gt; <strong>INSERT INTO memos VALUES(&#39;lunch with Christine&#39;, 100);</strong> <br> sqlite&gt; <strong>SELECT * FROM memos;</strong> <br> deliver project description|10 <br> lunch with Christine|100 <br> sqlite&gt;</p>

<p>データベース名を指定しない場合は、ATTACH sql コマンドを使って、既存のデータベースファイルに接続したり、新しいデータベースファイルを作成したりできます。ATTACH は、同じ対話セッション内で複数のデータベースに接続するためにも使えます。これは、途中でスキーマを変更しながら、データベース間でデータを移行する場合に便利です。</p>

<p>必要に応じて、1 つの引数として SQL 文、または一連の SQL 文を指定できます。複数の文はセミコロンで区切ってください。</p>

<p>例:</p>

<p>$ <strong>sqlite3 <code>-line</code> mydata.db &#39;SELECT * FROM memos WHERE priority &gt; 20;&#39;</strong> <br> text = lunch with Christine <br> priority = 100</p>

### SQLite メタコマンド {#SQLITE_META-COMMANDS}


<p>対話型インタプリタは、出力形式の制御、現在接続されているデータベースファイルの調査、または接続されたデータベースに対する管理操作（インデックスの再構築など）に使える一連のメタコマンドを提供します。メタコマンドには、常にドット（.）の接頭辞が付きます。</p>

<p>利用可能なメタコマンドの一覧は、いつでも &#39;.help&#39; コマンドを発行することで表示できます。たとえば:</p>

<p>sqlite&gt; <strong>.help</strong></p>

<pre><code></code></pre>

<p>利用可能なコマンドは版とビルドオプションによって異なるため、ここでは列挙しません。利用可能なすべてのオプションについては、手元のコピーを参照してください。</p>

## 初期化ファイル {#INIT_FILE}


<p><strong>sqlite3</strong> は、対話環境の設定を行うために初期化ファイルを読みます。初期化の過程では、それ以前に指定された設定は上書きできます。初期化の順序は次のとおりです。</p>

<p>o 既定の設定は次のように確立されます。</p>

<pre><code>mode            = LIST
separator       = &quot;|&quot;
main prompt     = &quot;sqlite&gt; &quot;
continue prompt = &quot;   ...&gt; &quot;
</code></pre>

<p>o ファイル <strong>${XDG_CONFIG_HOME}/sqlite3/sqliterc</strong> または <strong>~/.sqliterc</strong> が存在する場合、見つかったほうのうち最初のものが起動時に処理されます。通常はメタコマンドだけを含めるべきです。</p>

<p>o <code>-init</code> オプションがある場合、指定されたファイルが処理されます。</p>

<p>o その他のコマンドラインオプションはすべて処理されます。</p>
