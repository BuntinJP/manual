### 名前 {#Name}


<p>vfs_streams_xattr — 代替データストリームを POSIX 拡張属性に保存する</p>

### 書式 {#Synopsis}


<p><code>vfs objects = streams_xattr</code></p>

### 説明 {#DESCRIPTION}


<p>この VFS モジュールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.7.html">samba(7)</a> スイートの一部です。</p>

<p><code>vfs_streams_xattr</code> は、NTFS の代替データストリームをファイルシステムに保存できるようにします。通常の POSIX ファイルシステムは1つのファイルに複数のデータストリームを持つ概念をサポートしないため、streams_xattr モジュールは POSIX 拡張属性（xattr）にデータを保存します。これらの属性名は既定で user.DosStream.&quot;ADS-NAME&quot; です。接頭辞 &quot;user.DosStream.&quot; は <code>streams_xattr:prefix</code> モジュールオプションで変更できますが、変更すると SMB 拡張属性インターフェース経由でも ADS が公開されることに注意してください。</p>

<p>このモジュールを有効にして共有するファイルシステムは、xattr をサポートする必要があります。</p>

<p>ほとんどのファイルシステムでは xattr のサイズに厳しい制限があることに注意してください。そのため、ストリームに小さなゾーン情報を保存する IE のようなアプリケーションでは動作しても、ADS に大量のデータを保存するアプリケーションでは失敗します。</p>

### オプション {#OPTIONS}


<dl><dt>streams_xattr:prefix = STRING</dt><dd><p>ADS を xattr に保存するときに使う名前の接頭辞です。既定値は <code>user.DosStream.</code> です。変更すると SMB 拡張属性インターフェース経由でも ADS が公開されます。</p></dd><dt>streams_xattr:store_stream_type = [yes|no]</dt><dd><p>タイプ &quot;$DATA&quot; の代替データストリームの xattr 名に、ストリームタイプ文字列 &quot;:$DATA&quot; を接尾辞として付けるかどうかです。既定値は <code>yes</code> です。</p></dd><dt>streams_xattr:max xattrs per stream = NUM</dt><dd><p>単一 xattr のサイズ上限が inode ごとの xattr 合計サイズ上限より小さいファイルシステムでは、このパラメーターを2から16の値に設定すると、smbd は単一 xattr に収まらない大きさのストリームを保存できます。たとえば Linux の xattr ごとの上限は64kBですが、XFS は inode ごとにはそれ以上を保存できます。</p>
<p>単一 xattr のサイズは smb.conf パラメーター <code>smbd max xattr size</code> で制限されます。</p>
<p>代替データストリーム1つにつき最大16個の xattr に制限されます。</p>
<p>既定値は <code>1</code> で、この機能が導入される前の既定の動作と互換性があります。</p></dd><dt>streams_xattr:ext_prefix = STRING</dt><dd><p>ストリームのあふれた部分の xattr を保存する際に使う名前の接頭辞です。既定では <code>streams_xattr:prefix</code> に文字列 &quot;Ext&quot; を追加します。<code>streams_xattr:prefix</code> が &quot;.&quot; で終わる場合は、&quot;Ext&quot; を &quot;.&quot; の前に挿入します。</p>
<p>あふれた部分の xattr は &quot;user.DosStreamExt.0.ADS-NAME&quot; というパターンに従って命名されます。</p></dd></dl>

### 例 {#EXAMPLES}


<pre><code>        [share]
	vfs objects = streams_xattr</code></pre>
