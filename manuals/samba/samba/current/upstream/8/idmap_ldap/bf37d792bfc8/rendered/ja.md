### 名前 {#Name}


<p>idmap_ldap — Winbind用のSamba idmap_ldapバックエンド</p>

### 説明 {#DESCRIPTION}


<p>idmap_ldapプラグインは、WinbindがLDAPディレクトリサービスにSID/uid/gidの対応表を保存し、取得するための手段を提供します。</p>

<p>idmap_ridのような読み取り専用バックエンドとは異なり、割り当てを行うバックエンドです。つまり、新しい対応を作成するために、新しいユーザーIDとグループIDを割り当てる必要があります。</p>

### IDMAPオプション {#IDMAP-OPTIONS}


<dl><dt>ldap_base_dn = DN</dt><dd><p>SID/uid/gidの対応エントリーに使用するディレクトリのベースサフィックスを定義します。未定義の場合、idmap_ldapは既定で <code>${prefix}/etc/smb.conf</code> の「ldap idmap suffix」オプションを使用します。</p></dd><dt>ldap_user_dn = DN</dt><dd><p>認証に使用するユーザーDNを定義します。このユーザーの認証用シークレットは、net idmap secretで保存してください（<a href="https://www.samba.org/samba/docs/current/man-html/net.8.html">net(8)</a> を参照）。指定がない場合はldap passdb設定のLDAP資格情報を使用し、それもない場合は最後の手段として匿名バインドを実行します。</p></dd><dt>ldap_url = ldap://server/</dt><dd><p>SID/uid/gidの対応エントリーに使用するLDAPサーバーを指定します。未定義の場合、idmap_ldapはldap://localhost/を使用するものとします。</p></dd><dt>range = low - high</dt><dd><p>このバックエンドが管理する、対応付けに使用可能なuidとgidの範囲を定義します。</p></dd></dl>

### 使用例 {#EXAMPLES}


<p>次の例は、LDAPディレクトリを既定のidmapバックエンドとして使用する方法を示します。idmapの範囲とディレクトリのベースサフィックスも設定します。ldap_user_dnのシークレットは「net idmap secret &#39;*&#39; password」で設定する必要があります。</p>

<pre><code>	[global]
	idmap config * : backend      = ldap
	idmap config * : range        = 1000000-1999999
	idmap config * : ldap_url     = ldap://localhost/
	idmap config * : ldap_base_dn = ou=idmap,dc=example,dc=com
	idmap config * : ldap_user_dn = cn=idmap_admin,dc=example,dc=com</code></pre>

<p>次の例は、対応を保存する既定のバックエンドとしてtdbを使用しつつ、LDAPを読み取り専用バックエンドとして使用する方法を示します。LDAP idmapバックエンドを使用するドメインDOM1の設定を明示的に追加します。既定の範囲と重ならない範囲を使用している点に注意してください。</p>

<pre><code>	[global]
	# &quot;backend = tdb&quot; is redundant here since it is the default
	idmap config * : backend = tdb
	idmap config * : range = 1000000-1999999

	idmap config DOM1 : backend = ldap
	idmap config DOM1 : range = 2000000-2999999
	idmap config DOM1 : read only = yes
	idmap config DOM1 : ldap_url = ldap://server/
	idmap config DOM1 : ldap_base_dn = ou=idmap,dc=dom1,dc=example,dc=com
	idmap config DOM1 : ldap_user_dn = cn=idmap_admin,dc=dom1,dc=example,dc=com</code></pre>

### 注意 {#NOTE}


<p>LDAPサーバーで認証するには、DNとパスワードを指定する必要がある場合があります。設定ファイルに平文のパスワードを露出させないよう、パスワードは安全な保管領域に保存します。「net idmap 」コマンドを使って、特定のidmapドメインで指定したDNのシークレットを保存します。</p>
