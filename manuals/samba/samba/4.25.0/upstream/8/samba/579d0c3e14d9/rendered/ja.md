### 名前 {#Name}


<p>samba — クライアントに AD および SMB/CIFS サービスを提供するサーバー</p>

### 書式 {#Synopsis}


<p><code>samba</code> [<code>-D</code>|<code>--daemon</code>] [<code>-F</code>|<code>--foreground</code>] [<code>-i</code>|<code>--interactive</code>] [<code>-M</code>|<code>--model</code>=MODEL] [<code>--maximum-runtime</code>=seconds] [<code>-b</code>|<code>--show-build</code>] [<code>--no-process-group</code>] [<code>-d</code>|<code>--debuglevel</code>=DEBUGLEVEL] [<code>--debug-stdout</code>] [<code>--configfile</code>=CONFIGFILE] [<code>--option</code>=name=value] [<code>-l</code>|<code>--log-basename</code>=LOGFILEBASE] [<code>--leak-report</code>] [<code>--leak-report-full</code>] [<code>-V</code>|<code>--version</code>]</p>

### 説明 {#DESCRIPTION}


<p>このプログラムは <a href="https://www.samba.org/samba/docs/current/man-html/samba.7.html">samba(7)</a> スイートの一部です。</p>

<p><code>samba</code> はクライアントに Active Directory、ファイル共有、印刷サービスを提供するサーバーデーモンです。SMB（または CIFS）プロトコルと、DCE/RPC、LDAP、Kerberos などの関連プロトコルを使って、ファイル領域とディレクトリサービスを提供します。</p>

<p>対応クライアントには、DOS 用 MSCLIENT 3.0、Windows for Workgroups、Windows 95/98/ME、Windows NT、Windows 2000/XP/2003、OS/2、Macintosh 用 DAVE、Linux 用 cifsfs が含まれます。</p>

<p>サーバーが提供できるサービスの詳しい説明は、それらのサービスの属性を制御する設定ファイルのマニュアルページ（<a href="https://www.samba.org/samba/docs/current/man-html/smb.conf.5.html">smb.conf(5)</a> を参照）にあります。このマニュアルページではサービスではなく、サーバーの実行に関する管理面を中心に説明します。</p>

<p>このサーバーの実行にはセキュリティ上の重大な影響があるため、インストールを進める前に <a href="https://www.samba.org/samba/docs/current/man-html/smb.conf.5.html">smb.conf(5)</a> マニュアルページを必ず読んでください。</p>

### オプション {#OPTIONS}


<dl><dt><code>-D</code>|<code>--daemon</code></dt><dd><p>このパラメーターを指定すると、サーバーはデーモンとして動作します。すなわち端末から切り離されてバックグラウンドで動き、適切なポートへの要求を処理します。ファイル・印刷サービスをたまに使う以上の用途では、<code>samba</code> をデーモンとして実行することを推奨します。シェルのコマンドラインから <code>samba</code> を実行した場合、このスイッチが指定されたものとみなします。</p></dd><dt><code>-F</code>|<code>--foreground</code></dt><dd><p>このパラメーターを指定すると、<code>samba</code> プロセスはデーモン化（2回の fork と端末からの切り離し）を行いません。</p></dd><dt><code>-i</code>|<code>--interactive</code></dt><dd><p>このパラメーターを指定すると、シェルのコマンドラインから実行した場合でも、サーバーをデーモンではなく「対話的」に実行します。コマンドライン実行時の暗黙のデーモンモードを打ち消します。<code>samba</code> は、<code>-S</code> パラメーターを指定した場合のように標準出力へログを出します。</p></dd><dt><code>-M</code>|<code>--model</code></dt><dd><p>samba が使う「プロセスモデル」を指定できます。これによって同時接続クライアントの処理方法が決まります。使用できるモデルは次のとおりです。</p>
<ul><li><p><em>single</em></p>
<p>すべての Samba サービスを1つのプロセスで実行します。本番環境には推奨しません。</p></li><li><p><em>standard</em></p>
<p>Samba サービスごとにプロセスを作成し、対応サービス（現在は LDAP と NETLOGON のみ）では、新しいクライアント接続ごとに新しいプロセスを起動します。</p>
<p>従来、v4.10 まではこれが Samba の「標準的な」動作でした。このモデルはクライアント接続が多い場合、リソース消費が大きくなることに注意してください。</p></li><li><p><em>prefork</em></p>
<p>既定のモデルです。Samba サービスごとにプロセスを起動し、対応サービス（現在は LDAP、NETLOGON、KDC）では一定数のワーカープロセスを起動します。クライアント接続をワーカープロセス間で分担します。prefork に対応しないサービスへの要求は、そのサービスの単一プロセスが処理します。</p>
<p>起動する prefork ワーカープロセスの数は <a href="https://www.samba.org/samba/docs/current/man-html/smb.conf.5.html">smb.conf(5)</a> の <a href="https://www.samba.org/samba/docs/current/man-html/smb.conf.5.html#PREFORKCHILDREN">prefork children</a> パラメーターで制御し、既定値は4です。</p></li></ul></dd><dt><code>--maximum-runtime</code>=seconds</dt><dd><p>自動終了するまでのサーバープロセスの最大実行時間を秒単位で設定します。</p></dd><dt><code>-b</code>|<code>--show-build</code></dt><dd><p>Samba のビルド方法に関する情報を表示します。</p></dd><dt><code>-d</code>|<code>--debuglevel</code>=level</dt><dd><p><em><code>level</code></em> は0から10の整数です。このパラメーターを指定しない場合の既定値は0です。</p>
<p>値を大きくすると、サーバーの動作についてログファイルに記録する詳細が増えます。レベル0では重大なエラーと深刻な警告だけを記録します。レベル1は日常的な運用に適しており、実行した操作について少量の情報を生成します。</p>
<p>1より上のレベルは大量のログデータを生成するため、問題の調査時だけ使ってください。3より上は開発者専用に設計されており、大部分が非常に難解な、極めて大量のログデータを生成します。</p>
<p>ここでこのパラメーターを指定すると、<code>${prefix}/etc/smb.conf</code> ファイルの <a href="https://www.samba.org/samba/docs/current/man-html/smb.conf.5.html#LOGLEVEL">log level</a> パラメーターを上書きします。</p></dd><dt><code>--debug-stdout</code></dt><dd><p>デバッグ出力を STDOUT へリダイレクトします。既定ではサーバーデーモンはログファイルへ記録します。</p></dd><dt><code>--configfile</code>=CONFIGFILE</dt><dd><p>指定するファイルには、サーバーに必要な設定の詳細を記述します。使用する printcap ファイルなどサーバー固有の情報と、サーバーが提供するすべてのサービスの説明を含みます。詳しくは <code>${prefix}/etc/smb.conf</code> を参照してください。既定の設定ファイル名はコンパイル時に決まります。</p></dd><dt><code>--option</code>=&lt;name&gt;=&lt;value&gt;</dt><dd><p>コマンドラインから <a href="https://www.samba.org/samba/docs/current/man-html/smb.conf.5.html">smb.conf(5)</a> オプション &quot;&lt;name&gt;&quot; を値 &quot;&lt;value&gt;&quot; に設定します。コンパイル時の既定値と設定ファイルから読み込んだオプションを上書きします。名前や値に空白が含まれる場合は、<code>--option</code>=name=value 全体を引用符で囲んでください。</p></dd><dt><code>-l</code>|<code>--log-basename</code>=logdirectory</dt><dd><p>ログ/デバッグファイルの基底ディレクトリ名です。拡張子 <code>&quot;.progname&quot;</code> が追加されます（log.smbclient、log.smbd など）。クライアントがログファイルを削除することはありません。</p></dd><dt><code>--leak-report</code></dt><dd><p>終了時の talloc リーク報告を有効にします。</p></dd><dt><code>--leak-report-full</code></dt><dd><p>終了時の完全な talloc リーク報告を有効にします。</p></dd><dt><code>-V</code>|<code>--version</code></dt><dd><p>プログラムのバージョン番号を表示します。</p></dd><dt>-?|<code>--help</code></dt><dd><p>コマンドラインオプションの概要を表示します。</p></dd><dt><code>--usage</code></dt><dd><p>簡単な使用方法を表示します。</p></dd></dl>

### ファイル {#FILES}


<dl><dt><code>/etc/rc</code></dt><dd><p>またはシステムで使用する初期化スクリプト。</p>
<p>システム起動時にサーバーをデーモンとして実行する場合、このファイルにサーバーの適切な起動手順が必要です。</p></dd><dt><code>/etc/services</code></dt><dd><p>メタデーモン <code>inetd</code> 経由でサーバーを実行する場合、このファイルにサービス名（netbios-ssn など）とサービスのポート（139 など）、プロトコルの種類（tcp など）の対応付けが必要です。</p></dd><dt><code>/usr/local/samba/lib/smb.conf</code></dt><dd><p><a href="https://www.samba.org/samba/docs/current/man-html/smb.conf.5.html">smb.conf(5)</a> サーバー設定ファイルの既定の場所です。他によく使われるインストール先は <code>/usr/samba/lib/smb.conf</code> と <code>/etc/samba/smb.conf</code> です。</p>
<p>このファイルは、サーバーがクライアントに提供するすべてのサービスを記述します。詳しくは <a href="https://www.samba.org/samba/docs/current/man-html/smb.conf.5.html">smb.conf(5)</a> を参照してください。</p></dd></dl>

### 診断 {#DIAGNOSTICS}


<p>サーバーが出力する診断の大部分は、指定したログファイルに記録します。ログファイル名はコンパイル時に指定しますが、コマンドラインで上書きできます。</p>

<p>利用できる診断の数と種類は、サーバーのデバッグレベルによって異なります。問題がある場合はデバッグレベルを3に設定し、ログファイルを詳しく調べてください。</p>

<p>大部分のメッセージは、それ自体で意味をおおむね理解できます。残念ながら、このマニュアルページの作成時点で、ソースコード内の診断は多すぎて個別に説明できません。現時点では、ソースコードを grep し、表示された診断を引き起こす条件を調べるのが最善です。</p>
