### 名前 {#Name}


<p>vfs_ceph_new — libcephfs の低水準 API が提供する機能を利用する</p>

### 書式 {#Synopsis}


<p><code>vfs objects = ceph_new</code></p>

### 説明 {#DESCRIPTION}


<p>この VFS モジュールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.8.html">samba(8)</a> スイートの一部です。</p>

<p><code>vfs_ceph_new</code> VFS モジュールは、Samba で利用できるよう CephFS 固有の機能を公開します。</p>

<p>Ceph は、優れた性能、信頼性、拡張性を提供するよう設計された分散ネットワークファイルシステムです。これは、アプリケーションが POSIX に似たインターフェースを通じて Ceph 分散ファイルシステムにアクセスできる共有ライブラリーです。</p>

<p>このモジュールは他のモジュールと組み合わせられますが、<code>vfs objects</code> 一覧の最後に配置する必要があります。この一覧で ceph エントリーの右側に追加したモジュールは、まったく効果がない場合があります。</p>

<p><code>vfs_ceph_new</code> は Windows と POSIX のアクセス制御リスト（ACL）間の対応付けを行います。POSIX ACL を正しく処理し適用するため、次の Ceph 設定パラメーターを自動的に適用します。</p>

<pre><code>		client acl type = posix_acl
		fuse default permissions = false</code></pre>

<p><strong>注</strong>: これは libcephfs の低水準 API を使う、Ceph モジュールの2つ目の実装です（元の <a href="https://www.samba.org/samba/docs/current/man-html/vfs_ceph.8.html">vfs_ceph(8)</a> モジュールはパスベースの API を使います）。低水準 API により、Ceph ストレージ層へのアクセスをより最適化し、細かく制御できます。</p>

### 設定 {#CONFIGURATION}


<p><code>vfs_ceph_new</code> では、基となる共有パスが Ceph ファイルシステムである必要があります。</p>

<pre><code>		[share]
		vfs objects = ceph_new
		path = /non-mounted/cephfs/path
		kernel share modes = no</code></pre>

<p><code>vfs_ceph_new</code> はファイルシステムのマウントを必要としないため、共有の <code>path</code> の扱いが異なり、接続先 Ceph クラスターの Ceph ファイルシステム内の絶対パスと解釈されます。ctdb が Samba を管理する ctdb クラスター環境では、<code>CTDB_SAMBA_SKIP_SHARE_CHECK=yes</code> を設定してローカル共有パスの検査を無効にしなければ、ctdb は正常な状態になりません。</p>

<p>現在、CephFS VFS モジュールを使う共有でファイル提供を正しく動作させるには、<code>kernel share modes</code> を無効にする必要があることに注意してください。</p>
