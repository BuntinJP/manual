### 名前 {#Name}


<p>vfs_io_uring — Linux（5.1以降）のio_uringを使用してSamba VFSの非同期I/Oを実装する</p>

### 書式 {#Synopsis}


<p><code>vfs objects = io_uring</code></p>

### 説明 {#DESCRIPTION}


<p>このVFSモジュールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.7.html">samba(7)</a> スイートの一部です。</p>

<p><code>io_uring</code> VFSモジュールは、Linux（5.1以降）のio_uring基盤を使用して、非同期のpread、pwrite、fsyncを可能にします。非同期I/Oにpthreadpoolを使う場合と比べ、オーバーヘッドが大幅に減ります。</p>

<p>実際のカーネルファイル記述子を必要とするため、このモジュールはどのモジュールスタックでも最後に配置するべきです。</p>

### 使用例 {#EXAMPLES}


<p>基本的な使用例です。</p>

<pre><code>        [cooldata]
	path = /data/ice
	vfs objects = io_uring</code></pre>

### オプション {#OPTIONS}


<dl><dt>io_uring:num_entries = NUMBER_OF_QUEUE_ENTRIES</dt><dd><p>サブミッションキューのエントリー数です。許容される最大値はカーネルのバージョンに依存し、カーネルは値を2のべき乗へ切り上げます。</p>
<p>既定値は「128」です。</p></dd><dt>io_uring:sqpoll = BOOL</dt><dd><p>IORING_SETUP_SQPOLL機能を使用します。</p>
<p>既定値は「no」です。</p></dd></dl>
