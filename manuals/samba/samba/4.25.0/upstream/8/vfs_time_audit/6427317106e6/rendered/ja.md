### 名前 {#Name}


<p>vfs_time_audit — 遅いVFS操作を記録するSamba VFSモジュール</p>

### 書式 {#Synopsis}


<p><code>vfs objects = time_audit</code></p>

### 説明 {#DESCRIPTION}


<p>このVFSモジュールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.7.html">samba(7)</a> スイートの一部です。</p>

<p><code>time_audit</code> VFSモジュールは、変数 <code>time_audit:timeout</code> で定義したミリ秒数を超える時間がかかるシステムコールをログに記録します。呼び出しと、それに費やした時間を記録します。</p>

<p><code>strace -T</code> にある程度似ており、下位のファイルおよびストレージサブシステムの性能問題を明らかにするのに役立ちます。</p>

<p>このモジュールは他のモジュールと積み重ねて使用できます。</p>

### オプション {#OPTIONS}


<dl><dt>time_audit:timeout = ミリ秒数</dt><dd><p>指定したミリ秒数より長い時間がかかるVFS呼び出しをログに記録します。既定値は10000（10秒）です。</p></dd></dl>

### 使用例 {#EXAMPLES}


<p>次の設定では、3秒を超える時間がかかるVFS呼び出しを記録します。</p>

<pre><code>        [sample_share]
	path = /test/sample_share
	vfs objects = time_audit
	time_audit:timeout = 3000</code></pre>
