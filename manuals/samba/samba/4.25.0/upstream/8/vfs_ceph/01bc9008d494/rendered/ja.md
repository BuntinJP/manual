### 名前 {#Name}


<p>vfs_ceph — CephFS が提供する機能を利用する</p>

### 書式 {#Synopsis}


<p><code>vfs objects = ceph</code></p>

### 説明 {#DESCRIPTION}


<p>この VFS モジュールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.8.html">samba(8)</a> スイートの一部です。</p>

<p><code>vfs_ceph</code> VFS モジュールは、Samba が使えるように CephFS 固有の機能を公開します。</p>

<p>Ceph は優れた性能、信頼性、拡張性を提供するよう設計された分散ネットワークファイルシステムです。これは、アプリケーションが POSIX に似たインターフェースで Ceph 分散ファイルシステムへアクセスできるようにする共有ライブラリーです。</p>

<p>このモジュールは他のモジュールと組み合わせられますが、<code>vfs objects</code> 一覧の最後に置く必要があります。ceph エントリーの右側に追加したモジュールは、まったく効果がない場合があります。</p>

<p><code>vfs_ceph</code> は Windows と POSIX のアクセス制御リスト（ACL）を対応付けます。POSIX ACL の正しい処理と適用を保証するため、次の Ceph 設定パラメーターを自動的に適用します。</p>

<pre><code>		client acl type = posix_acl
		fuse default permissions = false</code></pre>

### 設定 {#CONFIGURATION}


<p><code>vfs_ceph</code> では、共有の基礎となるパスが Ceph ファイルシステムである必要があります。</p>

<pre><code>		[share]
		vfs objects = ceph
		path = /non-mounted/cephfs/path
		kernel share modes = no</code></pre>

<p><code>vfs_ceph</code> はファイルシステムのマウントを必要としないため、共有の <code>path</code> は異なる扱いになります。接続した Ceph クラスターの Ceph ファイルシステム内の絶対パスとして解釈します。ctdb が Samba を管理するクラスター環境では、<code>CTDB_SAMBA_SKIP_SHARE_CHECK=yes</code> を設定してローカルの共有パス検査を無効にする必要があります。そうしないと ctdb は正常状態になりません。</p>

<p>現在、CephFS VFS モジュールで動作する共有でファイル提供を正常に行うには、<code>kernel share modes</code> を無効にする必要があります。</p>

### オプション {#OPTIONS}


<dl><dt>ceph:config_file = path</dt><dd><p>使用する Ceph 設定ファイルを指定できます。既定では空です。</p>
<p>例: ceph:config_file = /etc/ceph/ceph.conf</p></dd><dt>ceph:user_id = name</dt><dd><p>CephFS マウントハンドルに使うクライアントIDを明示的に設定できます。既定では空です（libcephfs クライアントの既定値を使います）。</p>
<p>例: ceph:user_id = samba</p></dd><dt>ceph:filesystem = fs_name</dt><dd><p>Ceph クラスターが複数のファイルシステムをサポートする場合、使用する CephFS ファイルシステムを明示的に選べます。既定では空です（Ceph クラスターの既定ファイルシステムを使います）。</p>
<p>例: ceph:filesystem = myfs2</p></dd></dl>
