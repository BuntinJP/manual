### 名前 {#Name}


<p>vfs_ceph_rgw — ceph librgw が提供するオブジェクトストア上で SMB を使用する</p>

### 書式 {#Synopsis}


<p><code>vfs objects = ceph_rgw</code></p>

### 説明 {#DESCRIPTION}


<p>この VFS モジュールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.8.html">samba(8)</a> スイートの一部です。</p>

<p><code>vfs_ceph_rgw</code> VFS モジュールは、ceph-rgw がホストする S3 バケットをユーザーに公開します。</p>

<p>Ceph は、優れた性能、信頼性、拡張性を提供するよう設計された分散ネットワークファイルシステムです。librgw は、アプリケーションが POSIX に似たインターフェースを通じてオブジェクトストア、すなわち S3 バケットにアクセスできる共有ライブラリーです。</p>

<p>このモジュールは他のモジュールと組み合わせられません。librgw はディレクトリの名前変更をサポートしません。そのため、このモジュールは内部的に <a href="https://www.samba.org/samba/docs/current/man-html/smb.conf.5.html#VFSMKDIRUSETMPNAME">vfs mkdir use tmp name = no</a> を設定し、Samba がディレクトリ作成時に一時的な名前を使ってから指定名へ変更することを防ぎます。librgw はランダム書き込みをサポートしないため、非同期 I/O 書き込みメソッドは実装していません。このため、内部的に <a href="https://www.samba.org/samba/docs/current/man-html/smb.conf.5.html#AIOWRITESIZE">aio write size = 0</a> を設定し、Samba が常に同期書き込みメソッドを使用するようにします。</p>

### 設定 {#CONFIGURATION}


<p><code>vfs_ceph_rgw</code> では、基となる共有パスが S3 バケット名である必要があります。</p>

<pre><code>		[share]
		vfs objects = ceph_rgw
		path = /
	</code></pre>

<p><code>vfs_ceph_rgw</code> はファイルシステムのマウントを必要としないため、共有の <code>/</code> はバケットのルートとして扱われ、&#39;/&#39; に設定する必要があります。それ以外のパスは無視されます。ctdb が Samba を管理する ctdb クラスター環境では、<code>CTDB_SAMBA_SKIP_SHARE_CHECK=yes</code> を設定してローカル共有パスの検査を無効にしなければ、ctdb は正常な状態になりません。</p>

### グローバルオプション {#GLOBAL-OPTIONS}


<p>次のオプションは smb.conf の global セクションに設定する必要があり、共有単位で設定しても効果がありません。librgw はプロセスごとに1回だけ初期化できるため、これらのパラメーターはすべての共有で共通です。</p>

<dl><dt>ceph_rgw:id = name</dt><dd><p>librgw が使う Ceph クライアント名のクライアントID部分です。（必須）</p>
<p>例: ceph_rgw:id = admin</p></dd><dt>ceph_rgw:config_file = path</dt><dd><p>使用する Ceph 設定を指定できます。既定値: /etc/ceph/ceph.conf</p>
<p>例: ceph_rgw:config_file = /etc/ceph/ceph.conf</p></dd><dt>ceph_rgw:keyring_file = path</dt><dd><p>使用する Ceph キーリングファイルを指定できます。（必須）</p>
<p>例: ceph_rgw:keyring_file = /etc/ceph/ceph.client.admin.keyring</p></dd><dt>ceph_rgw:debug = boolean</dt><dd><p>librgw のデバッグログを制御します。既定値: off</p>
<p>例: ceph_rgw:debug = on</p></dd></dl>

### オプション {#OPTIONS}


<p>次のオプションは共有単位で設定できます。</p>

<dl><dt>ceph_rgw:user_id = name</dt><dd><p>バケット所有者のユーザーIDです。（必須）</p>
<p>例: ceph_rgw:user_id = samba</p></dd><dt>ceph_rgw:access_key = key</dt><dd><p>user_id オプションで指定したバケット所有者のアクセスキーです。（必須）</p>
<p>例: ceph_rgw:access_key = samba-key</p></dd><dt>ceph_rgw:secret_access_key = key</dt><dd><p>user_id オプションで指定したバケット所有者のシークレットアクセスキーです。（必須）</p>
<p>例: ceph_rgw:secret_access_key = samba-secret-key</p></dd><dt>ceph_rgw:bucket = bucket name</dt><dd><p>共有として公開するバケット名です。（必須）</p>
<p>例: ceph_rgw:bucket = video4k</p></dd></dl>

### 設定例 {#Sample-configuration}


<p>このモジュールを使うよう Samba を設定するには、動作する Ceph クラスターへのアクセスが必要です。次の例は、既存のユーザー、バケット、バケット内のオブジェクトを持つ既存の Ceph RGW オブジェクトストアに対する、動作可能な Samba 設定を示します。</p>

<ol><li><p>librgw-devel パッケージをインストールします。</p></li><li><p>Samba のソースを複製します。</p></li><li><p>通常の設定オプションに加え、&quot;<code>--enable-cephrgw</code>&quot; オプションを使って Samba のビルドを設定し、コンパイルしてインストールします。</p></li><li><p>smb.conf を編集して次の共有定義を追加します。注: path は &#39;/&#39; に設定する必要があり、それ以外のパスは無視されます。</p>
<pre><code>			[global]&#10;			ceph_rgw:id = admin&#10;			ceph_rgw:config_file = /etc/ceph/ceph.conf&#10;			ceph_rgw:keyring_file = /etc/ceph/ceph.client.admin.keyring&#10;&#10;			[share]&#10;			comment = rgw bucket&#10;			path = /&#10;			read only = no&#10;			inherit permissions = yes&#10;			vfs objects = ceph_rgw&#10;			ceph_rgw:bucket = my-bucket&#10;			ceph_rgw:user_id = user1&#10;			ceph_rgw:access_key = user1passwd&#10;			ceph_rgw:secret_access_key = user1passwd&#10;			</code></pre></li><li><p>Samba サーバーを起動します。</p></li></ol>
