### 名前 {#Name}


<p>vfs_syncops — メタデータ操作を同期的に実行する</p>

### 書式 {#Synopsis}


<p><code>vfs objects = syncops</code></p>

### 説明 {#DESCRIPTION}


<p>このVFSモジュールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.7.html">samba(7)</a> スイートの一部です。</p>

<p>一部のファイルシステム（ジャーナリングファイルシステムの一部を含む）では、電源障害後も操作の結果がファイルシステムに確実に残るよう、多くのメタデータ操作でfsync()を実行する必要があります。これは、クラスタ化したSambaとともにノードのフェイルオーバーシステムを構成する一部のクラスタファイルシステムで特に重要です。そうしたファイルシステムでは、<code>vfs_syncops</code> VFSモジュールにより、それらの操作を安全に実行できます。</p>

<p>このモジュールは他のモジュールと積み重ねて使用できます。</p>

### 設定 {#CONFIGURATION}


<p><code>vfs_syncops</code> VFSモジュールによる性能低下の大部分は、close()時のfsyncによるものです。グローバルまたは共有ごとに設定できる <code>syncops:onclose = no</code> で、この処理を無効にできます。</p>

<p>最後に書き込んだデータだけにfsync()が必要な一部のファイルシステムでは、<code>syncops:onmeta = no</code> により、このモジュールのメタデータ同期を無効にできます。このオプションはグローバルまたは共有ごとに設定できます。</p>

<p><code>syncops:disable = true</code> により、共有に対する <code>vfs_syncops</code> VFSモジュールを完全に無効にすることもできます。</p>

### 使用例 {#EXAMPLES}


<p>[share]にsyncops機能を追加します。</p>

<pre><code>        [share]
	path = /data/share
	vfs objects = syncops
	syncops:onclose = no</code></pre>
