### 名前 {#Name}


<p>vfs_audit — 選択された Samba VFS 操作をシステムログに記録する</p>

### 書式 {#Synopsis}


<p><code>vfs objects = audit</code></p>

### 説明 {#DESCRIPTION}


<p>この VFS モジュールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.7.html">samba(7)</a> スイートの一部です。</p>

<p><code>vfs_audit</code> VFS モジュールは、<a href="https://www.samba.org/samba/docs/current/man-html/syslog.3.html">syslog(3)</a> を使用して選択されたクライアント操作をシステムログに記録します。</p>

<p>次の Samba VFS 操作が記録されます。</p>

<div class="manual-table"><table><tbody><tr><td><p>connect</p></td></tr><tr><td><p>disconnect</p></td></tr><tr><td><p>opendir</p></td></tr><tr><td><p>mkdir</p></td></tr><tr><td><p>rmdir</p></td></tr><tr><td><p>open</p></td></tr><tr><td><p>close</p></td></tr><tr><td><p>rename</p></td></tr><tr><td><p>unlink</p></td></tr><tr><td><p>chmod</p></td></tr><tr><td><p>fchmod</p></td></tr></tbody></table></div>

<p>このモジュールはスタック可能です。</p>

### オプション {#OPTIONS}


<dl><dt>audit:facility = FACILITY</dt><dd><p>指定した <a href="https://www.samba.org/samba/docs/current/man-html/syslog.3.html">syslog(3)</a> ファシリティーにメッセージを記録します。</p></dd><dt>audit:priority = PRIORITY</dt><dd><p>指定した <a href="https://www.samba.org/samba/docs/current/man-html/syslog.3.html">syslog(3)</a> 優先度でメッセージを記録します。</p></dd></dl>

### 使用例 {#EXAMPLES}


<p>LOCAL1 ファシリティーと NOTICE 優先度を使用して、すべての共有の操作を記録します。</p>

<pre><code>        [global]
	vfs objects = audit
	audit:facility = LOCAL1
	audit:priority = NOTICE</code></pre>
