### 名前 {#Name}


<p>vfs_full_audit — Samba VFS 操作をシステムログに記録する</p>

### 書式 {#Synopsis}


<p><code>vfs objects = full_audit</code></p>

### 説明 {#DESCRIPTION}


<p>この VFS モジュールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.7.html">samba(7)</a> スイートの一部です。</p>

<p><code>vfs_full_audit</code> VFS モジュールは、選択したクライアント操作を <a href="https://www.samba.org/samba/docs/current/man-html/syslog.3.html">syslog(3)</a> を使ってシステムログに記録します。</p>

<p><code>vfs_full_audit</code> は、Samba VFS のすべての操作を記録できます。</p>

<p>これらの操作に加えて、<code>vfs_full_audit</code> は特別な操作名 &quot;all&quot; と &quot;none &quot; を認識します。それぞれ、すべての VFS 操作と、VFS 操作なしを意味します。</p>

<p>不明な操作名を使った場合（たとえば操作名の綴りを間違えた場合）、モジュールの読み込みは失敗し、このモジュールを使う共有へのクライアントの接続は拒否されます。</p>

<p><code>vfs_full_audit</code> は、&#39;|&#39; 文字で区切ったフィールドからなる固定形式で操作を記録します。形式は次のとおりです。</p>

<pre><code>		smbd_audit: PREFIX|OPERATION|RESULT|FILE</code></pre>

<p>レコードのフィールドは次のとおりです。</p>

<ul><li><p><code>PREFIX</code> - full_audit:prefix 文字列に変数置換を適用した結果</p></li><li><p><code>OPERATION</code> - VFS 操作の名前</p></li><li><p><code>RESULT</code> - 操作が成功したか失敗したか</p></li><li><p><code>FILE</code> - 操作対象のファイルまたはディレクトリの名前</p></li></ul>

<p>このモジュールは、他のモジュールと重ねて使用できます。</p>

### オプション {#OPTIONS}


<dl><dt>full_audit:prefix = STRING</dt><dd><p>監査メッセージの先頭に STRING を付けます。STRING には、<a href="https://www.samba.org/samba/docs/current/man-html/smb.conf.5.html">smb.conf(5)</a> に記載された標準の置換変数の処理を適用します。既定の接頭辞は &quot;<code>%u</code>|<code>%I</code>&quot; です。</p></dd><dt>full_audit:success = LIST</dt><dd><p>LIST は、成功した場合に記録する VFS 操作の一覧です。上記の名前を使って操作を指定します。名前の先頭に &quot;!&quot; を付けると、その操作の指定を解除できます。既定では、どの操作も記録しません。</p></dd><dt>full_audit:failure = LIST</dt><dd><p>LIST は、失敗した場合に記録する VFS 操作の一覧です。上記の名前を使って操作を指定します。名前の先頭に &quot;!&quot; を付けると、その操作の指定を解除できます。既定では、どの操作も記録しません。</p></dd><dt>full_audit:facility = FACILITY</dt><dd><p>指定した <a href="https://www.samba.org/samba/docs/current/man-html/syslog.3.html">syslog(3)</a> ファシリティーにメッセージを記録します。</p></dd><dt>full_audit:priority = PRIORITY</dt><dd><p>指定した <a href="https://www.samba.org/samba/docs/current/man-html/syslog.3.html">syslog(3)</a> 優先度でメッセージを記録します。</p></dd><dt>full_audit:syslog = true/false</dt><dd><p>syslog にメッセージを記録する（既定）か、デバッグレベル1のメッセージとして記録します。</p></dd><dt>full_audit:log_secdesc = true/false</dt><dd><p>クライアントが ACL を設定するときに受信するセキュリティー記述子を SDDL 形式で記録します。既定値は false です。</p></dd></dl>

### 例 {#EXAMPLES}


<p>[records] 共有でのファイルとディレクトリを開く操作を、LOCAL7 ファシリティーと ALERT 優先度で、ユーザー名と IP アドレスを含めて記録します。失敗時の記録からは open VFS 関数を除外します。</p>

<pre><code>        [records]
	path = /data/records
	vfs objects = full_audit
	full_audit:prefix = %u|%I
	full_audit:success = open opendir
	full_audit:failure = all !open
	full_audit:facility = LOCAL7
	full_audit:priority = ALERT</code></pre>
