### 名前 {#Name}


<p>vfs_crossrename — ファイルシステム境界を越えてサーバー側でファイル名を変更する</p>

### 書式 {#Synopsis}


<p><code>vfs objects = crossrename</code></p>

### 説明 {#DESCRIPTION}


<p>このVFSモジュールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.7.html">samba(7)</a> スイートの一部です。</p>

<p><code>vfs_crossrename</code> VFSモジュールは、移動元と移動先が異なる物理デバイス上にあっても、サーバー側での名前変更を可能にします。エクスプローラーでの「移動」は、単一の共有またはデバイス内であれば通常は名前変更操作です。通常、このようにデバイスをまたぐ名前変更操作はNT_STATUS_NOT_SAME_DEVICEを返すため、クライアントはコピーと削除を自ら実行してファイルを移動しなければなりません。コピーによる名前変更をサーバーが行えば、はるかに効率的になる場合があります。vfs_crossrenameは、このデバイスをまたぐ名前変更をサーバー側で行おうとします。</p>

<p>ただし、このモジュールが現在解決していない制限事項があります。</p>

<dl><dt></dt><dd></dd><dt></dt><dd></dd><dt></dt><dd></dd><dt></dt><dd></dd></dl>

<p>このモジュールは完全には積み重ね可能ではありません。他のモジュールと組み合わせられますが、<code>vfs objects</code> リストの最後に配置してください。OSのファイルシステム上のファイルへ直接アクセスします。</p>

### オプション {#OPTIONS}


<dl><dt>crossrename:sizelimit = BYTES</dt><dd><p>タイムアウトを防ぐため、サーバー側でデバイスをまたぐ名前変更を行うのは、ファイルサイズがMiB単位で指定されたサイズ以下の場合だけです。sizelimitの既定値は20（MiB）です。</p></dd></dl>

### 使用例 {#EXAMPLES}


<p>共有内の50MB以下のすべてのファイルに対し、サーバー側でデバイスをまたぐ名前変更を追加します。</p>

<pre><code>        [testshare]
	path = /data/mounts
	vfs objects = crossrename
	crossrename:sizelimit = 50</code></pre>
