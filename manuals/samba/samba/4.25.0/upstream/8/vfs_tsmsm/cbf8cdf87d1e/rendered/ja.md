### 名前 {#Name}


<p>vfs_tsmsm — Tivoli Storage Manager Space Management でオフラインファイルを扱う VFS モジュール</p>

### 書式 {#Synopsis}


<p><code>vfs objects = tsmsm</code></p>

### 説明 {#DESCRIPTION}


<p>この VFS モジュールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.7.html">samba(7)</a> スイートの一部です。</p>

<p><code>tsmsm</code> VFS モジュールは、Tivoli Storage Manager Space Management でオフラインファイルを扱う拡張です。</p>

<p>オンライン（移行されていない）ファイルでは、報告されるブロック数に512を掛けた値が、実際のサイズに「online ratio」を掛けた値より大きくなるという事実に基づくヒューリスティックにより、高コストな DMAPI 呼び出しを避けようとします。この判定が失敗すると、モジュールは DMAPI を呼び出し、オフライン（移行済み）ファイルに存在する特定の属性を問い合わせます。その属性があれば、ファイルをオフラインとみなします。</p>

<p>このモジュールは他のモジュールと積み重ねて使用できません。</p>

### オプション {#OPTIONS}


<dl><dt>tsmsm:hsm script = [ hsm スクリプトへのパス ]</dt><dd><p>hsm script には、操作とファイルパスの2つの引数を受け取るシェルスクリプトを指定します。tsmsm モジュールは操作として「offline」だけを使い、指定パスのファイルをオフラインにします。</p></dd><dt>tsmsm:online ratio = [ 数値 ]</dt><dd><p>報告されたサイズを実際のファイルサイズと比較する比率です。既定値は0.5です。</p></dd><dt>tsmsm:dmapi attribute = [ 属性名 ]</dt><dd><p>ファイルがオフラインの場合に存在する DMAPI 属性の名前です。既定値は「IBMobj」（GPFS が使う属性）です。</p></dd><dt>tsmsm:dmapi value = [ DMAPI 属性の値 ]</dt><dd><p>ファイルをオフラインとみなすために DMAPI 属性が持つべき値です。既定値は空で、値を要求しません。</p></dd></dl>

### 例 {#EXAMPLES}


<p>TSM 対応の GPFS マウントは、次のように Samba 経由で公開できます。</p>

<pre><code>        [gpfs_tsm_share]
	vfs objects = tsmsm gpfs
	path = /test/gpfs_mount</code></pre>
