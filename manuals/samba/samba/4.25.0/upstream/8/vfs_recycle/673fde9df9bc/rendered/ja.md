### 名前 {#Name}


<p>vfs_recycle — Samba VFS のごみ箱</p>

### 書式 {#Synopsis}


<p><code>vfs objects = recycle</code></p>

### 説明 {#DESCRIPTION}


<p>この VFS モジュールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.7.html">samba(7)</a> スイートの一部です。</p>

<p><code>vfs_recycle</code> はファイル削除要求を捕捉し、対象ファイルを直ちに削除するのではなく一時保管場所へ移動します。これは Windows コンピューターのごみ箱と同じ効果をもたらします。</p>

<p>このごみ箱は、Windows エクスプローラーで表示するネットワークファイルシステム（共有）にも、割り当てたドライブにもごみ箱としては表示されません。代わりに、recycle:repository が設定されていない場合、最初のファイルを削除すると .recycle というディレクトリーが自動作成されます。recycle:repository が設定されている場合、作成するディレクトリー名はその設定によって決まります。ユーザーはごみ箱からファイルを回復できます。recycle:keeptree オプションが指定されている場合、削除したファイルは削除前と同じパスで見つかります。</p>

<p>このモジュールはスタック可能です。</p>

### オプション {#OPTIONS}


<dl><dt>recycle:repository = PATH</dt><dd><p>削除したファイルの移動先ディレクトリーのパス。</p>
<p>このオプションを設定しない場合、既定のパス .recycle を使用します。</p></dd><dt>recycle:directory_mode = MODE</dt><dd><p>ごみ箱の保管ディレクトリーを作成するときのモードを 8 進数で MODE に設定します。保管ディレクトリーは最初のファイルを削除したときに作成されます。recycle:subdir_mode が設定されていない場合、MODE はサブディレクトリーにも適用されます。</p>
<p>このオプションを設定しない場合、既定のモード 0700 を使用します。</p></dd><dt>recycle:subdir_mode = MODE</dt><dd><p>ごみ箱の保管ディレクトリー内のサブディレクトリーを作成するときのモードを 8 進数で MODE に設定します。</p>
<p>このオプションを設定しない場合、サブディレクトリーは recycle:directory_mode のモードで作成されます。</p></dd><dt>recycle:keeptree = BOOL</dt><dd><p>ディレクトリー構造を保持するか、それとも削除対象ディレクトリー内のファイルを保管場所に個別に保存するかを指定します。</p></dd><dt>recycle:versions = BOOL</dt><dd><p>True の場合、削除した同名の 2 ファイルを両方とも保管場所に保持します。後で削除したバージョンのファイル名は &quot;Copy #x of filename&quot; になります。</p></dd><dt>recycle:touch = BOOL</dt><dd><p>ファイルを保管場所へ移動するときに、そのアクセス日時を更新するかどうかを指定します。</p></dd><dt>recycle:touch_mtime = BOOL</dt><dd><p>ファイルを保管場所へ移動するときに、その最終変更日時を更新するかどうかを指定します。</p></dd><dt>recycle:minsize = BYTES</dt><dd><p>このパラメーターで指定したバイト数より小さいファイルは、保管場所に入れません。</p></dd><dt>recycle:maxsize = BYTES</dt><dd><p>このパラメーターで指定したバイト数より大きいファイルは、保管場所に入れません。</p></dd><dt>recycle:exclude = LIST</dt><dd><p>削除時に保管場所に入れず、通常どおり削除するファイルのリストです。* や ? などのワイルドカードを使用できます。</p></dd><dt>recycle:exclude_dir = LIST</dt><dd><p>削除時にその中のファイルを保管場所に入れず、通常どおり削除するディレクトリーのリストです。* や ? などのワイルドカードを使用できます。</p></dd><dt>recycle:noversions = LIST</dt><dd><p>バージョン管理を使用しないパスのリストを指定します（* や ? などのワイルドカードを使用できます）。recycle:versions が有効な場合にのみ役立ちます。</p></dd></dl>

### 使用例 {#EXAMPLES}


<p><em><code>share</code></em> 上で「削除」したファイルを、削除する代わりに <em><code>/data/share/.recycle</code></em> に移動します。</p>

<pre><code>        [share]
	path = /data/share
	vfs objects = recycle
	recycle:repository = .recycle
	recycle:keeptree = yes
	recycle:versions = yes</code></pre>
