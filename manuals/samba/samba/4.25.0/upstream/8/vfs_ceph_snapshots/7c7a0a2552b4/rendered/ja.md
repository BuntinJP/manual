### 名前 {#Name}


<p>vfs_ceph_snapshots — CephFSスナップショットをシャドウコピーとして公開する</p>

### 書式 {#Synopsis}


<p><code>vfs objects = ceph_snapshots</code></p>

### 説明 {#DESCRIPTION}


<p>このVFSモジュールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.8.html">samba(8)</a> スイートの一部です。</p>

<p><code>vfs_ceph_snapshots</code> VFSモジュールは、Sambaで利用できるようCephFSスナップショットを公開します。有効にすると、Windowsエクスプローラーの「以前のバージョン」ダイアログなどのSMBクライアントは、スナップショットを列挙し、「timewarp」トークンを使ってアクセスできます。</p>

<p>このモジュールは <code>vfs_ceph</code> と組み合わせられますが、<code>vfs objects</code> パラメーターのリストでは <code>vfs_ceph_snapshots</code> を先に記載する必要があります。</p>

<p>このモジュールが正しく動作するには、CephFSがceph.snap.btime仮想拡張属性をサポートしている必要があります。このサポートは https://tracker.ceph.com/issues/38838 で追加されました。</p>

### 設定 {#CONFIGURATION}


<p><code>vfs_ceph</code> の上で使用する場合、<code>path</code> はCephファイルシステム内の絶対パスを指し、ローカルにはマウントしないでください。</p>

<pre><code>		[share]
		vfs objects = ceph_snapshots ceph
		path = /non-mounted/cephfs/path
		kernel share modes = no</code></pre>

<p><code>vfs_ceph_snapshots</code> は、<code>vfs_ceph</code> を使わず、カーネルのCephFSでマウントした共有パスの上でも使用できます。この場合、Sambaの既定のVFSバックエンド <code>vfs_default</code> を使用します。</p>

<pre><code>		[share]
		vfs objects = ceph_snapshots
		path = /mnt/cephfs/</code></pre>

### オプション {#OPTIONS}


<dl><dt>ceph:snapdir = subdirectory</dt><dd><p>CephFSの特別なスナップショットサブディレクトリ名を設定できます。このパラメーターを既定値「.snap」から変更してよいのは、ceph.confの <code>client snapdir</code>、またはマウントオプション <code>snapdirname</code> の設定を、対応する既定値「.snap」から変更した場合だけです。</p>
<p>既定値: <a href="https://www.samba.org/samba/docs/current/man-html/smb.conf.5.html#CEPH:SNAPDIR">ceph:snapdir = .snap</a></p>
<p>例: <a href="https://www.samba.org/samba/docs/current/man-html/smb.conf.5.html#CEPH:SNAPDIR">ceph:snapdir = .snapshots</a></p></dd></dl>
