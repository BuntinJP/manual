### 名前 {#Name}


<p>vfs_readonly — 指定した期間にSamba共有を読み取り専用にする</p>

### 書式 {#Synopsis}


<p><code>vfs objects = readonly</code></p>

### 説明 {#DESCRIPTION}


<p>このVFSモジュールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.7.html">samba(7)</a> スイートの一部です。</p>

<p><code>vfs_readonly</code> VFSモジュールは、設定された期間内に接続するすべてのクライアントに対して、共有を読み取り専用として扱います。その期間中に接続したクライアントは、実際のアクセス権限にかかわらず、共有内のすべてのファイルへの書き込みアクセスを拒否されます。</p>

<p>このモジュールは他のモジュールと積み重ねて使用できます。</p>

### オプション {#OPTIONS}


<dl><dt>readonly:period = BEGIN, END</dt><dd><p>クライアントの接続が、BEGINとENDの日付指定子が示す時刻の間に行われた場合にのみ、共有を読み取り専用として扱います。これらの日付指定子の構文は、GNU <a href="https://www.samba.org/samba/docs/current/man-html/date.1.html">date(1)</a> の <code>-d</code> オプションが受け付けるものと同じです。</p></dd></dl>

### 使用例 {#EXAMPLES}


<p>すべての共有を読み取り専用にします。</p>

<pre><code>        [global]
	vfs objects = readonly</code></pre>

<p>営業時間中は[backup]共有を読み取り専用として扱います。</p>

<pre><code>        [backup]
	path = /readonly
	vfs objects = readonly
	readonly:period = readonly:period = &quot;today 9:00&quot;,&quot;today 17:00&quot;</code></pre>
