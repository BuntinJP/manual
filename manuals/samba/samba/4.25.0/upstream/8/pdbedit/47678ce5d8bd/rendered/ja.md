### 名前 {#Name}


<p>pdbedit — SAM データベース（Samba ユーザーのデータベース）を管理する</p>

### 説明 {#DESCRIPTION}


<p>このツールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.7.html">samba(7)</a> スイートの一部です。</p>

<p>pdbedit プログラムは、SAM データベースに保存されたユーザーアカウントを管理するために使います。root だけが実行できます。</p>

<p>pdbedit ツールは passdb のモジュール式インターフェースを使い、利用するユーザーデータベースの種類に依存しません（現在は smbpasswd、ldap、nis+、tdb ベースのものがあり、ツールを変更せずに追加できます）。</p>

<p>pdbedit の主な用途は、ユーザーアカウントの追加、削除、変更、一覧表示、インポートの5つです。</p>

<h4 id="Note">注</h4>
<p><a href="https://www.samba.org/samba/docs/current/man-html/smb.conf.5.html#UNIXPASSWORDSYNC">unix password sync</a> が設定されていても、pdbedit は UNIX パスワード同期スクリプトを呼び出しません。Samba ユーザーデータベース内のデータだけを更新します。</p>

<p>例: <code>pdbedit -a -m -u w2k-wks</code></p></dd><dt><code>-x</code>|<code>--delete</code></dt><dd><p>pdbedit は、データベースからアカウントを削除します。<code>-u</code> スイッチでユーザー名を指定する必要があります。</p>
<p>例: <code>pdbedit -x -u bob</code></p></dd><dt><code>-i</code>|<code>--import</code> passdb-backend</dt><dd><p>smb.conf で指定したものとは異なる passdb バックエンドからユーザーを取得します。ローカルのユーザーデータベースへのデータのインポートに使えます。</p>
<p>ある passdb バックエンドから別のバックエンドへの移行を容易にします。</p>
<p>例: <code>pdbedit -i smbpasswd:/etc/smbpasswd.old</code></p></dd><dt><code>-e</code>|<code>--export</code> passdb-backend</dt><dd><p>現在利用できるすべてのユーザーを、指定したパスワードデータベースのバックエンドへエクスポートします。</p>
<p>ある passdb バックエンドから別のバックエンドへの移行と、バックアップを容易にします。</p>
<p>例: <code>pdbedit -e smbpasswd:/root/samba-users.backup</code></p></dd><dt><code>-g</code>|<code>--group</code></dt><dd><p><em><code>-g</code></em> を指定すると、<em><code>-i in-backend -e out-backend</code></em> は、ユーザーデータベースではなくグループマッピングに適用されます。</p>
<p>ある passdb バックエンドから別のバックエンドへの移行と、バックアップを容易にします。</p></dd><dt><code>-b</code>|<code>--backend</code> passdb-backend</dt><dd><p>別の既定の passdb バックエンドを使います。</p>
<p>例: <code>pdbedit -b xml:/root/pdb-backup.xml -l</code></p></dd><dt><code>-P</code>|<code>--account-policy</code> account-policy</dt><dd><p>アカウントポリシーを表示します。</p>
<p>有効なポリシーは、minimum password age、reset count minutes、disconnect time、user must logon to change password、password history、lockout duration、min password length、maximum password age、bad lockout attempt です。</p>

<pre><code>account policy value for bad lockout attempt is 0</code></pre></dd><dt><code>-C</code>|<code>--value</code> account-policy-value</dt><dd><p>アカウントポリシーを指定した値に設定します。<em><code>-P</code></em> オプションとの併用時だけ使えます。</p>
<p>例: <code>pdbedit -P &quot;bad lockout attempt&quot; -C 3</code></p>
<pre><code>account policy value for bad lockout attempt was 0

<p>例: <code>-I &quot;MYDOMAIN&quot;</code></p></dd><dt><code>--time-format</code></dt><dd><p>このオプションは現在使われていません。</p></dd><dt>-?|<code>--help</code></dt><dd><p>コマンドラインオプションの概要を表示します。</p></dd><dt><code>--usage</code></dt><dd><p>簡単な使用方法を表示します。</p></dd><dt><code>-d</code>|<code>--debuglevel</code>=level</dt><dd><p><em><code>level</code></em> は0から10の整数です。このパラメーターを省略した場合、クライアントアプリケーションでの既定値は1です。</p>
<p>値を大きくすると、サーバーの動作についてログファイルに記録する詳細が増えます。レベル0では重大なエラーと深刻な警告だけを記録します。レベル1は日常的な運用に適しており、実行した操作について少量の情報を生成します。</p>

<p>ここでこのパラメーターを指定すると、<code>${prefix}/etc/smb.conf</code> ファイルの <a href="https://www.samba.org/samba/docs/current/man-html/smb.conf.5.html#LOGLEVEL">log level</a> パラメーターを上書きします。</p></dd><dt><code>--debug-stdout</code></dt><dd><p>デバッグ出力を標準出力へ転送します。既定では、すべてのクライアントは標準エラー出力へログを出します。</p></dd><dt><code>--configfile</code>=&lt;configuration file&gt;</dt><dd><p>指定したファイルには、クライアントが必要とする設定の詳細を記述します。クライアントとサーバーに共通の情報のほか、<a href="https://www.samba.org/samba/docs/current/man-html/smb.conf.5.html#CLIENTSMBENCRYPT">client smb encrypt</a> などのクライアント固有のオプションだけを記述することもできます。詳細は <code>${prefix}/etc/smb.conf</code> を参照してください。既定の設定ファイル名はコンパイル時に決まります。</p></dd><dt><code>--option</code>=&lt;name&gt;=&lt;value&gt;</dt><dd><p>コマンドラインから <a href="https://www.samba.org/samba/docs/current/man-html/smb.conf.5.html">smb.conf(5)</a> オプション &quot;&lt;name&gt;&quot; を値 &quot;&lt;value&gt;&quot; に設定します。コンパイル時の既定値と設定ファイルから読み込んだオプションを上書きします。名前や値に空白が含まれる場合は、<code>--option</code>=name=value 全体を引用符で囲んでください。</p></dd><dt><code>-l</code>|<code>--log-basename</code>=logdirectory</dt><dd><p>ログ/デバッグファイルの基底ディレクトリ名です。拡張子 <code>&quot;.progname&quot;</code> が追加されます（log.smbclient、log.smbd など）。クライアントがログファイルを削除することはありません。</p></dd><dt><code>--leak-report</code></dt><dd><p>終了時の talloc リーク報告を有効にします。</p></dd><dt><code>--leak-report-full</code></dt><dd><p>終了時の完全な talloc リーク報告を有効にします。</p></dd><dt><code>-V</code>|<code>--version</code></dt><dd><p>プログラムのバージョン番号を表示します。</p></dd></dl>
