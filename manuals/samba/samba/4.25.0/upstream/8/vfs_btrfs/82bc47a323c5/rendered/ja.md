### 名前 {#Name}


<p>vfs_btrfs — Btrfsファイルシステムが提供する機能を利用する</p>

### 書式 {#Synopsis}


<p><code>vfs objects = btrfs</code></p>

### 説明 {#DESCRIPTION}


<p>このVFSモジュールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.8.html">samba(8)</a> スイートの一部です。</p>

<p><code>vfs_btrfs</code> VFSモジュールは、Sambaで利用できるようBtrfs固有の機能を公開します。</p>

<p>Btrfsでは、クローンした範囲を使うことにより、複数のファイルがディスク上の同じデータを共有できます。SMBクライアントが（FSCTL_SRV_COPYCHUNK経由で）データの複製を要求すると、このモジュールは従来のコピーに必要な読み書きを行う代わりに、その要求をBtrfsの範囲クローンIOCTLへ対応付けます。これにより、ストレージ容量を節約し、ディスクI/Oを大幅に減らせます。</p>

<p>このモジュールは、圧縮の取得/設定用fsctlを通じて、Btrfsのファイル単位の圧縮機能もSMBクライアントに公開します。</p>

<p>BtrfsスナップショットはSambaのFSRVPサーバーで操作できます。このモジュールによるスナップショット操作は現在実験的とみなされているため、既定では無効です。この目的には、代わりに <code>vfs_snapper</code> モジュールを推奨します。</p>

<p>このモジュールは他のモジュールと積み重ねて使用できます。</p>

### オプション {#OPTIONS}


<dl><dt>btrfs: manipulate snapshots = [yes|no]</dt><dd><p><em>yes</em>に設定すると、対応するBtrfs IOCTLによるスナップショットの作成と削除を実験的にサポートします。既定値は <em>no</em> で、この場合、そうした要求は下位のVFSモジュールにそのまま渡されます。</p></dd></dl>

### 設定 {#CONFIGURATION}


<p><code>vfs_btrfs</code> では、下位の共有パスがBtrfsサブボリュームである必要があります。</p>

<pre><code>		[share]
		vfs objects = btrfs
		btrfs: manipulate snapshots = no</code></pre>

<p>このモジュールが提供する実験的なスナップショット操作機能を使用するには、明示的に有効にし、SambaのFSRVPサーバーを動作させる必要があります。</p>

<p><code>vfs_shadow_copy</code> モジュールを使うと、<code>vfs_btrfs</code> が作成したスナップショットを、ファイル/ディレクトリの「以前のバージョン」としてWindowsエクスプローラーに公開できます。</p>

<pre><code>		[global]
		registry shares = yes
		include = registry

		[share]
		vfs objects = btrfs shadow_copy
		btrfs: manipulate snapshots = yes</code></pre>
