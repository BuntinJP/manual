### 名前 {#Name}


<p>vfs_glusterfs_fuse — GlusterFSが提供する機能を利用する</p>

### 書式 {#Synopsis}


<p><code>vfs objects = glusterfs_fuse</code></p>

### 説明 {#DESCRIPTION}


<p>このVFSモジュールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.8.html">samba(8)</a> スイートの一部です。</p>

<p>GlusterFS（<a href="http://www.gluster.org/">http://www.gluster.org</a>）は、数ペタバイトまで拡張可能なオープンソースのクラスタファイルシステムです。FUSEベースのネイティブクライアントにより、GlusterFSをPOSIX準拠のファイルシステムとして利用できるため、追加の手順なしにSambaで共有できます。</p>

<p><code>vfs_glusterfs_fuse</code> VFSモジュールは、Gluster FUSEマウントを使ってGlusterファイルシステムへアクセスする機能を強化します。<code>get_real_filename</code> VFS呼び出しをサポートし、既存のファイル名の正しい大文字・小文字表記を検出するための、負荷の高いcase folding検索呼び出しを何度も行わずに済むようにして、ファイルアクセス性能を向上させます。</p>

<p>さらに、このモジュールは代替のfile-id機構を実装します。既定のfile-id機構は、gluster fuseマウントの再公開では正しく動作しません。そのため、データ損失を避けるために、Sambaでgluster fuseマウントを公開するユーザーは、このモジュールを有効にしてください。</p>

<p>このモジュールは他のモジュールと組み合わせられますが、<code>vfs objects</code> リストの最後に置いてください。このリストでglusterfsエントリーの右側に追加したモジュールは、まったく効果がない場合があります。</p>

### 設定 {#CONFIGURATION}


<p>基本的な設定は次のようになります。</p>

<pre><code>		[share]
		vfs objects = glusterfs_fuse
		path = /absolute/path_of_fusemount</code></pre>

<p><code>vfs_glusterfs_fuse</code> にはGlusterマウントが必要です。GFAPIライブラリ経由でglusterfsへ直接アクセスするには、<code>vfs_glusterfs</code> モジュールを使用してください。</p>

### オプション {#OPTIONS}


<p>このモジュールには、現時点で追加のオプションはありません。</p>
