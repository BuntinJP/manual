### 名前 {#Name}


<p>winbind_krb5_locator — Windows と同じ方式で KDC を検出する MIT および Heimdal Kerberos 用プラグイン</p>

### 説明 {#DESCRIPTION}


<p>このプラグインは <a href="https://www.samba.org/samba/docs/current/man-html/samba.7.html">samba(7)</a> スイートの一部です。</p>

<p><code>winbind_krb5_locator</code> は、MIT および Heimdal Kerberos ライブラリーが、Samba スイートの他のツールと同じ方式で Kerberos サーバー（KDC と kpasswd サービス用）を検出できるようにするプラグインです。これには、サイトを考慮した DNS サービスレコードの検索や、最も近いドメインコントローラーのキャッシュが含まれます。このプラグインは、現代的な Kerberos 実装の多くが提供する公開ロケーター API を使用します。</p>

### 前提条件 {#PREREQUISITES}


<p>MIT Kerberos のバージョン 1.5 以降、または Heimdal Kerberos のバージョン 1.0 以降が必要です。</p>

<p>このプラグインは <a href="https://www.samba.org/samba/docs/current/man-html/winbindd.8.html">winbindd(8)</a> デーモンに問い合わせるため、このデーモンを別途設定して起動する必要があります。</p>

<p><code>winbind_krb5_locator.so</code> ファイルを、システムの Kerberos ライブラリーのプラグインディレクトリーへ手動でコピーする必要があります。MIT Kerberos では通常 <code>/usr/lib/krb5/plugins/libkrb5/</code>、Heimdal Kerberos では通常 <code>/usr/lib/plugin/krb5/</code> です。正しいパスはローカルの Kerberos のインストール内容を確認してください。このプラグインの使用を有効にするために <code>/etc/krb5.conf</code> を変更する必要はありません。</p>

<p>ロケータープラグインを適切なプラグインディレクトリーへコピーすると、すぐに使用できるはずです。ユーザーは、設定を変更したり <code>/etc/krb5.conf</code> にサーバーを手動で追加したりせずに、Kerberos を導入した Windows 環境で kinit を実行できるはずです。</p>
