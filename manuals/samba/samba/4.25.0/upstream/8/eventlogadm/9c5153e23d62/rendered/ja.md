### 名前 {#Name}


<p>eventlogadm — Samba イベントログストアにレコードを書き込む</p>

### 書式 {#Synopsis}


<p><code>eventlogadm</code> [<code>-s</code>] [<code>-d</code>] [<code>-h</code>] <code>-o</code> <code>addsource</code> <em><code>EVENTLOG</code></em> <em><code>SOURCENAME</code></em> <em><code>MSGFILE</code></em></p>

<p><code>eventlogadm</code> [<code>-s</code>] [<code>-d</code>] [<code>-h</code>] <code>-o</code> <code>write</code> <em><code>EVENTLOG</code></em></p>

<p><code>eventlogadm</code> [<code>-s</code>] [<code>-d</code>] [<code>-h</code>] <code>-o</code> <code>dump</code> <em><code>EVENTLOG</code></em> <em><code>RECORD_NUMBER</code></em></p>

### 説明 {#DESCRIPTION}


<p>このツールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.1.html">samba(1)</a> スイートの一部です。</p>

<p><code>eventlogadm</code> は、整形されたイベントログレコードを標準入力から受け取り、Samba イベントログストアに書き込むフィルターです。その後 Windows クライアントは、通常の管理ツールでこれらのレコードを操作できます。</p>

### オプション {#OPTIONS}


<dl><dt><code>-s</code> <em><code>FILENAME</code></em></dt><dd><p><code>-s</code> オプションは、Samba の既定の設定ファイルの代わりに、FILENAME として指定した設定ファイルを <code>eventlogadm</code> に読み込ませます。</p></dd><dt><code>-d</code></dt><dd><p><code>-d</code> オプションは、<code>eventlogadm</code> にデバッグ情報を出力させます。</p></dd><dt><code>-o</code> <code>addsource</code> <em><code>EVENTLOG</code></em> <em><code>SOURCENAME</code></em> <em><code>MSGFILE</code></em></dt><dd><p><code>-o addsource</code> オプションは、新しいイベントログソースを作成します。</p></dd><dt><code>-o</code> <code>write</code> <em><code>EVENTLOG</code></em></dt><dd><p><code>-o write</code> は、標準入力からイベントログレコードを読み取り、EVENTLOG で指定した Samba イベントログストアに書き込みます。</p></dd><dt><code>-o</code> <code>dump</code> <em><code>EVENTLOG</code></em> <em><code>RECORD_NUMBER</code></em></dt><dd><p><code>-o dump</code> は EVENTLOG tdb からイベントログレコードを読み取り、画面上の標準出力にダンプします。</p></dd><dt><code>-h</code></dt><dd><p>使用方法を表示します。</p></dd></dl>

### イベントログレコード形式 {#EVENTLOG-RECORD-FORMAT}


<p>書き込み操作では、<code>eventlogadm</code> は標準入力から構造化されたレコードを読み取ることを想定しています。レコードは一連の行で構成され、レコードのキーとデータをコロンで区切ります。レコード同士は 1 行以上の空行で区切ります。</p>

<p>イベントログレコードのフィールドは次のとおりです。</p>

<ul><li><p><code>LEN</code> - <code>eventlogadm</code> が値を計算するため、このフィールドは 0 にしてください。</p></li><li><p><code>RS1</code> - 必ず値 1699505740 にしてください。</p></li><li><p><code>RCN</code> - このフィールドは 0 にしてください。</p></li><li><p><code>TMG</code> - イベントログレコードが生成された時刻。形式は UTC の 1970 年 1 月 1 日 00:00:00 からの秒数です。</p></li><li><p><code>TMW</code> - イベントログレコードが書き込まれた時刻。形式は UTC の 1970 年 1 月 1 日 00:00:00 からの秒数です。</p></li><li><p><code>EID</code> - イベントログ ID。</p></li><li><p><code>ETP</code> - イベントの種類。&quot;INFO&quot;、&quot;ERROR&quot;、&quot;WARNING&quot;、&quot;AUDIT SUCCESS&quot;、&quot;AUDIT FAILURE&quot; のいずれかです。</p></li><li><p><code>ECT</code> - イベントのカテゴリー。メッセージファイルに依存します。主にイベントログビューアーでの絞り込みに使用します。</p></li><li><p><code>RS2</code> - このフィールドは 0 にしてください。</p></li><li><p><code>CRN</code> - このフィールドは 0 にしてください。</p></li><li><p><code>USL</code> - このフィールドは 0 にしてください。</p></li><li><p><code>SRC</code> - イベントログに関連付けられたソース名を含みます。イベントログにメッセージファイルを使用する場合、このソース名とメッセージファイル DLL を関連付けるレジストリーエントリーが存在します。</p></li><li><p><code>SRN</code> - イベントログを生成したマシンの名前。通常はホスト名です。</p></li><li><p><code>STR</code> - イベントログに関連付けられたテキスト。1 レコードに複数の文字列がある場合もあります。</p></li><li><p><code>DAT</code> - このフィールドは未設定のままにしてください。</p></li></ul>

### 使用例 {#EXAMPLES}


<p><code>eventlogadm</code> が受け付けるレコード形式の例:</p>

<pre><code>	LEN: 0
	RS1: 1699505740
	RCN: 0
	TMG: 1128631322
	TMW: 1128631322
	EID: 1000
	ETP: INFO
	ECT: 0
	RS2: 0
	CRN: 0
	USL: 0
	SRC: cron
	SRN: dmlinux
	STR: (root) CMD ( rm -f /var/spool/cron/lastrun/cron.hourly)
	DAT:</code></pre>

<p>メッセージファイル DLL を指定してイベントログソースを設定します。</p>

<pre><code>	eventlogadm -o addsource Application MyApplication | \\
	    	%SystemRoot%/system32/MyApplication.dll</code></pre>

<p>システムログのメッセージをフィルターに通してイベントログに書き込みます。</p>

<pre><code>	tail -f /var/log/messages | \\
		my_program_to_parse_into_eventlog_records | \\
	      	eventlogadm SystemLogEvents</code></pre>
