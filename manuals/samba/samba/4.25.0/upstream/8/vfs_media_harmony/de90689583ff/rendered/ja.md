### 名前 {#Name}


<p>vfs_media_harmony — 複数の Avid クライアントによるネットワークドライブの共有を可能にする</p>

### 書式 {#Synopsis}


<p><code>vfs objects = media_harmony</code></p>

### 説明 {#DESCRIPTION}


<p>この VFS モジュールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.7.html">samba(7)</a> スイートの一部です。</p>

<p><code>vfs_media_harmony</code> VFS モジュールは、Avid 編集ワークステーションによるネットワークドライブの共有を可能にします。次の方法で実現します。</p>

<ol><li><p>各クライアントに、Avid の msmMMOB.mdb と msmFMID.pmr ファイル、および Creating ディレクトリの専用コピーを与えます。</p></li><li><p>各クライアントが、Avid アプリケーションから見える Avid メディアディレクトリの書き込み時刻を明示的に制御できるようにします。</p></li></ol>

<p>このモジュールは他のモジュールと積み重ねて使用できます。</p>

### 設定 {#CONFIGURATION}


<p><code>vfs_media_harmony</code> は、Avid データベースファイルまたは Avid の Creating ディレクトリに対するクライアントの要求を、クライアント固有のファイルへ自動的に転送します。この機能にはモジュールを有効にする以外の設定は不要です。</p>

<p>Mac と Windows の Avid クライアントが同じフォルダーにアクセスする場合、別々の共有定義を与え、Windows 共有では Mac の隠しファイルを veto により除外する必要があります。「例」を参照してください。</p>

<p>各クライアントが Avid アプリケーションによるデータベース更新の時期を制御できるようにするには、各クライアントと各 Avid メディアディレクトリについて、[avid_dir_name]_[client_ip_address]_[client_username] という名前のファイルを作成します。これらのファイルの書き込み時刻を更新すると、Avid データベースの更新を促します。「例」を参照してください。</p>

<p>クライアントが Avid メディアフォルダーの書き込み時刻を制御するには、<code>cache locked write times = no</code> オプションも設定する必要があります。</p>

### 例 {#EXAMPLES}


<p>Mac と Windows クライアント向けに media_harmony を有効にします。</p>

<pre><code>        [avid_mac]
	path = /avid
	vfs objects = media_harmony
	cache locked write times = no
        [avid_win]
	path = /avid
	vfs objects = media_harmony
	cache locked write times = no
	veto files = /.DS_Store/._@/.Trash@/.Spotlight@/.hidden/.hotfiles@/.vol/
	delete veto files = yes</code></pre>

<p>ユーザー david と susan が各自の Avid データベース更新を制御できるようにするファイルを作成します。</p>

<pre><code>	touch &#39;/avid/OMFI MediaFiles_192.168.1.10_david&#39; \
		&#39;/avid/OMFI MediaFiles_192.168.1.11_susan&#39; \
		&#39;/avid/Avid MediaFiles/MXF/1_192.168.1.10_david&#39; \
		&#39;/avid/Avid MediaFiles/MXF/1_192.168.1.11_susan&#39;</code></pre>

<p>ユーザー david の Avid データベース更新を促します。</p>

<pre><code>	touch &#39;/avid/OMFI MediaFiles_192.168.1.10_david&#39; \
		&#39;/avid/Avid MediaFiles/MXF/1_192.168.1.10_david&#39;</code></pre>

<p>多数の Avid メディアフォルダーを管理する場合は、examples/scripts/vfs/media_harmony/trigger_avid_update.py を適切に修正して各編集者に渡し、これらのファイルを作成・更新させることができます。</p>

### 注意事項 {#CAVEATS}


<p><code>vfs_media_harmony</code> は、Avid MediaFiles または OMFI MediaFiles ディレクトリ内のメディアを探す Avid 編集アプリケーション向けに設計されています。汎用の用途であらゆる状況において期待どおりに動作するようには設計されていません。たとえば、msmMMOB.mdb_192.168.1.10_userx のようなクライアント固有のファイルは、ディレクトリ一覧に表示されなくても開くことができます。</p>
