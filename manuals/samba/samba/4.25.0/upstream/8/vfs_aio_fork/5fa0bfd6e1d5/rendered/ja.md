### 名前 {#Name}


<p>vfs_aio_fork — Samba VFS に非同期 I/O を実装する</p>

### 書式 {#Synopsis}


<p><code>vfs objects = aio_fork</code></p>

### 説明 {#DESCRIPTION}


<p>この VFS モジュールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.7.html">samba(7)</a> スイートの一部です。</p>

<p><code>aio_fork</code> VFS モジュールは、システムレベルの POSIX AIO インターフェースが不十分なプラットフォームで、Samba の非同期 I/O を有効にします。POSIX AIO には厳しい制限があることがあります。たとえば、一部の Linux バージョンでは、使用するリアルタイムシグナルが高負荷時に正常に動作しません。他のシステムでは、特別なカーネルモジュールを読み込んだ場合にしか AIO を使えなかったり、スケジュールできる非同期要求数にシステム全体の上限があったりします。glibc ベースのシステム（ほとんどの Linux システム）では、ファイル記述子ごとに未完了の要求を 1 つしか持てません。</p>

<p>これらすべての制限を回避するため、aio_fork モジュールが作成されました。内部の POSIX AIO インターフェースの代わりに、fork したヘルパープロセスを使用して、read と write 呼び出しを非同期にします。パラメーターはなく、非同期要求が届いたときに必要に応じてヘルパープロセスを作成します。アイドル状態のヘルパープロセスは 30 秒ごとに削除されます。</p>

<p>このモジュールは、他のモジュールと重ねて使用できます。</p>

### 使用例 {#EXAMPLES}


<p>基本的な使用例:</p>

<pre><code>        [cooldata]
	path = /data/ice
	vfs objects = aio_fork</code></pre>
