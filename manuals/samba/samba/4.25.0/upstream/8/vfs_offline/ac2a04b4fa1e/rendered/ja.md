### 名前 {#Name}


<p>vfs_offline — すべてのファイルをオフラインとしてマークする</p>

### 書式 {#Synopsis}


<p><code>vfs objects = offline</code></p>

### 説明 {#DESCRIPTION}


<p>この VFS モジュールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.7.html">samba(7)</a> スイートの一部です。</p>

<p><code>vfs_offline</code> モジュールは、共有内のすべてのファイルを、DOS の offline 属性を持つものとしてマークします。</p>

<p>DOS の offline 属性を持つファイルは、Windows SMB クライアントと Windows Explorer の両方で通常とは異なる扱いを受けます。特に、Windows Explorer は通常とは異なり、サムネイルの描画だけを目的としてこれらのファイルを読み取りません。一部のリモートファイルシステムでは、これにより操作感が向上することがあります。</p>

### 使用例 {#EXAMPLES}


<p>共有内のすべてのファイルをオフラインとしてマークします。</p>

<pre><code>        [remote]
	vfs objects = offline</code></pre>
