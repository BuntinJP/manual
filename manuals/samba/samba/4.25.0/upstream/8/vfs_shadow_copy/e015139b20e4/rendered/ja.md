### 名前 {#Name}


<p>vfs_shadow_copy — スナップショットをシャドウコピーとして Windows クライアントに公開する</p>

### 書式 {#Synopsis}


<p><code>vfs objects = shadow_copy</code></p>

### 説明 {#DESCRIPTION}


<p>この VFS モジュールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.7.html">samba(7)</a> スイートの一部です。</p>

<p><code>vfs_shadow_copy</code> VFS モジュールは Microsoft Shadow Copy サービスに似た機能を提供します。正しく設定すると、Microsoft Shadow Copy クライアントが Samba 共有上の「シャドウコピー」を参照できます。</p>

<p>このモジュールは他のモジュールと積み重ねて使用できます。</p>

### 設定 {#CONFIGURATION}


<p><code>vfs_shadow_copy</code> はファイルシステムのスナップショット実装に依存します。一般的なファイルシステムの多くはこの機能を標準でサポートします。</p>

<p><code>vfs_shadow_copy</code> が認識するには、ファイルシステムのスナップショットを特別な名前のディレクトリにマウントする必要があります。マウントポイントは共有ディレクトリの直下になければなりません。</p>

<p>スナップショットの命名規則は @GMT-YYYY.MM.DD-hh.mm.ss で、各部分の意味は次のとおりです。</p>

<ul><li><p><code>YYYY</code> は4桁の年</p></li><li><p><code>MM</code> は2桁の月</p></li><li><p><code>DD</code> は2桁の日</p></li><li><p><code>hh</code> は2桁の時</p></li><li><p><code>mm</code> は2桁の分</p></li><li><p><code>ss</code> は2桁の秒です。</p></li></ul>

<p><code>vfs_shadow_copy</code> のスナップショット命名規則に従う名前は、次の <a href="https://www.samba.org/samba/docs/current/man-html/date.1.html">date(1)</a> コマンドで生成できます。</p>

<pre><code>	TZ=GMT date +@GMT-%Y.%m.%d-%H.%M.%S</code></pre>

### 例 {#EXAMPLES}


<p>ユーザーのホームディレクトリにシャドウコピーのサポートを追加します。</p>

<pre><code>        [homes]
	vfs objects = shadow_copy</code></pre>

### 注意事項 {#CAVEATS}


<p>これはバックアップ、アーカイブ、バージョン管理のためのソリューションではありません。</p>

<p>Samba または Windows サーバーで、<code>vfs_shadow_copy</code> はエンドユーザー専用のツールとして設計されています。バックアップやアーカイブの仕組みを置き換えたり強化したりするものではなく、そのようにみなしてはいけません。また、バージョン管理が必要なら、バージョン管理システムを導入してください。</p>
