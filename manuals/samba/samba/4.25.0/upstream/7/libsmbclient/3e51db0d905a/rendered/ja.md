### 名前 {#Name}


<p>libsmbclient — ブラウザー用の拡張ライブラリー。汎用的なブラウズ API としても使用できます。</p>

### 書式 {#Synopsis}


<p>ブラウザーの URL: <code>smb://[[[domain:]user[:password@]]server[/share[/path[/file]]]] [?options]</code></p>

### 説明 {#DESCRIPTION}


<p>このツールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.7.html">samba(7)</a> スイートの一部です。</p>

<p><code>libsmbclient</code> は、ローカルの UNIX/Linux ファイル操作に使われる標準 POSIX 関数の多くを利用して、アプリケーションが CIFS/SMB ネットワークリソースを操作できるようにするライブラリー群です。単にブラウズするだけでなく、ファイルを開いて読み書きし、アクセス権やファイル時刻を変更し、属性や ACL を操作するなど、多くの処理が可能です。当然、一般にブラウズと呼ばれるすべての機能も含まれます。</p>

<p><code>libsmbclient</code> はコマンドラインから直接使うものではなく、ファイルマネージャーやブラウザーなどの機能を拡張します。このマニュアルページでは、ユーザーが最大限に活用できるよう、このツールの設定オプションを説明します。</p>

### オプション {#OPTIONS}


<p>URL の意味は次のとおりです。</p>

<dl><dt>smb://</dt><dd><p>ネットワーク上で参照できるすべてのワークグループまたはドメインを表示します。動作は Microsoft Windows Explorer と同じです。</p>
<p>ワークグループ（およびドメイン）の一覧を取得する方法は、コンテキスト変数 <code>(context-&gt;options.browse_max_lmb_count)</code> の設定によって異なります。適切な値を設定するのは、このライブラリーを呼び出すアプリケーションの責任です。これはコンパイル時のオプションです。この値は、ワークグループ一覧を問い合わせるローカルマスターブラウザーの最大数を決めます。ネットワークに存在するワークグループの完全な一覧を得るには、すべてのマスターブラウザーに問い合わせる必要があります。ワークグループが多い場合、問い合わせには相当な時間がかかります。小規模ネットワーク（ワークグループが少数）では、この値を0にし、すべてのローカルマスターブラウザーに問い合わせるよう libsmbclient に指示することを推奨します。多数のワークグループがある環境では、3程度がより適切な場合があります。</p></dd><dt>smb://name/</dt><dd><p>このコマンドにより libsmbclient は名前検索を行います。NAME&lt;1D&gt; または NAME&lt;1B&gt;（ワークグループ名）が存在する場合、ワークグループ（またはドメイン）のすべてのサーバーを一覧表示します。それ以外では NAME&lt;20&gt;（マシン名）を検索し、サーバー上の共有リソース一覧を表示します。</p></dd></dl>

<p>アプリケーションから呼び出されると、libsmbclient はユーザーのシェル環境で指定された $HOME ディレクトリ内の <code>.smb</code> ディレクトリを探します。次に <code>smb.conf</code> というファイルを探し、あればシステムの <code>${prefix}/etc/smb.conf</code> ファイルを完全に上書きします。代わりに <code>~/.smb/smb.conf.append</code> というファイルが見つかった場合は、システムの <code>/etc/samba/smb.conf</code> を読み、その後に <code>~/.smb/smb.conf.append</code> の内容を追加します。</p>

<p><code>libsmbclient</code> はユーザーのシェル環境で <code>USER</code> パラメーターを調べ、URL に <code>user</code> パラメーターが含まれていない場合はその値を使います。</p>
