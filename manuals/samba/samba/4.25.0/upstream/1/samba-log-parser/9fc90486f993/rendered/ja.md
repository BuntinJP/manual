### 名前 {#Name}


<p>samba-log-parser — Samba (winbind) トレース解析ツール</p>

<p>オプション: <code>-h</code>, <code>--help</code> このヘルプメッセージを表示して終了する <code>--traceid</code> ID トレースレコードの traceid を指定する <code>--pid</code> PID winbind クライアントの pid を指定する <code>--breakdown</code> トレースを traceid ごとのファイルに分割する <code>--merge-by-timestamp</code> タイムスタンプ順にログを統合する <code>--flow</code> 要求/副要求のフロートレースを表示する <code>--flow-compact</code> dcerpc の詳細を除いて要求/副要求のフロートレースを表示する</p>

### 書式 {#Synopsis}


<p><code>samba-log-parser</code> {path} [<code>--pid</code>=PID] [<code>--traceid</code>=ID] [<code>--breakdown</code>] [<code>--merge-by-timestamp</code>] [<code>--flow</code>] [<code>--flow-compact</code>] [<code>-h</code>|<code>--help</code>]</p>

### 説明 {#DESCRIPTION}


<p>このツールは <a href="https://www.samba.org/samba/docs/current/man-html/samba.7.html">samba(7)</a> スイートの一部です。</p>

<p><code>samba-log-parser</code> プログラムは samba の winbind ログを解析します。</p>

### オプション {#OPTIONS}


<p><code>samba-log-parser</code> プログラムでは次のオプションを使用できます。</p>

<dl><dt><code>--pid</code>=PID</dt><dd><p>一致する PID の winbind クライアントのトレースを表示します。</p></dd><dt><code>--traceid</code>=ID</dt><dd><p>デバッグヘッダーの traceid フィールドが一致するトレースを表示します。</p></dd><dt><code>--breakdown</code></dt><dd><p>すべてのトレースを現在の作業ディレクトリー内の個別ファイルに分割します。各 traceid について traceid.full traceid.flow traceid.flowcompact の 3 ファイルを作成します。</p></dd><dt><code>--merge-by-timestamp</code></dt><dd><p>トレース行をタイムスタンプ順に並べ替えます。traceid ヘッダーフィールドのないログファイルでも動作します。</p></dd><dt><code>--flow</code></dt><dd><p>要求/副要求のフローを表示します。</p></dd><dt><code>--flow-compact</code></dt><dd><p>dcerpc 呼び出しの詳細を除いて要求/副要求のフローを表示します。</p></dd></dl>

### 使用例 {#EXAMPLES}


<p>ログファイル log.winbind から、トレース ID <em><code>1234</code></em> のフロートレースを表示します。</p>

<pre><code>	# samba-log-parser --traceid 1234 --flow /var/log/samba/log.winbind</code></pre>

<p>samba ログディレクトリー内のログファイルから、PID <em><code>999999</code></em> の winbind クライアントの完全なトレースをタイムスタンプ順に表示します。</p>

<pre><code>	# samba-log-parser --pid 999999 --merge-by-timestamp /var/log/samba</code></pre>

<p>samba ログディレクトリー内のログファイルから、トレースを traceid ごとの個別ファイルに分割し、タイムスタンプ順に並べます。</p>

<pre><code>	# samba-log-parser --breakdown --merge-by-timestamp /var/log/samba</code></pre>

<p>samba ログディレクトリー内のログファイルのトレースをタイムスタンプ順に並べ替えます。トレースに traceid ヘッダーフィールドが含まれている必要はありません。</p>

<pre><code>	# samba-log-parser --merge-by-timestamp /var/log/samba</code></pre>
