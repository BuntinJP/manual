### 名前 {#Name}


<p>lmhosts — Samba の NetBIOS ホストファイル</p>

### 書式 {#Synopsis}


<p><code>lmhosts</code> は <a href="https://www.samba.org/samba/docs/current/man-html/samba.7.html">samba(7)</a> の NetBIOS 名を IP アドレスに対応付けるファイルです。</p>

### 説明 {#DESCRIPTION}


<p>このファイルは <a href="https://www.samba.org/samba/docs/current/man-html/samba.7.html">samba(7)</a> スイートの一部です。</p>

<p><code>lmhosts</code> は <em>Samba</em> の NetBIOS 名を IP アドレスに対応付けるファイルです。<code>/etc/hosts</code> の形式によく似ていますが、ホスト名部分は NetBIOS の命名形式に従う必要があります。</p>

### ファイル形式 {#FILE-FORMAT}


<p>NetBIOS 名ごとに1行を含む ASCII ファイルです。各行の2つのフィールドは空白で区切ります。「#」で始まるエントリーは無視されます。lmhosts の各行には次の情報を含めます。</p>

<ul><li><p>IP アドレス - ドット区切り10進数形式。</p></li><li><p>NetBIOS 名 - 最大15文字のホスト名で、任意で末尾に「#」と、それに続く2桁の16進数の NetBIOS 名タイプを付けます。</p>
<p>末尾の「#」を省略すると、検索する NetBIOS 名タイプに関係なく、指定した名前に一致するすべての名前に対して指定した IP アドレスが返されます。</p></li></ul>

<p>例を示します。</p>

<pre><code>#
# Sample Samba lmhosts file.
#
192.9.200.1	TESTPC
192.9.200.20	NTSERVER#20
192.9.200.21	SAMBASERVER</code></pre>

<p>IP アドレスから NetBIOS 名への3つの対応を含みます。1番目と3番目は、それぞれ「TESTPC」と「SAMBASERVER」への問い合わせに対し、要求された NetBIOS 名のタイプに関係なく返されます。</p>

<p>2番目は、名前「NTSERVER」の名タイプ「0x20」を問い合わせた場合にだけ返されます。それ以外の名タイプは解決されません。</p>

<p><code>lmhosts</code> ファイルの既定の場所は <a href="https://www.samba.org/samba/docs/current/man-html/smb.conf.5.html">smb.conf(5)</a> ファイルと同じディレクトリです。</p>

### ファイル {#FILES}


<p>lmhosts は設定ディレクトリから読み込まれます。通常は <code>/etc/samba</code> または <code>/usr/local/samba/lib</code> です。</p>
