## getcifsacl {#getcifsacl}


### Common Internet File System（CIFS）のセキュリティ記述子内の ACL を表示するユーザー空間ヘルパー {#Userspace-helper-to-display-an-ACL-in-a-security-descriptor-for-Common-Internet-File-System--CIFS}


<dl><dt>マニュアルのセクション:</dt><dd><p>1</p></dd></dl>

#### 書式 {#SYNOPSIS}


<blockquote><p>getcifsacl [<code>-v</code>|<code>-r</code>] {ファイルシステムオブジェクト}</p></blockquote>

#### 説明 {#DESCRIPTION}


<p>このツールは cifs-utils スイートの一部です。</p>

<p>getcifsacl は Linux CIFS クライアントファイルシステム用のユーザー空間ヘルパープログラムです。ファイルシステムオブジェクトの DACL と SACL を含むセキュリティ記述子を表示するためのものです。</p>

<p>このプログラムはプラグインを使って SID をユーザー名とグループ名に対応付けます。<em>@pluginpath@</em> は、使用する正しいプラグインを指すシンボリックリンクである必要があります。</p>

<p>ACE の SID、タイプ、フラグ、マスクなどのフィールドは / で区切って表示します。タイプ、フラグ、マスクの数値は16進数形式で表示します。</p>

#### オプション {#OPTIONS}


<dl><dt><code>-v</code></dt><dd><p>バージョン番号を表示して終了します。</p></dd><dt><code>-r</code></dt><dd><p>セキュリティ記述子を raw モードで表示します。タイプやフラグなどの値は16進数形式で表示し、SID は名前に変換しません。</p></dd><dt><code>-R</code></dt><dd><p>すべてのファイルとディレクトリの ACL を再帰的に一覧表示します。</p></dd></dl>

#### 注記 {#NOTES}


<p>getcifsacl/setcifsacl ユーティリティへのカーネルの対応は、2.6.37 カーネルで初めて導入されました。</p>
