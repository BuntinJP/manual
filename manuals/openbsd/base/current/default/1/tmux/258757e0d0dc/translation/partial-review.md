# tmux s0251–s0550 翻訳・自己照合

確認者: EMMA FreeBSD/FHS 担当（翻訳者による自己照合。独立レビューではない）

## 範囲

- 対象 300 セグメントすべての候補訳を保存した。全文 tmux 2,823 セグメントの完訳ではない。
- ペイン対象指定・特殊トークン・IDと対象解決、シェルコマンド引数、CLIENTS AND SESSIONS 全体、WINDOWS AND PANES 冒頭からコピーモードの previous-paragraph コマンド行（s0550）まで。
- 原文は `manuals/openbsd/base/current/default/1/tmux/258757e0d0dc/source.html`。全体 IR 内の対象 ID/text と部分 request の一致を確認し、保護トークンを戻した文が保存原文に存在することを確認した。s0410 の em 開閉トークンは HTML 装飾であり、テキスト照合時にタグ表記が加わる点を別途確認した。
- コマンド構文、キー表記、記号のみのセグメントは原形を保持。alias ラベルと説明文は翻訳した。未翻訳英文を埋めて完了扱いにはしていない。

## 意味照合の重点

- ペイン番号省略時のアクティブペイン、対象の曖昧性と完全修飾、IDの存続期間を保持。
- attach/detach の対象、親プロセスへの SIGHUP、読み取り専用で有効なキーの制限、アタッチされていない最近使用セッション優先を保持。
- kill-session の他セッションにリンクされないウィンドウだけを閉じる条件、フィルター、グループ全体、アラート消去を保持。
- new-session の -A/-D/-X、-dサイズ、グループ共有と独立状態、-E/-e条件を保持。
- refresh-client の方向・行列・既定1、クライアント属性であること、制御モード、毎秒最大1回の購読通知、ペインフラグとクリップボードを保持。
- server-access の root/所有者例外、ユーザー優先、実効グループのみ、補助グループ除外、信頼できないユーザーへの注意を保持。
- コピーモードの選択解除あり/なし、終了あり/なし、半ページ/1ページ、前後方向、OSC 133、1文字手前、空白以外の単語扱いを区別した。

## 原文のまま保持した点

- s0376 の continue 説明は保存原文が “return to sending output to the pane” と記述している。宛先を翻訳者が独断で client に訂正せず、「ペインへの出力送信」とした。
- s0433 は原文が “Copy from the cursor position and exit copy mode.” とだけ記述し、行末までとは明記していないため、訳文にも終点を追加していない。
- s0380 は s0375 と方向操作が重複しているが省略していない。

## 検証

- 保存原文と全体IRの実SHA-256を候補のバインド値と照合。
- 全体IRから対象300セグメントだけを取り出し、既存 validateTranslation でID集合・非空訳・保護トークン・インライン書式を検証、成功。
- キュー save/complete、受理、生成、公開は行っていない。統合担当でキュー保存と最終全体レビューが必要。

# tmux s0651–s0950 翻訳・自己照合

確認者: EMMA FreeBSD/FHS 担当（翻訳者による自己照合。独立レビューではない）

## 完了範囲

対象300セグメントをすべて翻訳。レイアウトの説明から break-pane / capture-pane / choose-client / choose-tree / customize-mode / switch-mode / display-panes / find-window / join-pane / kill-pane / kill-window / last-pane / last-window / link-window / list-panes / list-windows / move-pane の位置表途中（backward-loop のトークン、s0950）まで。

原文は保存済み OpenBSD-current tmux の source.html。部分 request の全 ID/text を全体 IR と照合し、各保護トークンを原文に戻した全300セグメントが原文本文中に存在することを確認した。原文/IRハッシュ一致も確認。コマンド構文、キー表記、トークンのみの行は保持し、説明と alias ラベルを翻訳した。

## 意味照合

- レイアウトの左右/上下、反転、均等分割、元より多いペイン数の制限を保持。
- フローティングペインの幅1/2・高さ1/4、列/行単位、位置と百分率、復元する未指定値、ズーム/非表示の禁止条件を保持。
- capture-pane の標準出力/バッファー分岐、代替画面と履歴、存在しない場合のエラー、末尾空白と折り返し連結、未完エスケープ、行番号/時刻/フラグ、ハイパーリンク、負の履歴番号と既定表示範囲を保持。非保護表記の8進数エスケープ `\xxx` も原文と一致。
- 選択中とタグ付きの操作、全タグ解除、方向、HUP、一時停止、確定と選択移動、確認無効化を区別。
- フィルター評価0/それ以外、空になる場合の無視、各行1回評価、プレビューなし/2回指定の大きい表示、モード終了時のペイン終了条件を保持。
- %% の最初の出現と %1 の全出現の置換、switch-mode の表示テキストでのあいまい一致と元の行の置換を保持。
- display-panes のミリ秒、0の無期限、キー例外、ズームの既定と解除、ペインIDへの置換を保持。
- find-window は表示内容だけで履歴は対象外。kill操作の例外とフィルター、リンク時の既存窓、入力有効/無効、並べ替えの時刻/面積、浮動ペインの重なり順を保持。
