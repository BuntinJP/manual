# 原文の識別と表記について

取得元は `manifest.json` の URL で指定した HTML です。選択された manpath は `FreeBSD 15.1-RELEASE and Ports.quarterly` ですが、本文のフッターは `FreeBSD ports 15.quarterly`、文書日付は `February 14, 2026` と表示されています。そのためディレクトリの product / version は `ports / 15.quarterly`、variant は `15.1-release-and-ports` としています。FreeBSD 本体の別リビジョンの roff に置き換えてはいません。

`source.html` は取得した応答本文をバイト単位で保存したものです。以下の表記は、その HTML 本文で確認できます。

- `-s` の説明では `foo` の引用符の外側にピリオドがあり、ディレクトリ名と文の句読点の境界が不明瞭です。日本語では、後続の ASCII に関する説明に従い、比較対象を `foo.` として明示しています。
- `-printf` の説明では、エスケープを指す箇所が `and` と `%` という表記になっています。訳文ではこの原文の表記を注記し、直後のエスケープ一覧を省略せず訳しています。
- PRINTF FORMATS の一覧には `h` が二度あり、一方は相対パス、もう一方は人が読める形式の uid と記されています。訳文でも二つの `h` を残しています。実装を検証して訂正したものではありません。
- 同一覧の `c` / `C` は原文で `Creation time` と記されています。訳文も「作成時刻」としています。`-ctime` などで説明される状態変更時刻との用語の不一致は原文にあります。
- ENVIRONMENT の参照は `envi-` と `ron(7)` に行分割され、HTML リンクの宛先も `query=ron` になっています。文章としては `environ(7)` を指すと読めますが、取得した原文のリンクはそのまま保存しています。

これらは翻訳元の表記を追跡するための記録であり、実コマンドの実装を検証した記録ではありません。
