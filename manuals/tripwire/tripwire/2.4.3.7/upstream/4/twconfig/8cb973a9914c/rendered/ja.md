### 名前 {#NAME}


<p>twconfig - <em>Tripwire</em> 設定ファイルのリファレンス</p>

### 説明 {#DESCRIPTION}


<p>設定ファイルには、<em>Tripwire</em> のデータファイルの場所やメール通知に使う設定など、システム固有の情報を保存します。設定値はインストール中に生成されますが、システム管理者はいつでも変更できます。設定ファイルはサイト鍵で署名されており、編集にはサイトのパスフレーズが必要です。</p>

<p>インストール中に、署名付きの <em>Tripwire</em> 設定ファイル <em>tw.cfg</em> が <em>/etc/tripwire</em> ディレクトリに作成され、同じディレクトリにプレーンテキストのコピー <em>twcfg.txt</em> も作成されます。</p>

<p>設定ファイルは <strong>twadmin ‐‐create‐cfgfile</strong> コマンドで変更します。このコマンドでは、既存のプレーンテキストファイルを現在の設定ファイルとして指定できます。現在のサイト鍵とパスフレーズを使って、新しい設定ファイルに暗号学的な署名を付けて保存します。</p>

#### 設定ファイルの構成要素 {#Components_of_the_Configuration_File}


<p><em>Tripwire</em> の設定ファイルはキーワードと値の組み合わせの一覧として構成され、コメントや変数定義も記述できます。第1列が &quot;#&quot; の行はコメントとして扱います。</p>

<p>変数定義の一般的な構文は次のとおりです。<br> <br></p>

<pre><code>keyword  =  value</code></pre>

<p><br> 例: <br></p>

<pre><code>ROOT = /usr/tripwire
EDITOR = /usr/local/bin/jove</code></pre>

<p>右辺では、次の構文で変数を置換できます。<br> <br></p>

<pre><code>$(  varname  )</code></pre>

<p><br> 例: <br></p>

<pre><code>DBFILE = $(ROOT)/db/$(HOSTNAME).twd</code></pre>

<p>変数名は大文字と小文字を区別し、英数字、アンダースコア、文字 &quot;+‐@:&quot;、ピリオドを使用できます。設定ファイルでは2つの変数があらかじめ定義されており、変更できません。HOSTNAME は <em>Tripwire</em> を実行しているホストの非修飾ホスト名、DATE は日付と時刻を表す文字列です。</p>

#### 必須の変数 {#Required_Variables}


<p><em>Tripwire</em> の動作には、次の変数を設定する必要があります。以下の値はインストール中に割り当てられます。</p>

<pre><code>
POLFILE         Default = /etc/tripwire/tw.pol
DBFILE          Default = /var/lib/tripwire/$(HOSTNAME).twd
REPORTFILE      Default = /var/lib/tripwire/report/$(HOSTNAME)-$(DATE).twr
SITEKEYFILE     Default = /etc/tripwire/site.key
LOCALKEYFILE    Default = /etc/tripwire/$(HOSTNAME)-local.key</code></pre>

<dl><dt>MAILMETHOD</dt><dd><p><em>Tripwire</em> がメール通知に使うプロトコルを指定します。このフィールドで許される値は SMTP または SENDMAIL だけです。それ以外の値ではエラーメッセージを出します。<br> 初期値: <em>SENDMAIL</em></p></dd><dt>SMTPHOST</dt><dd><p>メール通知に使う SMTP サーバーのドメイン名または IP アドレスを指定します。MAILMETHOD が SMTP に設定されていなければ無視します。<br> 初期値: <em>mail.domain.com</em></p></dd><dt>SMTPPORT</dt><dd><p>SMTP で使うポート番号を指定します。MAILMETHOD が SMTP に設定されていなければ無視します。<br> 初期値: <em>25</em></p></dd><dt>MAILPROGRAM</dt><dd><p>MAILMETHOD が SENDMAIL に設定されている場合に、ルール違反をメールで報告するプログラムを指定します。このプログラムは RFC822 形式のメールヘッダーを受け取る必要があり、受信者はそのヘッダーの &quot;To:&quot; フィールドに記載されます。一部のメールプログラムは、ピリオド1文字だけの行を入力の終わりと解釈し、それ以降のテキストをすべて無視します。<em>Tripwire</em> のレポートにそのような行が含まれる可能性がわずかにあるため、指定するメールプログラムはピリオド1文字だけの行を無視できなければなりません（sendmail の <strong>-oi</strong> オプションでこの動作になります）。<br> 初期値: <em>/usr/lib/sendmail <code>-oi</code> <code>-t</code></em></p></dd><dt>EMAILREPORTLEVEL</dt><dd><p><strong>tripwire</strong> <strong>‐‐check</strong> モードのメールレポートの既定レベルを指定します。有効な値は0から4です。コマンドラインの（<strong>‐t</strong> または <strong>‐‐email‐report‐level</strong>）オプションで、このレベルを上書きできます。設定ファイルにこの変数がない場合、既定のレポートレベルは3です。<br> 初期値: <em>3</em></p></dd><dt>MAILNOVIOLATIONS</dt><dd><p>このオプションは、整合性チェックでルール違反が見つからなかった場合に、<em>Tripwire</em> がメール通知を送る方法を制御します。MAILNOVIOLATIONS を <em>false</em> に設定し、違反が見つからなかった場合、<em>Tripwire</em> はレポートを送りません。それ以外の値、または設定ファイルから変数を削除した場合、<em>Tripwire</em> は違反が見つからなかったことを示すメールを送ります。</p></dd><dt></dt><dd><p>違反がないというレポートをメールで送ると、管理者は、無人実行の整合性チェックが実行できていないのか、それとも実行しているが違反がないのかを区別できます。ただし、違反なしのレポートを送ると、処理すべきデータ量が増えます。<br> 初期値: <em>true</em></p></dd><dt>MAILFROMADDRESS</dt><dd><p>メールレポートの &quot;From:&quot; フィールドの値を指定します。<br> 初期値: <em>tripwire@hostname</em>。ここで &#39;hostname&#39; はローカルマシン名です。</p></dd></dl>
