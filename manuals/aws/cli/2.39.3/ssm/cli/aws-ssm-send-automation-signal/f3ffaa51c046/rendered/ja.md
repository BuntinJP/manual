## send-automation-signal¶ {#send-automation-signal}


### 説明¶ {#Description}


<p>Automation 実行にシグナルを送信し、実行の現在の動作または状態を変更します。</p>

<p>関連項目: <a href="https://docs.aws.amazon.com/goto/WebAPI/ssm-2014-11-06/SendAutomationSignal">AWS API Documentation</a></p>

### オプション¶ {#Options}


<p><code>--automation-execution-id</code> (string) [必須]</p>

<blockquote><p>シグナルの送信先となる既存の Automation 実行の一意の識別子。</p>
<p>制約:</p>
<ul><li><p>最小: <code>36</code></p></li><li><p>最大: <code>36</code></p></li></ul></blockquote>

<p><code>--signal-type</code> (string) [必須]</p>

<blockquote><p>Automation 実行に送信するシグナルの種類。</p>
<p>指定可能な値:</p>
<ul><li><p><code>Approve</code></p></li><li><p><code>Reject</code></p></li><li><p><code>StartStep</code></p></li><li><p><code>StopStep</code></p></li><li><p><code>Resume</code></p></li><li><p><code>Revoke</code></p></li></ul></blockquote>

<p><code>--payload</code> (map)</p>

<blockquote><p>シグナルとともに送信するデータ。データのスキーマは、リクエストで使用するシグナルの種類によって異なります。</p>
<p><code>Approve</code> および <code>Reject</code> シグナルタイプの場合、ペイロードはそのシグナルタイプとともに送信できる任意のコメントです。例:</p>
<blockquote><p><code>Comment=&quot;Looks good&quot;</code></p></blockquote>
<p><code>StartStep</code> および <code>Resume</code> シグナルタイプの場合、開始または再開する Automation ステップの名前をペイロードとして送信する必要があります。例:</p>
<blockquote><p><code>StepName=&quot;step1&quot;</code></p></blockquote>
<p><code>StopStep</code> シグナルタイプの場合、ステップ実行 ID をペイロードとして送信する必要があります。例:</p>
<blockquote><p><code>StepExecutionId=&quot;97fff367-fc5a-4299-aed8-0123456789ab&quot;</code></p></blockquote>
<p>制約:</p>
<ul><li><p>最小: <code>1</code></p></li><li><p>最大: <code>200</code></p></li></ul>
<p>key -&gt; (string)</p>
<blockquote><p>制約:</p>
<ul><li><p>最小: <code>1</code></p></li><li><p>最大: <code>50</code></p></li></ul></blockquote>
<p>value -&gt; (list)</p>
<blockquote><p>制約:</p>
<ul><li><p>最小: <code>0</code></p></li><li><p>最大: <code>50</code></p></li></ul>
<p>(string)</p>
<blockquote><p>制約:</p>
<ul><li><p>最小: <code>1</code></p></li><li><p>最大: <code>512</code></p></li></ul></blockquote></blockquote></blockquote>

<p>短縮構文:</p>

<pre><code>KeyName1=string,string,KeyName2=string,string</code></pre>

<p>JSON 構文:</p>

<pre><code>{&quot;string&quot;: [&quot;string&quot;, ...]
  ...}</code></pre>

<p><code>--cli-input-json</code> | <code>--cli-input-yaml</code> (string) 指定された JSON 文字列から引数を読み取ります。JSON 文字列は <code>--generate-cli-skeleton</code> が提供する形式に従います。コマンドラインでほかの引数を指定した場合、その値が JSON で指定した値を上書きします。文字列はそのまま解釈されるため、JSON で指定する値を使って任意のバイナリ値を渡すことはできません。<code>--cli-input-yaml</code> と同時には指定できません。</p>

<p><code>--generate-cli-skeleton</code> (string) API リクエストを送信せずに、JSON スケルトンを標準出力に表示します。値を指定しない場合、または値に <code>input</code> を指定した場合は、<code>--cli-input-json</code> の引数に使用できる入力 JSON のサンプルを表示します。同様に、<code>yaml-input</code> を指定した場合は、<code>--cli-input-yaml</code> で使用できる入力 YAML のサンプルを表示します。値に <code>output</code> を指定した場合は、コマンドの入力を検証し、そのコマンドの出力 JSON のサンプルを返します。生成される JSON スケルトンは AWS CLI のバージョン間で一定ではなく、生成される JSON スケルトンの後方互換性は保証されません。</p>
