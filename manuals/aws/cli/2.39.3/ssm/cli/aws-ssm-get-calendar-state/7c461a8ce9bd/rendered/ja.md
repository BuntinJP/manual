## get-calendar-state¶ {#get-calendar-state}


### 説明¶ {#Description}


<p>現在時刻または指定した時刻における Amazon Web Services Systems Manager 変更カレンダーの状態を取得します。時刻を指定すると、<code>GetCalendarState</code> はその時刻におけるカレンダーの状態と、変更カレンダーの状態が次に遷移する時刻を返します。時刻を指定しない場合、<code>GetCalendarState</code> は現在時刻を使用します。Change Calendar のエントリーが取り得る状態は、<code>OPEN</code> または <code>CLOSED</code> の 2 つです。</p>

<p>リクエストで複数のカレンダーを指定した場合、リクエスト内のすべてのカレンダーが開いているときに限り、コマンドは <code>OPEN</code> の状態を返します。リクエスト内のカレンダーが 1 つでも閉じている場合、返される状態は <code>CLOSED</code> です。</p>

<p>Amazon Web Services Systems Manager のツールである Change Calendar の詳細については、<em>Amazon Web Services Systems Manager ユーザーガイド</em>の <a href="https://docs.aws.amazon.com/systems-manager/latest/userguide/systems-manager-change-calendar.html">Amazon Web Services Systems Manager Change Calendar</a> を参照してください。</p>

<p>関連項目: <a href="https://docs.aws.amazon.com/goto/WebAPI/ssm-2014-11-06/GetCalendarState">AWS API Documentation</a></p>

### 出力¶ {#Output}


<p>State -&gt; (string)</p>

<blockquote><p>カレンダーの状態。<code>OPEN</code> のカレンダーはアクションの実行が許可されることを示し、<code>CLOSED</code> のカレンダーはアクションの実行が許可されないことを示します。</p>
<p>指定可能な値:</p>
<ul><li><p><code>OPEN</code></p></li><li><p><code>CLOSED</code></p></li></ul></blockquote>

<p>AtTime -&gt; (string)</p>

<blockquote><p>コマンドで指定した時刻を表す <a href="https://en.wikipedia.org/wiki/ISO_8601">ISO 8601</a> 文字列。時刻を指定しない場合、<code>GetCalendarState</code> は現在時刻を使用します。</p></blockquote>

<p>NextTransitionTime -&gt; (string)</p>

<blockquote><p>カレンダーの状態が変わる時刻を表す <a href="https://en.wikipedia.org/wiki/ISO_8601">ISO 8601</a> 文字列。現在のカレンダーの状態が <code>OPEN</code> の場合、<code>NextTransitionTime</code> はカレンダーの状態が <code>CLOSED</code> に変わる時刻を示します。逆の場合も同様です。</p></blockquote>
