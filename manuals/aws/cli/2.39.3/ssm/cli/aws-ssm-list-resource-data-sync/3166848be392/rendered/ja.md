## list-resource-data-sync¶ {#list-resource-data-sync}


### 説明¶ {#Description}


<p>リソースデータ同期の設定を一覧表示します。同期が最後に開始を試みた時刻、最後の同期状態、最後に正常完了した時刻の情報を含みます。</p>

<p>同期設定の数が多く、<code>ListResourceDataSync</code> の 1 回の呼び出しでは返しきれない場合があります。<code>MaxResults</code> パラメーターを使用すると、返される同期設定の数を制限できます。さらに一覧表示する同期設定があるかを判断するには、出力の <code>NextToken</code> の値を確認します。さらに設定がある場合は、呼び出しで返された <code>NextToken</code> を後続の呼び出しのパラメーターに指定して要求できます。</p>

<p>関連項目: <a href="https://docs.aws.amazon.com/goto/WebAPI/ssm-2014-11-06/ListResourceDataSync">AWS API Documentation</a></p>

<p><code>list-resource-data-sync</code> はページネーションを行う操作です。結果のデータセット全体を取得するために、複数回の API 呼び出しが行われる場合があります。<code>--no-paginate</code> 引数を指定すると、ページネーションを無効にできます。ページネーションされた応答に対して <code>--output text</code> と <code>--query</code> 引数を使用する場合、<code>--query</code> 引数は次のクエリ式の結果からデータを抽出する必要があります: <code>ResourceDataSyncItems</code></p>
