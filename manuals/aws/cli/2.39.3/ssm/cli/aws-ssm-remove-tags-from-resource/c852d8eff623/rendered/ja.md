### オプション¶ {#Options}


<p><code>--resource-type</code> (string) [必須]</p>

<blockquote><p>タグを削除するリソースの種類。</p>
<h4 id="Note">注記</h4>
<p>この API 操作の <code>ManagedInstance</code> タイプは、オンプレミスのマネージドノード専用です。マネージドノードの名前は、次の形式で指定します: <code>mi-*ID_number* `` . For example, ``mi-1a2b3c4d5e6f</code>。</p>
<p>指定可能な値:</p>
<ul><li><p><code>Document</code></p></li><li><p><code>ManagedInstance</code></p></li><li><p><code>MaintenanceWindow</code></p></li><li><p><code>Parameter</code></p></li><li><p><code>PatchBaseline</code></p></li><li><p><code>OpsItem</code></p></li><li><p><code>OpsMetadata</code></p></li><li><p><code>Automation</code></p></li><li><p><code>Association</code></p></li><li><p><code>CloudConnector</code></p></li></ul></blockquote>

<p><code>--resource-id</code> (string) [必須]</p>

<blockquote><p>タグを削除するリソースの ID。例:</p>
<p>ManagedInstance: mi-012345abcde</p>
<p>MaintenanceWindow: mw-012345abcde</p>
<blockquote><p><code>Automation</code> : <code>example-c160-4567-8519-012345abcde</code></p></blockquote>
<p>PatchBaseline: pb-012345abcde</p>
<p>OpsMetadata オブジェクト: タグ付けに使用する <code>ResourceID</code> は、オブジェクトの Amazon リソースネーム (ARN) から作成されます。具体的には、<code>ResourceID</code> は ARN 内の <code>opsmetadata</code> という語の後に続く文字列から作成されます。たとえば、ARN が <code>arn:aws:ssm:us-east-2:1234567890:opsmetadata/aws/ssm/MyGroup/appmanager</code> の OpsMetadata オブジェクトでは、<code>ResourceID</code> は <code>aws/ssm/MyGroup/appmanager</code> または <code>/aws/ssm/MyGroup/appmanager</code> です。</p>
<p>Document と Parameter の値には、リソースの名前を使用します。</p>
<h4 id="Note-2">注記</h4>
<p>この API 操作の <code>ManagedInstance</code> タイプは、オンプレミスのマネージドノード専用です。マネージドノードの名前は mi-ID_number の形式で指定します。例: mi-1a2b3c4d5e6f。</p></blockquote>

<p><code>--tag-keys</code> (list) [必須]</p>

<blockquote><p>指定したリソースから削除するタグキー。</p>
<p>(string)</p>
<blockquote><p>制約:</p>
<ul><li><p>最小: <code>1</code></p></li><li><p>最大: <code>128</code></p></li><li><p>パターン: <code>^([\p{L}\p{Z}\p{N}_.:/=+\-@]*)$</code></p></li></ul></blockquote></blockquote>

<p>構文:</p>

<pre><code>&quot;string&quot; &quot;string&quot; ...</code></pre>
