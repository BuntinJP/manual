## describe-maintenance-window-tasks¶ {#describe-maintenance-window-tasks}


### 説明¶ {#Description}


<p>メンテナンスウィンドウ内のタスクを一覧表示します。</p>

#### 注記 {#Note}


<p>ターゲットを指定していないメンテナンスウィンドウタスクでは、<code>--max-errors</code> と <code>--max-concurrency</code> の値を指定できません。代わりに、システムはプレースホルダー値 <code>1</code> を挿入します。この値は、このコマンドのレスポンスに表示されることがあります。これらの値はタスクの実行に影響しないため、無視できます。</p>

<p>関連項目: <a href="https://docs.aws.amazon.com/goto/WebAPI/ssm-2014-11-06/DescribeMaintenanceWindowTasks">AWS API Documentation</a></p>

<p><code>describe-maintenance-window-tasks</code> はページネーションを行う操作です。結果のデータセット全体を取得するために、複数回の API 呼び出しが行われる場合があります。<code>--no-paginate</code> 引数を指定すると、ページネーションを無効にできます。ページネーションされた応答に対して <code>--output text</code> と <code>--query</code> 引数を使用する場合、<code>--query</code> 引数は次のクエリ式の結果からデータを抽出する必要があります: <code>Tasks</code></p>
