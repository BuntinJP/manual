## create-activation¶ {#create-activation}


### 説明¶ {#Description}


<p>オンプレミスサーバー、エッジデバイス、または仮想マシン (VM) を Amazon Web Services Systems Manager に登録するためのアクティベーションコードとアクティベーション ID を生成します。これらのマシンを Systems Manager に登録すると、Systems Manager ツールで管理できるようになります。ハイブリッド環境内のマシンに SSM Agent をインストールする際に、アクティベーションコードと ID を使用します。Systems Manager でオンプレミスマシンを管理するための要件については、<em>Amazon Web Services Systems Manager ユーザーガイド</em>の <a href="https://docs.aws.amazon.com/systems-manager/latest/userguide/systems-manager-hybrid-multicloud.html">Using Amazon Web Services Systems Manager in hybrid and multicloud environments</a> を参照してください。</p>

#### 注記 {#Note}


<p>Systems Manager 用に設定された Amazon Elastic Compute Cloud (Amazon EC2) インスタンス、エッジデバイス、オンプレミスサーバー、VM は、すべて<em>マネージドノード</em>と呼ばれます。</p>

<p>関連項目: <a href="https://docs.aws.amazon.com/goto/WebAPI/ssm-2014-11-06/CreateActivation">AWS API Documentation</a></p>
