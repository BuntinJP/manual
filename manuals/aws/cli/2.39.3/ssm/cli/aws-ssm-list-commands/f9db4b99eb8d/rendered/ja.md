## list-commands¶ {#list-commands}


### 説明¶ {#Description}


<p>Amazon Web Services アカウントのユーザーがリクエストしたコマンドを一覧表示します。</p>

<p>関連項目: <a href="https://docs.aws.amazon.com/goto/WebAPI/ssm-2014-11-06/ListCommands">AWS API Documentation</a></p>

<p><code>list-commands</code> はページネーションを行う操作です。結果のデータセット全体を取得するために、複数回の API 呼び出しが行われる場合があります。<code>--no-paginate</code> 引数を指定すると、ページネーションを無効にできます。ページネーションされた応答に対して <code>--output text</code> と <code>--query</code> 引数を使用する場合、<code>--query</code> 引数は次のクエリ式の結果からデータを抽出する必要があります: <code>Commands</code></p>

### オプション¶ {#Options}


<p><code>--command-id</code> (string)</p>

<blockquote><p>(オプション) 指定した場合、指定したコマンドのみを一覧表示します。</p>
<p>制約:</p>
<ul><li><p>最小: <code>36</code></p></li><li><p>最大: <code>36</code></p></li></ul></blockquote>

<p><code>--instance-id</code> (string)</p>

<blockquote><p>(オプション) このマネージドノード ID に対して発行されたコマンドを一覧表示します。</p>
<h4 id="Note">注記</h4>
<p><code>Status</code> = <code>Pending</code> を指定したコマンドでは、マネージドノード ID を指定できません。これは、コマンドがまだマネージドノードに到達していないためです。</p>
<p>制約:</p>
<ul><li><p>パターン: <code>(^i-(\w{8}|\w{17})$)|(^mi-\w{17}$)</code></p></li></ul></blockquote>

<p><code>--filters</code> (list)</p>

<blockquote><p>(オプション) 1 つ以上のフィルター。フィルターを使用して、より限定的な結果の一覧を返します。</p>
<p>制約:</p>
<ul><li><p>最小: <code>1</code></p></li><li><p>最大: <code>5</code></p></li></ul>
<p>(structure)</p>
<blockquote><p>コマンドフィルターを記述します。</p>
<h4 id="Note-2">注記</h4>
<p>コマンドのステータスが <code>Pending</code> の場合、コマンドがまだノードで実行されていないため、マネージドノード ID は指定できません。</p>
<p>key -&gt; (string) [必須]</p>
<blockquote><p>フィルターの名前。</p>
<h4 id="Note-3">注記</h4>
<p><code>ExecutionStage</code> フィルターは <code>ListCommandInvocations</code> オペレーションでは使用できず、<code>ListCommands</code> でのみ使用できます。</p>
<p>指定可能な値:</p>
<ul><li><p><code>InvokedAfter</code></p></li><li><p><code>InvokedBefore</code></p></li><li><p><code>Status</code></p></li><li><p><code>ExecutionStage</code></p></li><li><p><code>DocumentName</code></p></li></ul></blockquote>
<p>value -&gt; (string) [必須]</p>
<blockquote><p>フィルターの値。各フィルターキーに有効な値は次のとおりです。</p>
<ul><li><p><strong>InvokedAfter</strong>: 結果を絞り込むためのタイムスタンプを指定します。例えば、2021 年 7 月 7 日以降に行われたコマンド実行の一覧を表示するには、<code>2024-07-07T00:00:00Z</code> を指定します。</p></li><li><p><strong>InvokedBefore</strong>: 結果を絞り込むためのタイムスタンプを指定します。例えば、2021 年 7 月 7 日より前のコマンド実行の一覧を表示するには、<code>2024-07-07T00:00:00Z</code> を指定します。</p></li><li><p><strong>Status</strong>: 有効なコマンドステータスを指定すると、そのステータスを持つすべてのコマンド実行の一覧が表示されます。ステータスの選択肢は、呼び出す API によって異なります。<code>ListCommands</code> に指定できるステータス値は次のとおりです。</p>
<ul><li><p><code>Pending</code></p></li><li><p><code>InProgress</code></p></li><li><p><code>Success</code></p></li><li><p><code>Cancelled</code></p></li><li><p><code>Failed</code></p></li><li><p><code>TimedOut</code> (配信タイムアウトと実行タイムアウトの両方を含みます)</p></li><li><p><code>AccessDenied</code></p></li><li><p><code>DeliveryTimedOut</code></p></li><li><p><code>ExecutionTimedOut</code></p></li><li><p><code>Incomplete</code></p></li><li><p><code>NoInstancesInTag</code></p></li><li><p><code>LimitExceeded</code></p></li></ul></li></ul>
<p><code>ListCommandInvocations</code> に指定できるステータス値は次のとおりです。</p>
<blockquote><ul><li><p><code>Pending</code></p></li><li><p><code>InProgress</code></p></li><li><p><code>Delayed</code></p></li><li><p><code>Success</code></p></li><li><p><code>Cancelled</code></p></li><li><p><code>Failed</code></p></li><li><p><code>TimedOut</code> (配信タイムアウトと実行タイムアウトの両方を含みます)</p></li><li><p><code>AccessDenied</code></p></li><li><p><code>DeliveryTimedOut</code></p></li><li><p><code>ExecutionTimedOut</code></p></li><li><p><code>Undeliverable</code></p></li><li><p><code>InvalidPlatform</code></p></li><li><p><code>Terminated</code></p></li></ul></blockquote>
<ul><li><p><strong>DocumentName</strong>: コマンド実行結果を表示する Amazon Web Services Systems Manager ドキュメント (SSM ドキュメント) の名前を指定します。例えば、この SSM ドキュメントを使用してマネージドノードでセキュリティパッチ適用操作を行ったコマンド実行を表示するには、<code>AWS-RunPatchBaseline</code> を指定します。</p></li><li><p><strong>ExecutionStage</strong>: 次のいずれかの値を指定します (<code>ListCommands</code> オペレーションのみ)。</p>
<ul><li><p><code>Executing</code>: 現在も実行中のコマンド実行の一覧を返します。</p></li><li><p><code>Complete</code>: すでに完了しているコマンド実行の一覧を返します。</p></li></ul></li></ul>
<p>制約:</p>
<ul><li><p>最小: <code>1</code></p></li><li><p>最大: <code>128</code></p></li></ul></blockquote></blockquote></blockquote>

<p>短縮構文:</p>

<pre><code>key=string,value=string ...</code></pre>

<p>JSON 構文:</p>

<pre><code>[
  {
    &quot;key&quot;: &quot;InvokedAfter&quot;|&quot;InvokedBefore&quot;|&quot;Status&quot;|&quot;ExecutionStage&quot;|&quot;DocumentName&quot;,
    &quot;value&quot;: &quot;string&quot;
  }
  ...
]</code></pre>

<p><code>--starting-token</code> (string)</p>

<blockquote><p>ページネーションの開始位置を指定するトークン。これは、以前に途中で打ち切られた応答に含まれる <code>NextToken</code> です。</p>
<p>使用例については、<em>AWS Command Line Interface ユーザーガイド</em>の <a href="https://docs.aws.amazon.com/cli/latest/userguide/pagination.html">Pagination</a> を参照してください。</p></blockquote>

<p><code>--page-size</code> (integer)</p>

<blockquote><p>AWS サービスの呼び出しで取得する各ページのサイズ。これは、コマンドの出力で返される項目数には影響しません。ページサイズを小さくすると、AWS サービスへの呼び出し回数が増え、各呼び出しで取得する項目数が少なくなります。これにより、AWS サービスの呼び出しのタイムアウトを防げる場合があります。</p>
<p>使用例については、<em>AWS Command Line Interface ユーザーガイド</em>の <a href="https://docs.aws.amazon.com/cli/latest/userguide/pagination.html">Pagination</a> を参照してください。</p>
<p>制約:</p>
<ul><li><p>最小: <code>1</code></p></li><li><p>最大: <code>50</code></p></li></ul></blockquote>

<p><code>--max-items</code> (integer)</p>

<blockquote><p>コマンドの出力で返す項目の総数。取得可能な項目の総数が指定値を超える場合、コマンド出力に <code>NextToken</code> が含まれます。ページネーションを再開するには、後続のコマンドの <code>starting-token</code> 引数に <code>NextToken</code> の値を指定します。<code>NextToken</code> 応答要素を AWS CLI の外部で直接使用しては<strong>いけません</strong>。</p>
<p>使用例については、<em>AWS Command Line Interface ユーザーガイド</em>の <a href="https://docs.aws.amazon.com/cli/latest/userguide/pagination.html">Pagination</a> を参照してください。</p></blockquote>

<p><code>--cli-input-json</code> | <code>--cli-input-yaml</code> (string) 指定された JSON 文字列から引数を読み取ります。JSON 文字列は <code>--generate-cli-skeleton</code> が提供する形式に従います。コマンドラインでほかの引数を指定した場合、その値が JSON で指定した値を上書きします。文字列はそのまま解釈されるため、JSON で指定する値を使って任意のバイナリ値を渡すことはできません。<code>--cli-input-yaml</code> と同時には指定できません。</p>

<p><code>--generate-cli-skeleton</code> (string) API リクエストを送信せずに、JSON スケルトンを標準出力に表示します。値を指定しない場合、または値に <code>input</code> を指定した場合は、<code>--cli-input-json</code> の引数に使用できる入力 JSON のサンプルを表示します。同様に、<code>yaml-input</code> を指定した場合は、<code>--cli-input-yaml</code> で使用できる入力 YAML のサンプルを表示します。値に <code>output</code> を指定した場合は、コマンドの入力を検証し、そのコマンドの出力 JSON のサンプルを返します。生成される JSON スケルトンは AWS CLI のバージョン間で一定ではなく、生成される JSON スケルトンの後方互換性は保証されません。</p>

<p>メンテナンスウィンドウの Run Command タイプのタスクには、1 つ以上の対象を指定する必要があります。ほかのメンテナンスウィンドウのタスクタイプ (Automation、Lambda、Step Functions) では、タスクによって対象の指定は任意です。対象を指定しないタスクの実行については、<em>Amazon Web Services Systems Manager ユーザーガイド</em>の <a href="https://docs.aws.amazon.com/systems-manager/latest/userguide/maintenance-windows-targetless-tasks.html">Registering maintenance window tasks without targets</a> を参照してください。</p>
<p>サポートされる形式は次のとおりです。</p>
<blockquote><p><strong>すべての Systems Manager ツールの場合:</strong></p></blockquote>
<ul><li><p><code>Key=tag-key,Values=tag-value-1,tag-value-2</code></p></li></ul>
<blockquote><p><strong>Automation と Change Manager の場合:</strong></p></blockquote>
<ul><li><p><code>Key=tag:tag-key,Values=tag-value</code></p></li><li><p><code>Key=ResourceGroup,Values=resource-group-name</code></p></li><li><p><code>Key=ParameterValues,Values=value-1,value-2,value-3</code></p></li><li><p>Amazon Web Services リージョン内のすべてのインスタンスを対象とするには:</p>
<ul><li><p><code>Key=AWS::EC2::Instance,Values=*</code></p></li><li><p><code>Key=InstanceIds,Values=*</code></p></li></ul></li></ul>
<blockquote><p><strong>Run Command と Maintenance Windows の場合:</strong></p></blockquote>
<ul><li><p><code>Key=InstanceIds,Values=instance-id-1,instance-id-2,instance-id-3</code></p></li><li><p><code>Key=tag:tag-key,Values=tag-value-1,tag-value-2</code></p></li><li><p><code>Key=resource-groups:Name,Values=resource-group-name</code></p></li><li><p>また、Maintenance Windows はリソースタイプによる対象指定をサポートします。</p>
<ul><li><p><code>Key=resource-groups:ResourceTypeFilters,Values=resource-type-1,resource-type-2</code></p></li></ul></li></ul>
<blockquote><p><strong>State Manager の場合:</strong></p></blockquote>
<ul><li><p><code>Key=InstanceIds,Values=instance-id-1,instance-id-2,instance-id-3</code></p></li><li><p><code>Key=tag:tag-key,Values=tag-value-1,tag-value-2</code></p></li><li><p>Amazon Web Services リージョン内のすべてのインスタンスを対象とするには:</p>
<ul><li><p><code>Key=InstanceIds,Values=*</code></p></li></ul></li></ul>
<p><code>Key,Value</code> パラメーターを使ってマネージドノードを対象とするコマンドの送信方法については、<em>Amazon Web Services Systems Manager ユーザーガイド</em>の <a href="https://docs.aws.amazon.com/systems-manager/latest/userguide/send-commands-multiple.html#send-commands-targeting">Targeting multiple managed nodes</a> を参照してください。</p>

<p>制約:</p>

<p>(string)</p></blockquote></blockquote></blockquote>

<p>StatusDetails -&gt; (string)</p>

<ul><li><p>Pending: コマンドはどのマネージドノードにも送信されていません。</p></li><li><p>In Progress: コマンドは少なくとも 1 つのマネージドノードに送信されていますが、すべてのマネージドノードで最終状態に達しているわけではありません。</p></li><li><p>Success: すべての呼び出しでコマンドが正常に実行されました。これは終端状態です。</p></li><li><p>Delivery Timed Out: MaxErrors の値以上の数のコマンド呼び出しが Delivery Timed Out のステータスを示しています。これは終端状態です。</p></li><li><p>Execution Timed Out: MaxErrors の値以上の数のコマンド呼び出しが Execution Timed Out のステータスを示しています。これは終端状態です。</p></li><li><p>Failed: MaxErrors の値以上の数のコマンド呼び出しが Failed のステータスを示しています。これは終端状態です。</p></li><li><p>Incomplete: すべてのマネージドノードでコマンドが試行され、1 つ以上の呼び出しの値が Success ではありませんが、ステータスが Failed になるほど多くの呼び出しが失敗したわけではありません。これは終端状態です。</p></li><li><p>Cancelled: コマンドは完了する前に終了させられました。終端状態です。</p></li><li><p>Rate Exceeded: コマンドの対象となるマネージドノードの数が、保留中の呼び出しに対するアカウントの制限を超えました。システムは、どのマネージドノードでも実行する前にコマンドをキャンセルしました。これは終端状態です。</p></li><li><p>Delayed: システムはマネージドノードへのコマンド送信を試みましたが、成功しませんでした。システムは再試行します。</p></li></ul>

<blockquote><p>Amazon Simple Notification Service (Amazon SNS) トピックの Amazon リソースネーム (ARN)。Run Command は、このトピックにコマンドステータス変更の通知をプッシュします。</p></blockquote>
<p>NotificationEvents -&gt; (list)</p>
<blockquote><p>通知を受け取ることができる各種イベント。これらのイベントの詳細については、<em>Amazon Web Services Systems Manager ユーザーガイド</em>の <a href="https://docs.aws.amazon.com/systems-manager/latest/userguide/monitoring-sns-notifications.html">Monitoring Systems Manager status changes using Amazon SNS notifications</a> を参照してください。</p>
<p>(string)</p>
<blockquote><p>指定可能な値:</p>
<ul><li><p><code>All</code></p></li><li><p><code>InProgress</code></p></li><li><p><code>Success</code></p></li><li><p><code>TimedOut</code></p></li><li><p><code>Cancelled</code></p></li><li><p><code>Failed</code></p></li></ul></blockquote></blockquote>
<p>NotificationType -&gt; (string)</p>
<blockquote><p>通知の種類。</p>
<ul><li><p><code>Command</code>: コマンドのステータスが変わったときに通知を受け取ります。</p></li><li><p><code>Invocation</code>: 複数のマネージドノードに送信されたコマンドについて、コマンドのステータスが変わったときにノード単位で通知を受け取ります。</p></li></ul>
<p>指定可能な値:</p>
<ul><li><p><code>Command</code></p></li><li><p><code>Invocation</code></p></li></ul></blockquote></blockquote>
<p>CloudWatchOutputConfig -&gt; (structure)</p>
<blockquote><p>Amazon Web Services Systems Manager がコマンド出力を送信する先の Amazon CloudWatch Logs 情報。</p>
<p>CloudWatchLogGroupName -&gt; (string)</p>
<blockquote><p>コマンド出力の送信先となる CloudWatch Logs ロググループの名前。グループ名を指定しない場合、Amazon Web Services Systems Manager がロググループを自動作成します。ロググループは次の命名形式を使用します。</p>
<blockquote><p><a href="#id1">``</a>aws/ssm/<em>SystemsManagerDocumentName</em> ``</p></blockquote>
<p>制約:</p>
<ul><li><p>最小: <code>1</code></p></li><li><p>最大: <code>512</code></p></li></ul></blockquote>
<p>CloudWatchOutputEnabled -&gt; (boolean)</p>
<blockquote><p>Systems Manager がコマンド出力を CloudWatch Logs に送信できるようにします。</p></blockquote></blockquote>
<p>TimeoutSeconds -&gt; (integer)</p>
<blockquote><p>コマンドに指定された <code>TimeoutSeconds</code> の値。</p>
<p>制約:</p>
<ul><li><p>最小: <code>30</code></p></li><li><p>最大: <code>2592000</code></p></li></ul></blockquote>
<p>AlarmConfiguration -&gt; (structure)</p>
<blockquote><p>コマンドに適用された CloudWatch アラームの詳細。</p>
<p>IgnorePollAlarmFailure -&gt; (boolean)</p>
<blockquote><p>この値が <em>true</em> の場合、CloudWatch からアラーム状態情報を取得できない場合でも、オートメーションまたはコマンドは実行を継続します。OK または INSUFFICIENT_DATA のアラーム状態を正常に取得できた場合は、この値にかかわらず実行を継続します。既定値は <em>false</em> です。</p></blockquote>
<p>Alarms -&gt; (list) [必須]</p>
<blockquote><p>設定で指定した CloudWatch アラームの名前。</p>
<p>制約:</p>
<ul><li><p>最小: <code>1</code></p></li><li><p>最大: <code>1</code></p></li></ul>
<p>(structure)</p>
<blockquote><p>オートメーションまたはコマンドに適用する CloudWatch アラーム。</p>
<p>Name -&gt; (string) [必須]</p>
<blockquote><p>CloudWatch アラームの名前。</p>
<p>制約:</p>
<ul><li><p>最小: <code>1</code></p></li><li><p>最大: <code>255</code></p></li><li><p>パターン: <code>^(?!\s*$).+</code></p></li></ul></blockquote></blockquote></blockquote></blockquote>
<p>TriggeredAlarms -&gt; (list)</p>
<blockquote><p>コマンドによって呼び出された CloudWatch アラーム。</p>
<p>制約:</p>
<ul><li><p>最小: <code>1</code></p></li><li><p>最大: <code>1</code></p></li></ul>
<p>(structure)</p>
<blockquote><p>CloudWatch アラームの状態の詳細。</p>
<p>Name -&gt; (string) [必須]</p>
<blockquote><p>CloudWatch アラームの名前。</p>
<p>制約:</p>
<ul><li><p>最小: <code>1</code></p></li><li><p>最大: <code>255</code></p></li><li><p>パターン: <code>^(?!\s*$).+</code></p></li></ul></blockquote>
<p>State -&gt; (string) [必須]</p>
<blockquote><p>CloudWatch アラームの状態。</p>
<p>指定可能な値:</p>
<ul><li><p><code>UNKNOWN</code></p></li><li><p><code>ALARM</code></p></li></ul></blockquote></blockquote></blockquote></blockquote></blockquote>

<p>NextToken -&gt; (string)</p>

<blockquote><p>(オプション) 返す次の項目セットのトークン。(このトークンは前の呼び出しで受け取ったものです。)</p></blockquote>
