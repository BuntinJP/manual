## create-resource-data-sync¶ {#create-resource-data-sync}


### 説明¶ {#Description}


<p>リソースデータ同期を使用すると、複数のソースのデータを 1 か所で表示できます。Amazon Web Services Systems Manager は、<code>SyncToDestination</code> と <code>SyncFromSource</code> の 2 種類のリソースデータ同期を提供しています。</p>

<p>Systems Manager Inventory で <code>SyncToDestination</code> タイプを使用し、複数の Amazon Web Services リージョンの Inventory データを 1 つの Amazon Simple Storage Service (Amazon S3) バケットに同期するよう設定できます。詳細については、<em>Amazon Web Services Systems Manager ユーザーガイド</em>の <a href="https://docs.aws.amazon.com/systems-manager/latest/userguide/inventory-create-resource-data-sync.html">Creating a resource data sync for Inventory</a> を参照してください。</p>

<p>Systems Manager Explorer で <code>SyncFromSource</code> タイプを使用し、複数の Amazon Web Services リージョンの運用作業項目 (OpsItem) と運用データ (OpsData) を 1 つの Amazon S3 バケットに同期するよう設定できます。このタイプは、Organizations を使用して、複数の Amazon Web Services アカウントおよび Amazon Web Services リージョンまたは <code>EntireOrganization</code> から OpsItem と OpsData を同期できます。詳細については、<em>Amazon Web Services Systems Manager ユーザーガイド</em>の <a href="https://docs.aws.amazon.com/systems-manager/latest/userguide/Explorer-resource-data-sync.html">Setting up Systems Manager Explorer to display data from multiple accounts and Regions</a> を参照してください。</p>

<p>リソースデータ同期は、直ちに応答を返す非同期操作です。最初の同期が正常に完了した後、システムは継続的にデータを同期します。同期の状態を確認するには、ListResourceDataSync を使用します。</p>

#### 注記 {#Note}


<p>既定では、Amazon S3 内のデータは暗号化されません。安全にデータを保存するために、Amazon S3 で暗号化を有効にすることを強くお勧めします。また、制限の厳しいバケットポリシーを作成して、Amazon S3 バケットへのアクセスを保護することもお勧めします。</p>

<p>関連項目: <a href="https://docs.aws.amazon.com/goto/WebAPI/ssm-2014-11-06/CreateResourceDataSync">AWS API Documentation</a></p>
