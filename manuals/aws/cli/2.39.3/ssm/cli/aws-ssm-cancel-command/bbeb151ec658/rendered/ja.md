## cancel-command¶ {#cancel-command}


### 説明¶ {#Description}


<p>Command ID で指定したコマンドのキャンセルを試みます。コマンドが終了し、その基盤となるプロセスが停止するという保証はありません。</p>

<p>関連項目: <a href="https://docs.aws.amazon.com/goto/WebAPI/ssm-2014-11-06/CancelCommand">AWS API Documentation</a></p>
