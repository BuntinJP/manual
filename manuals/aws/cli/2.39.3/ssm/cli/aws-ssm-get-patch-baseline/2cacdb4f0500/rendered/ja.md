<p>Patch Manager は、協定世界時 (UTC) を使用してパッチのリリース日を評価します。パッチが <code>2025-11-09T18:00:00Z</code> にリリースされ、<code>ApproveAfterDays</code> が <code>7</code> に設定されている場合、パッチは <code>2025-11-16T18:00:00Z</code> より後に承認されます。</p>
<p>このパラメータは <code>Required: No</code> と記載されていますが、リクエストには <code>ApproveAfterDays</code> または <code>ApproveUntilDate</code> のいずれかの値を含める必要があります。</p>
<p>Debian Server または Ubuntu Server ではサポートされません。</p>
<h4 id="Warning">警告</h4>
<p>Windows Server のパッチベースラインでこの値を設定する際は注意してください。後の更新プログラムに置き換えられたパッチ更新プログラムは削除されるため、このパラメータに広すぎる値を設定すると、重要なパッチがインストールされない場合があります。詳細については、<em>Amazon Web Services Systems Manager ユーザーガイド</em>のトピック <a href="https://docs.aws.amazon.com/systems-manager/latest/userguide/patch-manager-selecting-patches.html">How security patches are selected</a> にある <strong>Windows Server</strong> タブを参照してください。</p>
<p>制約:</p>
<ul><li><p>最小: <code>0</code></p></li><li><p>最大: <code>360</code></p></li></ul></blockquote>
<p>ApproveUntilDate -&gt; (string)</p>
<blockquote><p>リリース済みパッチの自動承認の締め切り日。この日以前にリリースされたすべてのパッチが自動的にインストールされます。</p>
<p>日付は <code>YYYY-MM-DD</code> の形式で入力します。例: <code>2025-11-16</code>。</p>
<p>Patch Manager は、協定世界時 (UTC) を使用してパッチのリリース日を評価します。日付 <code>2025-11-16</code> を入力すると、<code>2025-11-16T00:00:00Z</code> から <code>2025-11-16T23:59:59Z</code> の間にリリースされたパッチが承認に含まれます。</p>
<p>このパラメータは <code>Required: No</code> と記載されていますが、リクエストには <code>ApproveUntilDate</code> または <code>ApproveAfterDays</code> のいずれかの値を含める必要があります。</p>
