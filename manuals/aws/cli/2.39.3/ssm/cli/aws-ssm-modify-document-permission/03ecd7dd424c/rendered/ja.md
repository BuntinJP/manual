## modify-document-permission¶ {#modify-document-permission}


### 説明¶ {#Description}


<p>Amazon Web Services Systems Manager ドキュメント (SSM ドキュメント) を公開または非公開で共有します。非公開で共有する場合、そのドキュメントを使用できる人の Amazon Web Services ユーザー ID を指定する必要があります。公開で共有する場合、アカウント ID に <em>All</em> を指定する必要があります。</p>

<p>関連項目: <a href="https://docs.aws.amazon.com/goto/WebAPI/ssm-2014-11-06/ModifyDocumentPermission">AWS API Documentation</a></p>
