## describe-available-patches¶ {#describe-available-patches}


### 説明¶ {#Description}


<p>パッチベースラインに含めることのできるすべてのパッチを一覧表示します。</p>

#### 注記 {#Note}


<p>現在、<code>DescribeAvailablePatches</code> がサポートするオペレーティングシステムは Amazon Linux 1、Amazon Linux 2、Windows Server のみです。</p>

<p>関連項目: <a href="https://docs.aws.amazon.com/goto/WebAPI/ssm-2014-11-06/DescribeAvailablePatches">AWS API Documentation</a></p>

<p><code>describe-available-patches</code> はページネーションを行う操作です。結果のデータセット全体を取得するために、複数回の API 呼び出しが行われる場合があります。<code>--no-paginate</code> 引数を指定すると、ページネーションを無効にできます。ページネーションされた応答に対して <code>--output text</code> と <code>--query</code> 引数を使用する場合、<code>--query</code> 引数は次のクエリ式の結果からデータを抽出する必要があります: <code>Patches</code></p>
