## command-executed¶ {#command-executed}


### 説明¶ {#Description}


<p><code>get-command-invocation</code> でポーリングしたときに、JMESPath クエリ Status が Success を返すまで待機します。成功状態に達するまで 5 秒ごとにポーリングします。確認が 20 回失敗すると、終了コード 255 で終了します。</p>

<p>関連項目: <a href="https://docs.aws.amazon.com/goto/WebAPI/ssm-2014-11-06/GetCommandInvocation">AWS API Documentation</a></p>
