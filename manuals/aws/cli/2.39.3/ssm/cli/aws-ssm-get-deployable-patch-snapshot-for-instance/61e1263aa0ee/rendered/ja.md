## get-deployable-patch-snapshot-for-instance¶ {#get-deployable-patch-snapshot-for-instance}


### 説明¶ {#Description}


<p>マネージドノードが使用するパッチベースラインの現在のスナップショットを取得します。この API は主に <code>AWS-RunPatchBaseline</code> Systems Manager ドキュメント (SSM ドキュメント) によって使用されます。</p>

#### 注記 {#Note}


<p>コマンドラインインターフェイス (CLI) などを使用してローカルでコマンドを実行すると、システムはローカルの Amazon Web Services 認証情報を使用しようとするため、操作は失敗します。これを回避するには、Amazon Web Services Systems Manager コンソールでコマンドを実行できます。スクリプトまたはコマンドでマネージドノードを対象にできる SSM ドキュメントとともに、Amazon Web Services Systems Manager のツールである Run Command を使用します。例えば、<code>AWS-RunShellScript</code> ドキュメントまたは <code>AWS-RunPowerShellScript</code> ドキュメントを使用してコマンドを実行します。</p>

<p>関連項目: <a href="https://docs.aws.amazon.com/goto/WebAPI/ssm-2014-11-06/GetDeployablePatchSnapshotForInstance">AWS API Documentation</a></p>

<p><strong>インスタンスが使用するパッチベースラインの現在のスナップショットを取得するには</strong></p>
