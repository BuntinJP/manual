## create-maintenance-window¶ {#create-maintenance-window}


### 説明¶ {#Description}


<p>新しいメンテナンスウィンドウを作成します。</p>

#### 注記 {#Note}


<p><code>Duration</code> に指定する値によって、開始時刻に基づくメンテナンスウィンドウの具体的な終了時刻が決まります。その終了時刻から <code>Cutoff</code> に指定した時間数を差し引いた時刻より後には、メンテナンスウィンドウのタスクは開始できません。たとえば、メンテナンスウィンドウが午後 3 時に開始し、継続時間が 3 時間で、<code>Cutoff</code> に 1 時間を指定した場合、午後 5 時より後にタスクを開始することはできません。</p>

<p>関連項目: <a href="https://docs.aws.amazon.com/goto/WebAPI/ssm-2014-11-06/CreateMaintenanceWindow">AWS API Documentation</a></p>

<p><code>--schedule-offset</code> (integer)</p>

<blockquote><p>cron 式で指定した日時から、メンテナンスウィンドウを実行するまでに待機する日数。</p>

<ul><li><p>最小: <code>1</code></p></li><li><p>最大: <code>24</code></p></li></ul></blockquote>

<p>制約:</p>
<ul><li><p>最小: <code>0</code></p></li><li><p>最大: <code>23</code></p></li></ul></blockquote>

<p><code>--allow-unassociated-targets</code> | <code>--no-allow-unassociated-targets</code> (boolean) [必須]</p>

<blockquote><p>ノードを対象として登録していない場合でも、マネージドノードでメンテナンスウィンドウのタスクを実行できるようにします。有効にした場合、メンテナンスウィンドウにタスクを登録するときに、未登録のマネージドノードをノード ID で指定する必要があります。</p>
<p>このオプションを有効にしない場合、メンテナンスウィンドウにタスクを登録するときに、以前に登録した対象を指定する必要があります。</p></blockquote>

<p><strong>例 1: メンテナンスウィンドウを作成するには</strong></p>

<p>次の <code>create-maintenance-window</code> の例は、5 分ごとに必要に応じて最大 2 時間実行される新しいメンテナンスウィンドウを作成します。ウィンドウの実行終了までの 1 時間は新しいタスクの開始を禁止し、未関連付けの対象 (メンテナンスウィンドウに登録していないインスタンス) を許可します。また、カスタムタグを使って、作成者がチュートリアルで使用する意図であることを示します。</p>

<pre><code>aws ssm create-maintenance-window \
    --name &quot;My-Tutorial-Maintenance-Window&quot; \
    --schedule &quot;rate(5 minutes)&quot; \
    --duration 2 \
    --cutoff 1 \
    --allow-unassociated-targets \
    --tags &quot;Key=Purpose,Value=Tutorial&quot;</code></pre>

<p>出力:</p>

<pre><code>{
    &quot;WindowId&quot;: &quot;mw-0c50858d01EXAMPLE&quot;
}</code></pre>
