## put-inventory¶ {#put-inventory}


### 説明¶ {#Description}


<p>1 つ以上のマネージドノードのカスタムインベントリ項目を一括更新します。リクエストは、インベントリ項目がまだ存在しない場合は追加し、既に存在する場合は更新します。</p>

<p>関連項目: <a href="https://docs.aws.amazon.com/goto/WebAPI/ssm-2014-11-06/PutInventory">AWS API Documentation</a></p>
