## describe-instance-properties¶ {#describe-instance-properties}


### 説明¶ {#Description}


<p>Systems Manager コンソールが Systems Manager マネージドノードの情報を表示するために使用する API オペレーション。</p>

<p>関連項目: <a href="https://docs.aws.amazon.com/goto/WebAPI/ssm-2014-11-06/DescribeInstanceProperties">AWS API Documentation</a></p>

<p><code>describe-instance-properties</code> はページネーションを行う操作です。結果のデータセット全体を取得するために、複数回の API 呼び出しが行われる場合があります。<code>--no-paginate</code> 引数を指定すると、ページネーションを無効にできます。ページネーションされた応答に対して <code>--output text</code> と <code>--query</code> 引数を使用する場合、<code>--query</code> 引数は次のクエリ式の結果からデータを抽出する必要があります: <code>InstanceProperties</code></p>
