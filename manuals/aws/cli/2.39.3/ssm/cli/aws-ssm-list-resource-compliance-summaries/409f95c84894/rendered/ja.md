## list-resource-compliance-summaries¶ {#list-resource-compliance-summaries}


### 説明¶ {#Description}


<p>リソースレベルの件数概要を返します。概要には、指定したフィルター条件に応じた、準拠・非準拠の状態情報と、コンプライアンス項目の重要度別の詳細な件数が含まれます。</p>

<p>関連項目: <a href="https://docs.aws.amazon.com/goto/WebAPI/ssm-2014-11-06/ListResourceComplianceSummaries">AWS API Documentation</a></p>

<p><code>list-resource-compliance-summaries</code> はページネーションを行う操作です。結果のデータセット全体を取得するために、複数回の API 呼び出しが行われる場合があります。<code>--no-paginate</code> 引数を指定すると、ページネーションを無効にできます。ページネーションされた応答に対して <code>--output text</code> と <code>--query</code> 引数を使用する場合、<code>--query</code> 引数は次のクエリ式の結果からデータを抽出する必要があります: <code>ResourceComplianceSummaryItems</code></p>
