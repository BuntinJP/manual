## describe-automation-step-executions¶ {#describe-automation-step-executions}


### 説明¶ {#Description}


<p>Automation ワークフローの、アクティブなすべてのステップ実行と終了したすべてのステップ実行に関する情報。</p>

<p>関連項目: <a href="https://docs.aws.amazon.com/goto/WebAPI/ssm-2014-11-06/DescribeAutomationStepExecutions">AWS API Documentation</a></p>
