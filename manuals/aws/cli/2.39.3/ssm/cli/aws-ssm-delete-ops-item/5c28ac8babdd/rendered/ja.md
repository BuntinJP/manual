## delete-ops-item¶ {#delete-ops-item}


### 説明¶ {#Description}


<p>OpsItem を削除します。OpsItem を削除するには、Identity and Access Management (IAM) の権限が必要です。</p>

#### 警告 {#Warning}


<p>この操作について、次の重要な情報に注意してください。</p>

<ul><li><p>OpsItem の削除は取り消せません。削除した OpsItem を復元することはできません。</p></li><li><p>この操作は <em>結果整合性モデル</em>を使用するため、システムが操作を完了するまでに数分かかる場合があります。OpsItem を削除した直後に、たとえば GetOpsItem を呼び出すと、削除した OpsItem が応答にまだ表示される場合があります。</p></li><li><p>この操作は冪等です。同じ OpsItem に対してこの操作を繰り返し呼び出しても、システムは例外を発生させません。最初の呼び出しが成功した場合、それ以降のすべての呼び出しは最初と同じ成功応答を返します。</p></li><li><p>この操作はクロスアカウント呼び出しをサポートしていません。OpsCenter にクロスアカウント管理を設定していても、委任管理者や管理アカウントはほかのアカウント内の OpsItem を削除できません。クロスアカウント管理の詳細については、<em>Systems Manager ユーザーガイド</em>の <a href="https://docs.aws.amazon.com/systems-manager/latest/userguide/OpsCenter-setting-up-cross-account.html">Setting up OpsCenter to centrally manage OpsItems across accounts</a> を参照してください。</p></li></ul>

<p>関連項目: <a href="https://docs.aws.amazon.com/goto/WebAPI/ssm-2014-11-06/DeleteOpsItem">AWS API Documentation</a></p>
