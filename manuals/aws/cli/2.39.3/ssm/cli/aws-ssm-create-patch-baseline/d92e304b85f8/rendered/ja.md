## create-patch-baseline¶ {#create-patch-baseline}


### 説明¶ {#Description}

<blockquote><p><code>RejectedPackages</code> 一覧に含まれるパッチに対して Patch Manager が実行するアクション。</p>
<blockquote><blockquote><p>ALLOW_AS_DEPENDENCY</p></blockquote>
<p><strong>Linux および macOS</strong>: 拒否されたパッチの一覧にあるパッケージは、別のパッケージの依存関係である場合にのみインストールされます。パッチベースラインに準拠しているとみなされ、ステータスは <code>INSTALLED_OTHER</code> として報告されます。オプションを指定しない場合、これがデフォルトのアクションです。</p>

<p><strong>すべての OS</strong>: 拒否されたパッチの一覧にあるパッケージ、およびそれらを依存関係として含むパッケージは、いかなる場合も Patch Manager によってインストールされません。</p></blockquote>
<p>パッチコンプライアンスの状態値の割り当て:</p>
<ul><li><p>パッケージが拒否されたパッチの一覧に追加される前にインストールされた場合、または追加後に Patch Manager 以外でインストールされた場合、そのパッケージはパッチベースラインに非準拠とみなされ、ステータスは <code>INSTALLED_REJECTED</code> として報告されます。</p></li><li><p>パッケージの以前のバージョンは拒否されていなかったものの、現在はベースラインで拒否されている依存パッケージを更新処理がインストールしようとした場合、更新対象のパッケージは <code>SCAN</code> 操作では <code>MISSING</code>、<code>INSTALL</code> 操作では <code>FAILED</code> として報告されます。</p></li></ul>
<p>指定可能な値:</p>
<ul><li><p><code>ALLOW_AS_DEPENDENCY</code></p></li><li><p><code>BLOCK</code></p></li></ul></blockquote>

### 例¶ {#Examples}

<p>以下の例を使用するには、AWS CLI をインストールして設定しておく必要があります。詳細については、<em>AWS CLI ユーザーガイド</em>の <a href="https://docs.aws.amazon.com/cli/latest/userguide/cli-chap-getting-started.html">Getting started guide</a> を参照してください。</p>

<p>特に断りのない限り、すべての例は Unix 系の引用符規則を使用しています。これらの例は、使用する端末の引用符規則に合わせて調整する必要があります。<em>AWS CLI ユーザーガイド</em>の <a href="https://docs.aws.amazon.com/cli/latest/userguide/cli-usage-parameters-quoting-strings.html">Using quotation marks with strings</a> を参照してください。</p>

<p><strong>例 1: 自動承認を備えたパッチベースラインを作成するには</strong></p>

<p>次の <code>create-patch-baseline</code> の例は、Microsoft によるパッチのリリースから 7 日後に本番環境用のパッチを承認する Windows Server のパッチベースラインを作成します。</p>

<pre><code>aws ssm create-patch-baseline \
    --name &quot;Windows-Production-Baseline-AutoApproval&quot; \
    --operating-system &quot;WINDOWS&quot; \
    --approval-rules &quot;PatchRules=[{PatchFilterGroup={PatchFilters=[{Key=MSRC_SEVERITY,Values=[Critical,Important,Moderate]},{Key=CLASSIFICATION,Values=[SecurityUpdates,Updates,UpdateRollups,CriticalUpdates]}]},ApproveAfterDays=7}]&quot; \
    --description &quot;Baseline containing all updates approved for Windows Server production systems&quot;</code></pre>

<p>出力:</p>

<pre><code>{
    &quot;BaselineId&quot;: &quot;pb-045f10b4f3EXAMPLE&quot;
