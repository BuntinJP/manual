### 出力¶ {#Output}


<p>Instances -&gt; (integer)</p>

<blockquote><p>パッチグループ内のマネージドノードの数。</p></blockquote>

<p>InstancesWithInstalledPatches -&gt; (integer)</p>

<blockquote><p>インストール済みパッチがあるマネージドノードの数。</p></blockquote>

<p>InstancesWithInstalledOtherPatches -&gt; (integer)</p>

<blockquote><p>パッチベースラインで定義されていないパッチがインストールされているマネージドノードの数。</p></blockquote>

<p>InstancesWithInstalledPendingRebootPatches -&gt; (integer)</p>

<blockquote><p>Patch Manager がパッチをインストールした後、まだ再起動されていないマネージドノードの数。これらのマネージドノードの状態は <code>NON_COMPLIANT</code> です。</p></blockquote>

<p>InstancesWithInstalledRejectedPatches -&gt; (integer)</p>

<blockquote><p><code>RejectedPatches</code> 一覧に指定されたパッチがインストールされているマネージドノードの数。状態が <code>INSTALLED_REJECTED</code> のパッチは通常、<code>RejectedPatches</code> 一覧に追加される前にインストールされたものです。</p>
<h4 id="Note-2">注記</h4>
<p><code>RejectedPatchesAction</code> に指定されたオプションが <code>ALLOW_AS_DEPENDENCY</code> の場合、<code>InstancesWithInstalledRejectedPatches</code> の値は常に <code>0</code> (ゼロ) になります。</p></blockquote>

<p>InstancesWithMissingPatches -&gt; (integer)</p>

<blockquote><p>パッチベースラインに含まれるパッチが不足しているマネージドノードの数。</p></blockquote>

<p>InstancesWithFailedPatches -&gt; (integer)</p>

<blockquote><p>パッチベースラインに含まれるパッチのインストールに失敗したマネージドノードの数。</p></blockquote>

<p>InstancesWithNotApplicablePatches -&gt; (integer)</p>

<blockquote><p>適用対象外のパッチがあるマネージドノードの数。</p></blockquote>

<p>InstancesWithUnreportedNotApplicablePatches -&gt; (integer)</p>

<blockquote><p>サポートされる上限を超える <code>NotApplicable</code> パッチがあり、それらのパッチが名前付きで Inventory に報告されないマネージドノードの数。Inventory は Amazon Web Services Systems Manager のツールです。</p></blockquote>

<p>InstancesWithCriticalNonCompliantPatches -&gt; (integer)</p>

<blockquote><p>パッチベースラインのコンプライアンス報告で <code>Critical</code> と指定されたパッチがインストールされていないマネージドノードの数。これらのパッチは、不足、インストール失敗、拒否、またはインストール済みで必要なマネージドノードの再起動待ちの可能性があります。これらのマネージドノードの状態は <code>NON_COMPLIANT</code> です。</p></blockquote>

<p>InstancesWithSecurityNonCompliantPatches -&gt; (integer)</p>

<blockquote><p>パッチアドバイザリで <code>Security</code> と指定されたパッチがインストールされていないマネージドノードの数。これらのパッチは、不足、インストール失敗、拒否、またはインストール済みで必要なマネージドノードの再起動待ちの可能性があります。これらのマネージドノードの状態は <code>NON_COMPLIANT</code> です。</p></blockquote>

<p>InstancesWithOtherNonCompliantPatches -&gt; (integer)</p>

<blockquote><p><code>Critical</code> または <code>Security</code> 以外に指定され、パッチベースラインに準拠していないパッチがインストールされているマネージドノードの数。これらのマネージドノードの状態は <code>NON_COMPLIANT</code> です。</p></blockquote>

<p>InstancesWithAvailableSecurityUpdates -&gt; (integer)</p>

<blockquote><p>セキュリティ関連のパッチが利用可能でも、パッチベースラインの要件を満たしていないため承認されていないマネージドノードの数。たとえば、指定された自動承認期間が終わる前に、パッチの更新版がリリースされた場合があります。</p>
<p>Windows Server マネージドノードにのみ適用されます。</p></blockquote>
