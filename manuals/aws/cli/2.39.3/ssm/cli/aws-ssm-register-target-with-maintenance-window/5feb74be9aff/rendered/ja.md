### オプション¶ {#Options}


<p><code>--window-id</code> (string) [必須]</p>

<blockquote><p>対象を登録するメンテナンスウィンドウの ID。</p>
<p>制約:</p>
<ul><li><p>最小: <code>20</code></p></li><li><p>最大: <code>20</code></p></li><li><p>パターン: <code>^mw-[0-9a-f]{17}$</code></p></li></ul></blockquote>

<p><code>--resource-type</code> (string) [必須]</p>

<blockquote><p>メンテナンスウィンドウに登録する対象の種類。</p>
<p>指定可能な値:</p>
<ul><li><p><code>INSTANCE</code></p></li><li><p><code>RESOURCE_GROUP</code></p></li></ul></blockquote>

<p><code>--targets</code> (list) [必須]</p>

<blockquote><p>メンテナンスウィンドウに登録する対象。つまり、メンテナンスウィンドウの実行時にコマンドを実行するマネージドノードです。</p>
<h4 id="Note">注記</h4>
<p>単一のメンテナンスウィンドウタスクが複数の対象に登録されている場合、そのタスクの呼び出しは並列ではなく順番に行われます。複数の対象で同時に実行する必要がある場合は、対象ごとにタスクを個別に登録し、各タスクに同じ優先度を割り当ててください。</p>
<p>マネージドノード ID、リソースグループ名、またはマネージドノードに適用したタグを使用して対象を指定できます。</p>
<blockquote><p><strong>例 1</strong>: マネージドノード ID を指定する</p>
<p><code>Key=InstanceIds,Values=&lt;instance-id-1&gt;,&lt;instance-id-2&gt;,&lt;instance-id-3&gt;</code></p>
<p><strong>例 2</strong>: マネージドノードに適用したタグのキーペアを使用する</p>
<p><code>Key=tag:&lt;my-tag-key&gt;,Values=&lt;my-tag-value-1&gt;,&lt;my-tag-value-2&gt;</code></p>
<p><strong>例 3</strong>: マネージドノードに適用したタグキーを使用する</p>
<p><code>Key=tag-key,Values=&lt;my-tag-key-1&gt;,&lt;my-tag-key-2&gt;</code></p>
<p><strong>例 4</strong>: リソースグループ名を使用する</p>
<p><code>Key=resource-groups:Name,Values=&lt;resource-group-name&gt;</code></p>
<p><strong>例 5</strong>: リソースグループタイプのフィルターを使用する</p>
<p><code>Key=resource-groups:ResourceTypeFilters,Values=&lt;resource-type-1&gt;,&lt;resource-type-2&gt;</code></p></blockquote>
<h4 id="Note-2">注記</h4>
<p><code>Key=resource-groups:ResourceTypeFilters</code> には、次の形式でリソースタイプを指定します。</p>
<blockquote><p><code>Key=resource-groups:ResourceTypeFilters,Values=AWS::EC2::INSTANCE,AWS::EC2::VPC</code></p></blockquote>
<p>各形式に適したユースケースなど、これらの例の形式について詳しくは、<em>Amazon Web Services Systems Manager ユーザーガイド</em>の <a href="https://docs.aws.amazon.com/systems-manager/latest/userguide/mw-cli-tutorial-targets-examples.html">Examples: Register targets with a maintenance window</a> を参照してください。</p>
<p>制約:</p>
<ul><li><p>最小: <code>0</code></p></li><li><p>最大: <code>5</code></p></li></ul>
<p>(structure)</p>
<blockquote><p>指定したキーと値のペアを使用してマネージドノードを対象にする、検索条件の配列。</p>
<h4 id="Note-3">注記</h4>
<p>メンテナンスウィンドウの Run Command タイプのタスクには、1 つ以上の対象を指定する必要があります。ほかのメンテナンスウィンドウのタスクタイプ (Automation、Lambda、Step Functions) では、タスクによって対象の指定は任意です。対象を指定しないタスクの実行については、<em>Amazon Web Services Systems Manager ユーザーガイド</em>の <a href="https://docs.aws.amazon.com/systems-manager/latest/userguide/maintenance-windows-targetless-tasks.html">Registering maintenance window tasks without targets</a> を参照してください。</p>
<p>サポートされる形式は次のとおりです。</p>
<blockquote><p><strong>すべての Systems Manager ツールの場合:</strong></p></blockquote>
<ul><li><p><code>Key=tag-key,Values=tag-value-1,tag-value-2</code></p></li></ul>
<blockquote><p><strong>Automation と Change Manager の場合:</strong></p></blockquote>
<ul><li><p><code>Key=tag:tag-key,Values=tag-value</code></p></li><li><p><code>Key=ResourceGroup,Values=resource-group-name</code></p></li><li><p><code>Key=ParameterValues,Values=value-1,value-2,value-3</code></p></li><li><p>Amazon Web Services リージョン内のすべてのインスタンスを対象とするには:</p>
<ul><li><p><code>Key=AWS::EC2::Instance,Values=*</code></p></li><li><p><code>Key=InstanceIds,Values=*</code></p></li></ul></li></ul>
<blockquote><p><strong>Run Command と Maintenance Windows の場合:</strong></p></blockquote>
<ul><li><p><code>Key=InstanceIds,Values=instance-id-1,instance-id-2,instance-id-3</code></p></li><li><p><code>Key=tag:tag-key,Values=tag-value-1,tag-value-2</code></p></li><li><p><code>Key=resource-groups:Name,Values=resource-group-name</code></p></li><li><p>また、Maintenance Windows はリソースタイプによる対象指定をサポートします。</p>
<ul><li><p><code>Key=resource-groups:ResourceTypeFilters,Values=resource-type-1,resource-type-2</code></p></li></ul></li></ul>
<blockquote><p><strong>State Manager の場合:</strong></p></blockquote>
<ul><li><p><code>Key=InstanceIds,Values=instance-id-1,instance-id-2,instance-id-3</code></p></li><li><p><code>Key=tag:tag-key,Values=tag-value-1,tag-value-2</code></p></li><li><p>Amazon Web Services リージョン内のすべてのインスタンスを対象とするには:</p>
<ul><li><p><code>Key=InstanceIds,Values=*</code></p></li></ul></li></ul>
<p><code>Key,Value</code> パラメーターを使ってマネージドノードを対象とするコマンドの送信方法については、<em>Amazon Web Services Systems Manager ユーザーガイド</em>の <a href="https://docs.aws.amazon.com/systems-manager/latest/userguide/send-commands-multiple.html#send-commands-targeting">Targeting multiple managed nodes</a> を参照してください。</p>
<p>Key -&gt; (string)</p>
<blockquote><p>条件を満たすマネージドノードを対象にコマンドを送信するための、ユーザー定義の条件。</p>
<p>制約:</p>
<ul><li><p>最小: <code>1</code></p></li><li><p>最大: <code>163</code></p></li><li><p>パターン: <code>^[\p{L}\p{Z}\p{N}_.:/=\-@]*$|resource-groups:ResourceTypeFilters|resource-groups:Name</code></p></li></ul></blockquote>
<p>Values -&gt; (list)</p>
<blockquote><p><code>Key</code> に対応するユーザー定義の条件。たとえば、<code>tag:ServerRole</code> を指定した場合、<code>value:WebServer</code> を指定すると、EC2 タグに <code>ServerRole,WebServer</code> を含むインスタンスでコマンドを実行できます。</p>
<p>対象の種類によっては、キーに指定できる値の最大数が、全体の上限である 50 より少なくなる場合があります。</p>
<p>制約:</p>
<ul><li><p>最小: <code>0</code></p></li><li><p>最大: <code>50</code></p></li></ul>
<p>(string)</p></blockquote></blockquote></blockquote>

<p>短縮構文:</p>

<pre><code>Key=string,Values=string,string ...</code></pre>

<p>JSON 構文:</p>

<pre><code>[

<p><strong>例 5: リソースグループ名を使って対象を登録するには</strong></p>

<p>次の <code>register-target-with-maintenance-window</code> の例は、含まれるリソースの種類にかかわらず、指定したリソースグループを登録します。</p>

<pre><code>aws ssm register-target-with-maintenance-window \
    --window-id &quot;mw-0c50858d01EXAMPLE&quot; \
    --resource-type &quot;RESOURCE_GROUP&quot; \
    --target &quot;Key=resource-groups:Name,Values=MyResourceGroup&quot;</code></pre>

<p>出力:</p>

<pre><code>{
    &quot;WindowTargetId&quot;:&quot;1a2b3c4d-1a2b-1a2b-1a2b-1a2b3c4d-1a2&quot;
}</code></pre>

<p>詳細については、<em>AWS Systems Manager ユーザーガイド</em>の <a href="https://docs.aws.amazon.com/systems-manager/latest/userguide/mw-cli-tutorial-targets.html">Register a Target Instance with the Maintenance Window (AWS CLI)</a> を参照してください。</p>
