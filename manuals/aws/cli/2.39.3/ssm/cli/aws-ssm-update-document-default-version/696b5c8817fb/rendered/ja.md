## update-document-default-version¶ {#update-document-default-version}


### 説明¶ {#Description}


<p>ドキュメントの既定のバージョンを設定します。</p>

#### 注記 {#Note}


<p>State Manager の関連付けでドキュメントのバージョンを変更すると、以前に <code>apply-only-at-cron-interval</code> パラメーターを指定していた場合を除き、Systems Manager はその関連付けを直ちに実行します。</p>

<p>関連項目: <a href="https://docs.aws.amazon.com/goto/WebAPI/ssm-2014-11-06/UpdateDocumentDefaultVersion">AWS API Documentation</a></p>
