## associate-ops-item-related-item¶ {#associate-ops-item-related-item}


### 説明¶ {#Description}


<p>関連項目を Systems Manager OpsCenter の OpsItem に関連付けます。たとえば、Incident Manager のインシデントや分析を OpsItem に関連付けることができます。Incident Manager と OpsCenter は Amazon Web Services Systems Manager のツールです。</p>

<p>関連項目: <a href="https://docs.aws.amazon.com/goto/WebAPI/ssm-2014-11-06/AssociateOpsItemRelatedItem">AWS API Documentation</a></p>

### オプション¶ {#Options}

<blockquote><p>OpsItem とリソースの間に作成する関連付けの種類。OpsCenter は <code>IsParentOf</code> と <code>RelatesTo</code> の関連付けの種類をサポートしています。</p></blockquote>
