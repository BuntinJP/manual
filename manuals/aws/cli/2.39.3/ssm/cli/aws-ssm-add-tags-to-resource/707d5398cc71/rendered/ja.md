## add-tags-to-resource¶ {#add-tags-to-resource}


### 説明¶ {#Description}


<p>指定したリソースに 1 つ以上のタグを追加または上書きします。<em>タグ</em>は、オートメーション、ドキュメント、マネージドノード、メンテナンスウィンドウ、Parameter Store のパラメーター、パッチベースラインに割り当てられるメタデータです。タグにより、目的、所有者、環境など、さまざまな方法でリソースを分類できます。各タグは、自分で定義するキーと任意の値で構成されます。たとえば、各ノードの所有者とスタックレベルを追跡するために、アカウントのマネージドノード用のタグセットを定義できます。例:</p>

<ul><li><p><code>Key=Owner,Value=DbAdmin</code></p></li><li><p><code>Key=Owner,Value=SysAdmin</code></p></li><li><p><code>Key=Owner,Value=Dev</code></p></li><li><p><code>Key=Stack,Value=Production</code></p></li><li><p><code>Key=Stack,Value=Pre-Production</code></p></li><li><p><code>Key=Stack,Value=Test</code></p></li></ul>

<p>ほとんどのリソースには最大 50 個のタグを付けられます。オートメーションには最大 5 個のタグを付けられます。</p>

<p>リソースタイプごとの要件を満たすタグキーのセットを設計することをお勧めします。一貫したタグキーのセットを使用すると、リソースを管理しやすくなります。追加したタグに基づいてリソースを検索し、絞り込めます。タグには意味的な意味付けはなく、厳密に文字列として解釈されます。</p>

<p>Amazon Elastic Compute Cloud (Amazon EC2) インスタンスでのタグの使用については、<em>Amazon EC2 ユーザーガイド</em>の <a href="https://docs.aws.amazon.com/AWSEC2/latest/UserGuide/Using_Tags.html">Tag your Amazon EC2 resources</a> を参照してください。</p>

<p>関連項目: <a href="https://docs.aws.amazon.com/goto/WebAPI/ssm-2014-11-06/AddTagsToResource">AWS API Documentation</a></p>

### オプション¶ {#Options}


<p><code>--resource-type</code> (string) [必須]</p>

<p>この API 操作の <code>ManagedInstance</code> タイプは、オンプレミスのマネージドノード用です。マネージドノードの名前は、次の形式で指定する必要があります: <code>mi-*ID_number* `` . For example, ``mi-1a2b3c4d5e6f</code>。</p>
