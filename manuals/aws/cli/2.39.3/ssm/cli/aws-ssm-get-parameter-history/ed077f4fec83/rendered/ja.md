## get-parameter-history¶ {#get-parameter-history}


### 説明¶ {#Description}


<p>パラメーターのすべての変更履歴を取得します。</p>

<p>パラメーター名にスペースを含めることはできません。サービスは、パラメーター名の先頭または末尾に指定されたスペースをすべて削除します。指定したパラメーター名の文字の間にスペースがある場合、リクエストは <code>ValidationException</code> エラーで失敗します。</p>

#### 警告 {#Warning}


<p>パラメーターの暗号化に使用した KMS キーのエイリアスを変更した場合は、そのパラメーターが KMS の参照に使用するキーエイリアスも更新する必要があります。そうしない場合、<code>GetParameterHistory</code> は元のキーエイリアスが参照していたものを取得します。</p>

<p>関連項目: <a href="https://docs.aws.amazon.com/goto/WebAPI/ssm-2014-11-06/GetParameterHistory">AWS API Documentation</a></p>

<p><code>get-parameter-history</code> はページネーションを行う操作です。結果のデータセット全体を取得するために、複数回の API 呼び出しが行われる場合があります。<code>--no-paginate</code> 引数を指定すると、ページネーションを無効にできます。ページネーションされた応答に対して <code>--output text</code> と <code>--query</code> 引数を使用する場合、<code>--query</code> 引数は次のクエリ式の結果からデータを抽出する必要があります: <code>Parameters</code></p>
