## reset-service-setting¶ {#reset-service-setting}


### 説明¶ {#Description}


<blockquote><p><code>ServiceSetting</code> は Amazon Web Services サービスのアカウントレベルの設定です。この設定は、ユーザーがサービスやその機能をどのように操作し、使用するかを定義します。たとえば、機能やサービスの使用量に基づいてアカウントに課金する Amazon Web Services サービスでは、サービスチームが既定の設定を「false」にすることがあります。これは、ユーザーが設定を「true」に変更して有料機能を明示的に利用開始しない限り、その機能を使用できないことを意味します。</p></blockquote>

<p>サービスは <code>SettingId</code> オブジェクトを設定値に対応付けます。<code>SettingId</code> の既定値は Amazon Web Services のサービスチームが定義します。新しい <code>SettingId</code> を作成することはできませんが、その設定の <code>ssm:UpdateServiceSetting</code> 権限を持っていれば既定値を上書きできます。現在値を表示するには GetServiceSetting API 操作を使用します。既定の設定を変更するには UpdateServiceSetting API 操作を使用します。</p>

<p>アカウントのサービス設定を、Amazon Web Services のサービスチームが用意した既定値にリセットします。</p>

<p>関連項目: <a href="https://docs.aws.amazon.com/goto/WebAPI/ssm-2014-11-06/ResetServiceSetting">AWS API Documentation</a></p>

### オプション¶ {#Options}


<p><code>--setting-id</code> (string) [必須]</p>

<blockquote><p>リセットするサービス設定の Amazon リソースネーム (ARN)。設定 ID には次のいずれかを指定できます。</p>
<ul><li><p><code>/ssm/appmanager/appmanager-enabled</code></p></li><li><p><code>/ssm/automation/customer-script-log-destination</code></p></li><li><p><code>/ssm/automation/customer-script-log-group-name</code></p></li><li><p>/ssm/automation/enable-adaptive-concurrency</p></li><li><p><code>/ssm/documents/console/public-sharing-permission</code></p></li><li><p><code>/ssm/managed-instance/activation-tier</code></p></li><li><p><code>/ssm/managed-instance/default-ec2-instance-management-role</code></p></li><li><p><code>/ssm/opsinsights/opscenter</code></p></li><li><p><code>/ssm/parameter-store/default-parameter-tier</code></p></li><li><p><code>/ssm/parameter-store/high-throughput-enabled</code></p></li></ul>
