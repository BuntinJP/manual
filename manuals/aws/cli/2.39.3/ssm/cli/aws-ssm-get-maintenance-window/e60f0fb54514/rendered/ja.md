### 出力¶ {#Output}


<p>WindowId -&gt; (string)</p>

<blockquote><p>作成されたメンテナンスウィンドウの ID。</p>
<p>制約:</p>
<ul><li><p>最小: <code>20</code></p></li><li><p>最大: <code>20</code></p></li><li><p>パターン: <code>^mw-[0-9a-f]{17}$</code></p></li></ul></blockquote>

<p>Name -&gt; (string)</p>

<blockquote><p>メンテナンスウィンドウの名前。</p>
<p>制約:</p>
<ul><li><p>最小: <code>3</code></p></li><li><p>最大: <code>128</code></p></li><li><p>パターン: <code>^[a-zA-Z0-9_\-.]{3,128}$</code></p></li></ul></blockquote>

<p>Description -&gt; (string)</p>

<blockquote><p>メンテナンスウィンドウの説明。</p>
<p>制約:</p>
<ul><li><p>最小: <code>1</code></p></li><li><p>最大: <code>128</code></p></li></ul></blockquote>

<p>StartDate -&gt; (string)</p>

<blockquote><p>メンテナンスウィンドウが有効になる予定の日時。ISO-8601 拡張形式で表します。メンテナンスウィンドウは、この指定時刻より前には実行されません。</p></blockquote>

<p>EndDate -&gt; (string)</p>

<blockquote><p>メンテナンスウィンドウが無効になる予定の日時。ISO-8601 拡張形式で表します。メンテナンスウィンドウは、この指定時刻より後には実行されません。</p></blockquote>

<p>Schedule -&gt; (string)</p>

<blockquote><p>cron 式または rate 式で表されるメンテナンスウィンドウのスケジュール。</p>
<p>制約:</p>
<ul><li><p>最小: <code>1</code></p></li><li><p>最大: <code>256</code></p></li></ul></blockquote>

<p>ScheduleTimezone -&gt; (string)</p>

<blockquote><p>スケジュールされたメンテナンスウィンドウの実行の基準となるタイムゾーン。Internet Assigned Numbers Authority (IANA) 形式で表します。例: 「America/Los_Angeles」、「UTC」、「Asia/Seoul」。詳細については、IANA ウェブサイトの <a href="https://www.iana.org/time-zones">Time Zone Database</a> を参照してください。</p></blockquote>

<p>ScheduleOffset -&gt; (integer)</p>

<blockquote><p>cron 式でスケジュールされた日時から、メンテナンスウィンドウの実行までに待機する日数。</p>
<p>制約:</p>
<ul><li><p>最小: <code>1</code></p></li><li><p>最大: <code>6</code></p></li></ul></blockquote>

<p>NextExecutionTime -&gt; (string)</p>

<blockquote><p>メンテナンスウィンドウが有効または無効になる指定時刻を考慮した、次回の実際の実行時刻。</p></blockquote>

<p>Duration -&gt; (integer)</p>

<blockquote><p>メンテナンスウィンドウの継続時間 (時間単位)。</p>
<p>制約:</p>
<ul><li><p>最小: <code>1</code></p></li><li><p>最大: <code>24</code></p></li></ul></blockquote>

<p>Cutoff -&gt; (integer)</p>

<blockquote><p>メンテナンスウィンドウの終了の何時間前に、Amazon Web Services Systems Manager が新しいタスクの実行スケジュールを停止するか。</p>
<p>制約:</p>
<ul><li><p>最小: <code>0</code></p></li><li><p>最大: <code>23</code></p></li></ul></blockquote>

<p>AllowUnassociatedTargets -&gt; (boolean)</p>

<blockquote><p>対象に対してタスクを定義する前に、その対象をメンテナンスウィンドウに登録する必要があるかどうか。</p></blockquote>

<p>Enabled -&gt; (boolean)</p>

<blockquote><p>メンテナンスウィンドウが有効かどうかを示します。</p></blockquote>

<p>CreatedDate -&gt; (timestamp)</p>

<blockquote><p>メンテナンスウィンドウが作成された日時。</p></blockquote>

<p>ModifiedDate -&gt; (timestamp)</p>

<blockquote><p>メンテナンスウィンドウが最後に変更された日時。</p></blockquote>
