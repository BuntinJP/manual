## register-default-host-management-configuration¶ {#register-default-host-management-configuration}


### 説明¶ {#Description}


<p>現在の Amazon Web Services アカウントおよび Amazon Web Services リージョンで Default Host Management Configuration（DHMC）を有効にします。DHMC を有効にすると、Amazon EC2 インスタンスを Amazon Web Services Systems Manager のマネージドノードとして使用するために、インスタンスプロファイルなどの追加リソースを設定する必要がなくなります。</p>

<p>この操作を使用するには、次の権限が必要です。</p>

<ul><li><p><code>/ssm/managed-instance/default-ec2-instance-management-role</code> サービス設定に対する <code>ssm:GetServiceSetting</code> および <code>ssm:UpdateServiceSetting</code> 権限が必要です。</p></li><li><p>Default Host Management Configuration に使用するロールに対する <code>iam:GetRole</code> および <code>iam:PassRole</code> 権限が必要です。</p></li></ul>

<p><code>PermissionModel</code> が <code>SERVICE_MANAGED</code> の場合、Amazon Web Services Systems Manager がユーザーに代わってロールを作成および設定できるように、<code>iam:CreateRole</code> および <code>iam:AttachRolePolicy</code> 権限も必要です。</p>

<p>関連項目: <a href="https://docs.aws.amazon.com/goto/WebAPI/ssm-2014-11-06/RegisterDefaultHostManagementConfiguration">AWS API Documentation</a></p>

### オプション¶ {#Options}


<p><code>--permission-model</code> (string) [必須]</p>

<blockquote><p>Default Host Management Configuration 用の IAM ロールをどのように提供するかを決定するアクセス許可モデルです。</p>
<p>アクセス許可モデルには、次のいずれかの値を指定できます。</p>
<blockquote><p>SERVICE_MANAGED</p></blockquote>
<p>Amazon Web Services Systems Manager がユーザーに代わってロールを作成および管理します。</p>
<blockquote><p>SELF_MANAGED</p></blockquote>
<p>登録するロールを <code>RoleArn</code> に指定します。</p>
<p>指定可能な値:</p>
<ul><li><p><code>SERVICE_MANAGED</code></p></li><li><p><code>SELF_MANAGED</code></p></li></ul></blockquote>

<p><code>--role-arn</code> (string)</p>

<blockquote><p>Default Host Management Configuration に登録する自己管理 IAM ロールの Amazon リソースネーム（ARN）です。この値を指定する必要があるかどうかは、アクセス許可モデルによって異なります。</p>
<ul><li><p><code>PermissionModel</code> が <code>SELF_MANAGED</code> の場合、この値は必須です。</p></li><li><p><code>PermissionModel</code> が <code>SERVICE_MANAGED</code> の場合、この値を設定してはいけません。</p></li></ul>
<p>制約:</p>
<ul><li><p>最小: <code>20</code></p></li><li><p>最大: <code>2048</code></p></li><li><p>パターン: <code>^arn:aws[a-z0-9-]*:iam::\d{12}:role/[\w+=,.@/-]+$</code></p></li></ul></blockquote>

<p><code>--overwrite</code> | <code>--no-overwrite</code> (boolean)</p>

<blockquote><p>Default Host Management Configuration に現在登録されているロールを上書きするかどうかを指定します。既定値は <code>false</code> で、既存の設定を誤って置き換えることを防ぎます。現在登録されているロールを置き換えるには、<code>true</code> に設定します。</p></blockquote>

<p><code>--cli-input-json</code> | <code>--cli-input-yaml</code> (string) 指定された JSON 文字列から引数を読み取ります。JSON 文字列は <code>--generate-cli-skeleton</code> が提供する形式に従います。コマンドラインでほかの引数を指定した場合、その値が JSON で指定した値を上書きします。文字列はそのまま解釈されるため、JSON で指定する値を使って任意のバイナリ値を渡すことはできません。<code>--cli-input-yaml</code> と同時には指定できません。</p>

<p><code>--generate-cli-skeleton</code> (string) API リクエストを送信せずに、JSON スケルトンを標準出力に表示します。値を指定しない場合、または値に <code>input</code> を指定した場合は、<code>--cli-input-json</code> の引数に使用できる入力 JSON のサンプルを表示します。同様に、<code>yaml-input</code> を指定した場合は、<code>--cli-input-yaml</code> で使用できる入力 YAML のサンプルを表示します。値に <code>output</code> を指定した場合は、コマンドの入力を検証し、そのコマンドの出力 JSON のサンプルを返します。生成される JSON スケルトンは AWS CLI のバージョン間で一定ではなく、生成される JSON スケルトンの後方互換性は保証されません。</p>
