register-default-host-management-configuration¶

Description¶

Enables Default Host Management Configuration (DHMC) for the current Amazon Web Services account and Amazon Web Services Region. With DHMC enabled, you don’t need to configure additional resources, such as an instance profile, to use your Amazon EC2 instances as managed nodes in Amazon Web Services Systems Manager.

To use this operation, you must have the following permissions:

  • You need the ssm:GetServiceSetting and ssm:UpdateServiceSetting permissions for the /ssm/managed-instance/default-ec2-instance-management-role service setting.
  • You need the iam:GetRole and iam:PassRole permissions for the role used for Default Host Management Configuration.

If PermissionModel is SERVICE_MANAGED , you also need the iam:CreateRole and iam:AttachRolePolicy permissions so that Amazon Web Services Systems Manager can create and configure the role on your behalf.

See also: AWS API Documentation

Options¶

--permission-model (string) [required]

The permission model that determines how the IAM role for Default Host Management Configuration is provided.

The permission model can be one of the following values:

SERVICE_MANAGED

Amazon Web Services Systems Manager creates and manages the role on your behalf.

SELF_MANAGED

You provide the role to register in RoleArn .

Possible values:

  • SERVICE_MANAGED
  • SELF_MANAGED

--role-arn (string)

The Amazon Resource Name (ARN) of the self-managed IAM role that you register for Default Host Management Configuration. The requirement for this value depends on the permission model:

  • If PermissionModel is SELF_MANAGED , this value is required.
  • If PermissionModel is SERVICE_MANAGED , this value must not be set.

Constraints:

  • min: 20
  • max: 2048
  • pattern: ^arn:aws[a-z0-9-]*:iam::\d{12}:role/[\w+=,.@/-]+$

--overwrite | --no-overwrite (boolean)

Specifies whether to override the role that is currently registered for Default Host Management Configuration. The default is false , which acts as a guardrail against accidentally replacing an existing configuration. Set this to true to replace the currently registered role.

--cli-input-json | --cli-input-yaml (string) Reads arguments from the JSON string provided. The JSON string follows the format provided by --generate-cli-skeleton. If other arguments are provided on the command line, those values will override the JSON-provided values. It is not possible to pass arbitrary binary values using a JSON-provided value as the string will be taken literally. This may not be specified along with --cli-input-yaml.

--generate-cli-skeleton (string) Prints a JSON skeleton to standard output without sending an API request. If provided with no value or the value input, prints a sample input JSON that can be used as an argument for --cli-input-json. Similarly, if provided yaml-input it will print a sample input YAML that can be used with --cli-input-yaml. If provided with the value output, it validates the command inputs and returns a sample output JSON for that command. The generated JSON skeleton is not stable between versions of the AWS CLI and there are no backwards compatibility guarantees in the JSON skeleton generated.

The Amazon Resource Name (ARN) of the IAM role registered for Default Host Management Configuration. The value depends on the permission model:

SERVICE_MANAGED

The ARN of the role that Amazon Web Services Systems Manager created in the IAM reserved path.

SELF_MANAGED

The RoleArn that you provided.
